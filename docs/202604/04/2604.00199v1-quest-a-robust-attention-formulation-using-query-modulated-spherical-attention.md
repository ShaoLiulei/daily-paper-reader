## 摘要
Transformer 模型架构已成为深度学习中最广泛使用的架构之一，而注意力机制是其核心。标准注意力公式对查询（query）和键（key）向量之间的缩放点积应用 softmax 操作。我们探讨了查询和键的范数所起的作用，当这些范数任意增大时，可能会导致训练不稳定。我们证明了即使在简单的 Transformer 模型中，当数据中存在易于学习的伪模式（spurious patterns）时，这种情况也会发生。我们提出了一种新的注意力公式——查询调制球面注意力（QUEST），它将键约束在超球面潜空间中，同时仍允许单个 token 灵活地控制注意力分布的锐度。QUEST 可以作为标准注意力的直接替代方案轻松使用。我们专注于视觉应用，同时也探索了其他领域，以突出该方法的通用性。我们表明：(1) QUEST 的训练过程稳定；(2) 提升了模型性能；(3) 对数据损坏和对抗性攻击具有鲁棒性。

## Abstract
The Transformer model architecture has become one of the most widely used in deep learning and the attention mechanism is at its core. The standard attention formulation uses a softmax operation applied to a scaled dot product between query and key vectors. We explore the role played by norms of the queries and keys, which can cause training instabilities when they arbitrarily increase. We demonstrate how this can happen even in simple Transformer models, in the presence of easy-to-learn spurious patterns in the data. We propose a new attention formulation, QUEry-modulated Spherical aTtention (QUEST), that constrains the keys to a hyperspherical latent space, while still allowing individual tokens to flexibly control the sharpness of the attention distribution. QUEST can be easily used as a drop-in replacement for standard attention. We focus on vision applications while also exploring other domains to highlight the method's generality. We show that (1) QUEST trains without instabilities and (2) produces models with improved performance (3) that are robust to data corruptions and adversarial attacks.

Transformer 的核心是缩放点积注意力（Scaled Dot-Product Attention, SDPA）。研究发现，Query（查询）和 Key（键）向量的范数（Norm）在训练过程中往往会无限制增长，导致注意力 Logits 爆炸，进而引发训练不稳定（如梯度消失或爆炸）。
*   **核心发现**：即使在简单模型中，如果数据包含易于学习的“伪模式”（Spurious Patterns），Key 的范数会迅速增大以“窃取”全局注意力，导致模型陷入次优解且对噪声敏感。
*   **研究目标**：设计一种既能保持注意力表达灵活性，又能通过约束向量范数来确保训练稳定性和鲁棒性的新注意力机制。

### 2. 方法论：核心思想与技术细节
论文提出了 **QUEST (QUEry-modulated Spherical aTtention)**，其核心思想是将 Key 向量约束在超球面上，而保留 Query 的范数作为调节因子。
*   **核心公式**：不同于标准注意力的 $A = \text{softmax}(C Q K^T)$，QUEST 的计算方式为：
    $$A = \text{softmax}(Q \bar{K}^T)$$
    其中 $\bar{K}$ 是经过 $\ell_2$ 归一化后的 Key 向量（即 $\bar{k}_j = k_j / \|k_j\|_2$），且去除了传统的缩放因子 $C=1/\sqrt{D_H}$。
*   **机制解释**：
    *   **Key 归一化**：防止单个 Token 通过增大范数来强行占据全局注意力，将相似度计算转化为超球面上的余弦相似度。
    *   **Query 调制**：保留 Query 的范数 $\|q_i\|$，使其能够独立控制该 Token 对应注意力分布的“锐度”（Sharpness）。范数越大，分布越集中；范数越小，分布越平滑。
*   **易用性**：QUEST 可作为标准注意力的“掉入式”（Drop-in）替代方案，无需修改模型架构。
