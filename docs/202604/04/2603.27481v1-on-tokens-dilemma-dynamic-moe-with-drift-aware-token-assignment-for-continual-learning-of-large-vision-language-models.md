## 摘要
多模态持续指令微调旨在通过学习新数据来不断增强大规模视觉语言模型（LVLMs），同时不遗忘先前习得的知识。混合专家（MoE）架构通过增量添加新专家并扩展路由，同时保持现有专家冻结，自然地促进了这一过程。然而，尽管存在专家隔离，基于 MoE 的持续学习者仍会因路由漂移（routing-drift）而遭受遗忘：旧任务的 token 会被错误地吸引到新添加的专家中，从而降低在先前任务上的性能。我们在 token 层面分析了这种失效模式，并揭示了“token 的困境”：新任务数据中的模糊 token 和旧 token 提供的学习收益极低，但当它们在训练期间因模糊的路由分配而被路由到新专家时，会导致遗忘。受此启发，我们提出了 LLaVA-DyMoE，这是一个通过漂移感知 token 分配来增量扩展 MoE 的动态 MoE 框架。我们通过路由评分分布来表征 token 类型，并应用针对性的正则化。具体而言，token 级的分配引导使模糊 token 和旧 token 远离新专家，以保留已建立的路由模式并缓解路由漂移，而互补的路由评分正则化则强制执行专家组分离并促进新专家的专业化。广泛的实验表明，我们的 LLaVA-DyMoE 有效地缓解了路由漂移引起的遗忘，与基准模型相比，平均最终准确率提高了 7% 以上，遗忘率降低了 12%。项目页面见 https://zhaoc5.github.io/DyMoE。

## Abstract
Multimodal Continual Instruction Tuning aims to continually enhance Large Vision Language Models (LVLMs) by learning from new data without forgetting previously acquired knowledge. Mixture of Experts (MoE) architectures naturally facilitate this by incrementally adding new experts and expanding routers while keeping the existing ones frozen. However, despite expert isolation, MoE-based continual learners still suffer from forgetting due to routing-drift: old-task tokens become mistakenly attracted to newly added experts, degrading performance on prior tasks. We analyze the failure mode at the token level and reveal the token's dilemma: ambiguous and old tokens in new-task data offer minimal learning benefit yet induce forgetting when routed to new experts, due to their ambiguous routing assignment during training. Motivated by this, we propose LLaVA-DyMoE, a dynamic MoE framework that incrementally expands the MoE with drift-aware token assignment. We characterize token types via their routing score distributions and apply targeted regularization. Specifically, a token-level assignment guidance steers ambiguous and old tokens away from new experts to preserve established routing patterns and alleviate routing-drift, while complementary routing score regularizations enforce expert-group separation and promote new-expert specialization. Extensive experiments demonstrate that our LLaVA-DyMoE effectively mitigates routing-drift-induced forgetting, achieving over a 7% gain in mean final accuracy and a 12% reduction in forgetting compared to baselines. The project page is https://zhaoc5.github.io/DyMoE.

### 1. 核心问题与整体含义（研究动机和背景）
本文针对**多模态持续指令微调（MCIT）**中的灾难性遗忘问题展开研究。虽然混合专家模型（MoE）通过冻结旧专家并添加新专家的“参数隔离”机制被认为能缓解遗忘，但作者发现了一个关键失效模式：**路由漂移（Routing-drift）**。
*   **核心发现**：即使旧专家参数被冻结，新任务训练过程中更新的路由器参数也会产生偏差，导致旧任务的 Token 在推理时被错误地分配给未经相关训练的新专家。
*   **Token 的困境**：新任务数据中并非所有 Token 都有利于学习。作者识别出“模糊 Token”和“旧 Token”，它们对新任务贡献极小，却极易诱发路由漂移，导致模型在旧知识上的崩溃。

### 2. 方法论：LLaVA-DyMoE
作者提出了 **LLaVA-DyMoE** 框架，通过“漂移感知”的 Token 分配策略来优化动态 MoE 的扩展过程。

*   **核心思想**：在训练阶段，根据 Token 的路由评分分布动态识别其类型，并对其分配路径进行干预，确保“上帝的归上帝，凯撒的归凯撒”。
*   **关键技术细节**：
    1.  **Token 分配引导 (TAG)**：计算 Token 对新旧专家组的置信度差异（相对差异 $D_{rel}$）。若 Token 表现出高度模糊性（$D_{rel} \le \tau$）或明显偏向旧专家，则通过掩码机制强制将其路由至旧专家组，保护新路由器不被旧模式干扰。
    2.  **路由评分正则化 (RSR)**：
        *   **独占性损失 ($L_{exc}$)**：通过最小化新旧专家组权重的乘积，强制 Token 路由具有明确的选择性，避免“脚踩两只船”。
        *   **特化损失 ($L_{spe}$)**：鼓励新专家专注于处理那些真正具有新模式的 Token，提升新任务的学习效率。
    3.  **动态扩展**：每当新任务到达，增加一组 LoRA 专家并扩展路由器输出维度，仅训练新增部分。

### 6. 主要结论与发现
*   **性能领先**：LLaVA-DyMoE 在平均最终准确率（MFN）上达到了 57.03%，比基线 IncMoELoRA 提升了 **7.35%**。

### 7. 优点
*   **理论深刻**：从 Token 级别的微观视角揭示了 MoE 持续学习中遗忘的本质原因（路由漂移），而非仅仅停留在宏观的参数隔离。
*   **高效简洁**：无需存储大量旧数据（在纯正则化模式下），且推理时不需要额外的任务 ID 预测，保持了 MoE 的推理效率。
*   **通用性强**：作为一种路由正则化手段，它可以轻松集成到任何基于 MoE 的 Transformer 架构中。

### 8. 不足与局限
*   **超参数依赖**：模糊阈值 $\tau$ 对性能有一定影响，虽然实验给出了推荐值，但在面对极度差异化或极度相似的任务流时，可能需要手动调优。
*   **任务类型局限**：实验主要集中在 VQA（问答）类任务上，对于长文本生成、多轮对话等更复杂的持续学习场景尚未深入探讨。
*   **模型规模限制**：虽然测试了 7B 和 13B 模型，但在更大规模（如 70B+）或混合模态更复杂的模型上的表现仍待验证。
