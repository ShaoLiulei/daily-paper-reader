## 摘要
我们提出了 EventHub，这是一个用于训练深度事件立体网络的新型框架，它无需来自昂贵主动传感器的真值标注，而是依赖于标准的彩色图像。通过这些图像，我们利用最先进的新视角合成技术推导出代理标注和代理事件，或者在图像已与事件数据配对的情况下，仅推导出代理标注。利用我们数据工厂生成的训练集，我们将 RGB 文献中最先进的立体模型重新用于处理事件数据，从而获得了具有前所未有泛化能力的全新事件立体模型。在广泛使用的事件立体数据集上进行的实验证明了 EventHub 的有效性，并展示了相同的数据蒸馏机制如何提高 RGB 立体基础模型在夜间场景等挑战性条件下的准确性。

## Abstract
We propose EventHub, a novel framework for training deep-event stereo networks without ground truth annotations from costly active sensors, relying instead on standard color images. From these images, we derive either proxy annotations and proxy events through state-of-the-art novel view synthesis techniques, or simply proxy annotations when images are already paired with event data. Using the training set generated by our data factory, we repurpose state-of-the-art stereo models from RGB literature to process event data, obtaining new event stereo models with unprecedented generalization capabilities. Experiments on widely used event stereo datasets support the effectiveness of EventHub and show how the same data distillation mechanism can improve the accuracy of RGB stereo foundation models in challenging conditions such as nighttime scenes.

*   **核心问题**：事件相机（Event Camera）在高速运动和极端光照下具有优势，但其立体匹配（Stereo Matching）任务面临严重的**数据短缺**问题。现有的数据集（如 DSEC, M3ED）依赖 LiDAR 获取真值，但 LiDAR 标注存在稀疏、动态物体伪影、重投影误差以及无法处理非朗伯体表面（如玻璃）等局限性。
*   **研究动机**：摆脱对昂贵且有缺陷的主动传感器（LiDAR）的依赖，利用互联网上海量的彩色图像（RGB）资源，通过跨模态蒸馏和神经渲染技术，为事件立体网络构建一个高质量、稠密且易于获取的“数据工厂”。

### 2. 方法论：EventHub 框架
EventHub 包含两个核心组件，旨在从 RGB 图像中提取代理标注（Proxy Labels）和代理事件（Proxy Events）：

*   **基于新视角合成（NVS）的合成数据生成**：
    *   针对只有单目 RGB 序列的场景，利用 **SVRaster**（一种改进的 3D 高斯泼溅技术）重建场景。
    *   **虚拟轨迹构建**：设计局部（物体中心）和全局（室内漫游）虚拟相机轨迹，模拟相机运动。
    *   **运动自适应渲染**：利用 ESIM 模拟器从渲染的 RGB 帧中生成事件流，并根据像素运动速度动态调整渲染频率，以消除模拟伪影。
    *   **深度正则化**：引入 `DepthAnythingV2` 等先验知识约束 NVS 的深度生成，并提出一种基于体素大小的置信度度量 $C_{Vsize}$ 来过滤噪声标注。
*   **跨模态立体蒸馏**：
    *   针对已有 RGB-Event 配对但无深度真值的场景，利用成熟的 **RGB 立体基础模型（SFM）**（如 FoundationStereo）处理彩色图像对，生成高精度深度图。
    *   通过相机外参将 RGB 领域的深度图重投影至事件相机坐标系，实现对真实事件数据的自动标注。
*   **模型重用（Repurposing）**：
    *   将 RGB 立体网络的架构直接迁移至事件领域，使用 `Tencode` 编码将事件流转化为 3 通道张量，并利用预训练的 RGB 权重进行微调，从而继承 RGB 基础模型的强大几何感知能力。

### 6. 主要结论与发现
*   **泛化性飞跃**：使用 EventHub 训练的模型在跨域测试（M3ED/MVSEC）中显著优于直接用 LiDAR 真值训练的模型，误差降低最高达 **50%**。
*   **LiDAR 并非完美**：实验发现 LiDAR 标注的稀疏性和噪声实际上限制了模型的上限，而 EventHub 提供的稠密代理标注能产生更锐利、更完整的深度图。
*   **闭环增强**：训练好的事件立体模型可以反过来为夜间 RGB 图像提供代理标注，显著提升 RGB 基础模型在极端黑暗环境下的表现。

### 7. 优点与亮点
*   **无需主动传感器**：彻底摆脱了对 LiDAR 的依赖，降低了事件相机研究的门槛。
*   **跨模态协同**：不仅是 RGB 辅助事件，还实现了事件辅助 RGB（夜间增强），展示了双向知识迁移的可能性。
*   **高质量合成管线**：结合了最新的 NVS 技术和运动自适应渲染，生成的代理事件和深度图在质量上达到了新的高度。

### 8. 不足与局限
*   **静态场景限制**：目前的 NVS 数据生成管线（SVRaster）主要针对静态场景，对于包含大量动态物体的复杂场景生成能力有限。
*   **计算开销**：虽然推理很快，但前期针对每个场景进行 NVS 优化（20 分钟/场景）仍具有一定的计算成本。
*   **模拟差距**：尽管使用了先进的模拟器，但代理事件与真实硬件捕获的事件之间仍可能存在微小的领域间隙（Domain Gap）。
