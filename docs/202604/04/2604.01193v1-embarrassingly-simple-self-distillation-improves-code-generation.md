## 摘要
大型语言模型（LLM）能否仅利用其自身的原始输出，在没有验证器、教师模型或强化学习的情况下，提升代码生成能力？我们通过简单自蒸馏（SSD）给出了肯定的回答：在特定的温度和截断配置下从模型中采样解法，然后使用标准监督微调（SFT）对这些样本进行微调。SSD 将 Qwen3-30B-Instruct 在 LiveCodeBench v6 上的 pass@1 准确率从 42.4% 提升至 55.3%，且增益主要集中在较难的问题上；此外，该方法在 4B、8B 和 30B 规模的 Qwen 和 Llama 模型（包括指令微调版和思考版）上均具有泛化性。为了理解为何如此简单的方法能够奏效，我们将这些增益归因于 LLM 解码过程中的精度-探索冲突，并证明 SSD 以一种上下文相关的方式重塑了 token 分布：在需要精度的场景下抑制干扰项尾部，而在需要探索的场景下保留有用的多样性。综上所述，SSD 为提升 LLM 代码生成能力提供了一个互补的训练后方向。

## Abstract
Can a large language model (LLM) improve at code generation using only its own raw outputs, without a verifier, a teacher model, or reinforcement learning? We answer in the affirmative with simple self-distillation (SSD): sample solutions from the model with certain temperature and truncation configurations, then fine-tune on those samples with standard supervised fine-tuning. SSD improves Qwen3-30B-Instruct from 42.4% to 55.3% pass@1 on LiveCodeBench v6, with gains concentrating on harder problems, and it generalizes across Qwen and Llama models at 4B, 8B, and 30B scale, including both instruct and thinking variants. To understand why such a simple method can work, we trace these gains to a precision-exploration conflict in LLM decoding and show that SSD reshapes token distributions in a context-dependent way, suppressing distractor tails where precision matters while preserving useful diversity where exploration matters. Taken together, SSD offers a complementary post-training direction for improving LLM code generation.

*   **整体含义**：论文证明了“简单自蒸馏”（Simple Self-Distillation, SSD）这一极简路径的有效性，揭示了模型内部潜藏的性能可以通过重塑 Token 分布来释放。

#### 2. 方法论：核心思想与技术细节
*   **核心思想**：通过调整采样时的解码参数（温度和截断），获取模型自身的输出，并直接对这些原始数据进行有监督微调（SFT）。
*   **关键流程**：
    1.  **数据合成**：给定一组编程题目，使用基座模型 $p_\theta$ 以特定的训练温度 $T_{train}$ 和截断配置（top-k, top-p）生成解法。**不对解法进行任何正确性验证或过滤**。
    2.  **微调训练**：使用标准的交叉熵损失函数，在这些原始输出上对模型进行 SFT。
    3.  **推理评估**：在推理阶段，使用评估温度 $T_{eval}$ 进行解码。
*   **理论机制（精度-探索冲突）**：
    *   **Lock（锁定位置）**：语法或逻辑高度确定的位置，需要高精度（抑制长尾分布）。
    *   **Fork（分叉位置）**：存在多种可行路径的位置，需要探索（保留多样性）。
    *   SSD 通过训练重塑了分布：在 Lock 处压缩支持集以提高精度，在 Fork 处平滑分布以增强探索能力。

#### 6. 主要结论与发现
*   **性能显著提升**：Qwen3-30B-Instruct 在 LCB v6 上的 pass@1 从 42.4% 提升至 **55.3%**（相对提升 30%）。

*   **极其简单**：无需复杂的 RL 算法（如 PPO/GRPO），无需执行环境（Sandbox），无需外部标签。

*   **泛化性强**：在不同规模、不同架构（Dense/MoE）以及是否包含“思考过程”的模型上均有效。

#### 8. 不足与局限
*   **领域局限性**：主要针对代码生成任务，虽然在 30B 模型上表现出较好的能力保持，但在 4B/8B 小模型上，SSD 训练可能会导致数学（AIME）或通用知识（MMLU）性能的轻微下降。

*   **数据依赖**：虽然不需要标签，但仍需要高质量的题目提示词（Prompts）池。
