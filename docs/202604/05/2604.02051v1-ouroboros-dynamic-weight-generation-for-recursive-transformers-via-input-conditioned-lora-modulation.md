## 摘要
递归 Transformer 在多个深度步骤中重用共享权重块，以计算量换取参数量。其核心局限性在于：每一步都应用相同的变换，阻碍了模型在深度方向上组合不同的操作。我们提出了 Ouroboros，该系统将一个紧凑的控制器（Controller）超网络附加到递归 Transformer 块上。控制器观察当前的隐藏状态，生成逐步的对角调制向量，并将其应用于冻结的、经 SVD 初始化的 LoRA 基矩阵，从而使每个递归步骤都具有输入依赖性。我们将此方法与门控递归（偏置初始化为 88% 的保留率）和逐步层归一化（LayerNorm）相结合，以实现稳定的深度迭代。在将 Qwen2.5-3B 拆分为 Prelude/Recurrent/Coda 架构（保留 36 层中的 17 层）的实验中，Ouroboros 相比未经修改的 17 层基线降低了 43.4% 的训练损失，弥补了因移除层而导致的 51.3% 的性能差距。整个系统仅增加了 920 万个可训练参数（包括控制器、门控和逐步归一化），但在深度为 1 时，其性能比同等规模的静态逐步 LoRA 高出 1.44 个损失点，并且在所有测试深度（1, 4, 8, 16）和秩（8, 32, 64）下均保持领先。我们还发现门控递归至关重要：如果没有它，递归层的应用会使模型表现明显变差。这些提升是在训练分布上测得的；在预留文本上，控制器尚未表现出优于基线的改进，我们将这一局限性归因于冻结的下游层，并对此进行了详细讨论。

## Abstract
Recursive transformers reuse a shared weight block across multiple depth steps, trading parameters for compute. A core limitation: every step applies the same transformation, preventing the model from composing distinct operations across depth. We present Ouroboros, a system that attaches a compact Controller hypernetwork to a recursive transformer block. The Controller observes the current hidden state, produces a per-step diagonal modulation vector, and applies it to frozen SVD-initialized LoRA bases, making each recurrence step input-dependent. We combine this with gated recurrence (bias-initialized to 88% retention) and per-step LayerNorm for stable deep iteration. On Qwen2.5-3B split into a Prelude/Recurrent/Coda architecture (17 of 36 layers retained), Ouroboros reduces training loss by 43.4% over the unmodified 17-layer baseline, recovering 51.3% of the performance gap caused by layer removal. The full system adds only 9.2M trainable parameters (Controller, gate, and per-step norms) yet outperforms equivalently-sized static per-step LoRA by 1.44 loss points at depth 1 and remains ahead across all tested depths (1, 4, 8, 16) and ranks (8, 32, 64). We also find that gated recurrence is essential: without it, recursive layer application makes the model strictly worse. These gains are measured on the training distribution; on held-out text, the Controller does not yet improve over the baseline, a limitation we attribute to frozen downstream layers and discuss in detail. ### 论文总结：Ouroboros —— 基于输入条件 LoRA 调制的递归 Transformer 动态权重生成

#### 1. 核心问题与整体含义（研究动机和背景）
递归 Transformer（Recursive Transformers）通过在多个计算步骤中重用同一组权重块，实现了以计算量换取参数量的目标，是模型压缩和端侧部署的重要方向。然而，传统递归模型存在**权重均匀性（Uniformity）**的局限：每一层递归都执行完全相同的变换，无法像深层静态模型那样在不同深度学习不同的特征组合。

本文提出的 **Ouroboros** 旨在打破这种限制。其核心动机是：能否引入一个微型超网络，根据模型当前的计算状态动态生成每一层递归的权重修改，从而使递归过程具备“输入相关性”和“步骤相关性”。

#### 2. 方法论：核心思想与关键技术
Ouroboros 系统将预训练模型拆分为 **Prelude（前奏层）**、**Recurrent Block（递归块）**和 **Coda（尾声层）** 三部分，其核心技术包含：

*   **Controller（控制器）超网络**：这是一个仅 0.7M 参数的小型 MLP。它接收当前隐藏状态的均值池化向量和步骤嵌入（Step Embedding），动态输出对角调制向量 $\delta$。
*   **SVD 初始化的固定 LoRA 基底**：为了捕捉被移除层的知识，作者对移除层的权重残差进行奇异值分解（SVD），初始化 LoRA 的 $A$ 和 $B$ 矩阵并将其冻结。控制器仅负责生成对角缩放向量来调制这些预存的“知识方向”。
*   **门控递归（Gated Recurrence）**：引入带有恒等偏置（初始化为 88% 保留率）的门控机制，混合新旧隐藏状态。这解决了深层迭代中残差连接导致的方差爆炸问题。
*   **逐步层归一化（Per-step LayerNorm）**：为每个递归步骤提供独立的 RMSNorm 缩放参数，帮助模型区分不同的迭代阶段。
*   **算法流程**：输入经过 Prelude 后进入递归块；在每一步 $t$，控制器根据当前状态生成 LoRA 调制，更新递归层权重并执行前向计算，最后通过门控和 StepNorm 更新隐藏状态，循环 $N$ 次后进入 Coda 输出。

#### 3. 实验设计
*   **基础模型**：Qwen2.5-3B（36层），实验中将其缩减为 17 层（8层 Prelude + 1层 Recurrent + 8层 Coda）。
*   **数据集**：主要在 **FineWeb-edu** 上进行训练和评估，并在 12 个多样化的预留文本段落上测试泛化性。
*   **Benchmark 与对比方法**：
    *   **17层基线**：不进行递归的截断模型。
    *   **全量 36 层 Qwen2.5-3B**：性能上限。
    *   **静态 LoRA（Static LoRA）**：权重修改仅取决于步骤索引，不取决于输入内容。
    *   **消融实验**：针对不同递归深度（1, 4, 8, 16）、LoRA 秩（8, 32, 64）以及是否有门控机制进行对比。

#### 4. 资源与算力
*   **硬件**：使用 **NVIDIA H100 80GB GPU**。
*   **训练细节**：每个配置在单卡上训练 **300,000 步**。
*   **精度与优化器**：采用 BF16 精度，AdamW 优化器，有效 Batch Size 为 32，序列长度 2048。

#### 5. 实验数量与充分性
作者进行了约 **13 组核心配置实验**，涵盖了深度、秩、学习率的交叉验证。
*   **充分性**：实验覆盖了从架构组件（门控、控制器）到超参数（Rank、Depth）的多个维度。
*   **客观性**：作者不仅展示了正面结果（训练损失大幅下降），还诚实地披露了模型在预留数据集上未能超越基线的泛化性问题，并进行了深入的归因分析，表现出较高的学术严谨性。

#### 6. 主要结论与发现
*   **性能提升**：在 Qwen2.5-3B 上，Ouroboros 相比 17 层基线降低了 **43.4%** 的训练损失，弥补了层数削减带来性能损失的 **51.3%**。
*   **动态性优势**：控制器生成的动态调制在所有配置下均优于静态 LoRA，尤其在深度为 1 时，领先优势达 **1.44** 个损失点。
*   **门控是必需的**：实验证明如果没有门控机制，简单的递归应用反而会导致模型性能恶化。
*   **深度不变性**：令人惊讶的是，在当前设置下，增加递归深度（从 1 到 16）对最终损失的影响极小，这表明单次动态调制已捕捉了大部分增益。

#### 7. 优点
*   **极高的参数效率**：仅增加 9.2M 可训练参数（约占原模型的 0.6%），实现了显著的性能恢复。
*   **创新的初始化策略**：利用 SVD 从被移除的层中提取“知识基底”，降低了超网络的学习难度。
*   **工程完备性**：提供了开源代码，包含 66 个单元测试，确保了架构的可复现性。

#### 8. 不足与局限
*   **泛化性瓶颈**：模型在训练分布上表现优异，但在未见过的文本上未能提升。作者分析这是因为 **Coda（尾声层）被冻结**，无法适应递归块输出的新分布。
*   **深度利用不足**：目前的系统未能体现出“越难的输入需要越深思考”的自适应深度优势，深度增加带来的边际收益递减。
*   **规模验证单一**：实验仅在 3B 规模模型上进行，尚未在 7B 或更大规模模型上验证其扩展性。
