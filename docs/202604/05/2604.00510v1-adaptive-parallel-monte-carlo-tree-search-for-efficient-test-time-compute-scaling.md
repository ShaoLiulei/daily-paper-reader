## 摘要
蒙特卡洛树搜索 (MCTS) 是一种有效的测试时计算扩展 (TTCS) 方法，用于提升大语言模型的推理性能，但其高度波动的执行时间在实践中会导致严重的长尾延迟。现有的优化手段（如正向提前退出）在理想情况下能降低延迟，但在搜索持续进行却无实质性进展时效果有限。我们引入了“负向提前退出”（negative early exit）来剪枝无成效的 MCTS 轨迹，并提出了一种“自适应增强机制”（adaptive boosting mechanism），通过重新分配回收的计算资源来减少并发搜索间的资源竞争。这些技术集成到 vLLM 中，在保持推理准确性的同时，显著降低了 p99 端到端延迟并提高了吞吐量。

## Abstract
Monte Carlo Tree Search (MCTS) is an effective test-time compute scaling (TTCS) method for improving the reasoning performance of large language models, but its highly variable execution time leads to severe long-tail latency in practice. Existing optimizations such as positive early exit, reduce latency in favorable cases but are less effective when search continues without meaningful progress. We introduce {\it negative early exit}, which prunes unproductive MCTS trajectories, and an {\it adaptive boosting mechanism} that reallocates reclaimed computation to reduce resource contention among concurrent searches. Integrated into vLLM, these techniques substantially reduce p99 end-to-end latency while improving throughput and maintaining reasoning accuracy.

*   **核心问题**：MCTS 具有高度的**顺序依赖性**，导致执行时间波动巨大，在实际生产环境中会引发严重的**长尾延迟（Tail Latency）**。
*   **动机**：现有的“正向早停”（找到好答案就停止）无法解决那些“搜索很久却无果”的请求，这些请求会长时间霸占计算资源，导致系统吞吐量下降。

#### 2. 方法论：核心思想与关键技术
本文提出了一套自适应并行 MCTS 框架，核心思想是将 MCTS 视为一个需要动态资源管理的系统，而非单纯的搜索算法。

*   **负向早停（Negative Early Exit, NE）**：
    *   **原理**：基于轨迹得分的上限受限于叶子节点得分的特性。如果当前搜索树中所有叶子节点的 PRM 得分都低于预设阈值（即均为“徒劳节点”），则判定该请求无法产生高质量答案，立即终止搜索。
    *   **优化**：引入“选择性徒劳检查”，利用第一步奖励与最终得分的相关性，排除低潜力分支，提高剪枝效率。
*   **自适应增强机制（Adaptive Boosting）**：
    *   **资源重分配**：将“早停”释放的计算资源动态分配给更有潜力的并发任务。
    *   **并行度控制公式**：通过评分函数 $S(i, t) = \log(1 + \Delta t_i) + \beta \cdot I(\rho_i > \tau)$ 决定任务 $i$ 的并行度。其中 $\Delta t_i$ 是等待时间（防止饥饿），$I(\rho_i > \tau)$ 是“90%接近规则”（优先加速即将完成的任务）。
*   **WU-PUCT 并行策略**：
    *   改进了 AlphaZero 风格的 PUCT 规则，引入“未观测计数”（Unobserved Counts）来处理并行 rollout 时的统计延迟，防止多个线程重复探索同一路径。
