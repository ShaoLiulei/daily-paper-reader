## 摘要
多模态大语言模型经常受到物体幻觉的困扰。虽然现有研究利用了注意力增强和视觉回溯，但我们发现这些工作对于模型最终阶段注意力漂移的解释性不足。在本文中，我们研究了视觉特征的逐层演化，并发现幻觉源于深层注意力向早期层的初始视觉噪声回归。我们观察到，输出的可靠性取决于在中间层而非最终层获取视觉锚点。基于这些见解，我们提出了 CLVA（Cross-Layer Visual Anchors，跨层视觉锚点），这是一种无需训练的方法，它在抑制回归噪声的同时增强了关键的中间层特征。该方法通过利用从注意力动态中捕获的关键锚点，有效地将深层注意力拉回到正确的视觉区域。我们在多种架构和基准测试上评估了我们的方法，证明了其在不显著增加计算时间和 GPU 显存的情况下具有出色的性能。

## Abstract
Multimodal Large Language Models often suffer from object hallucination. While existing research utilizes attention enhancement and visual retracing, we find these works lack sufficient interpretability regarding attention drift in final model stages. In this paper, we investigate the layer wise evolution of visual features and discover that hallucination stems from deep layer attention regressing toward initial visual noise from early layers. We observe that output reliability depends on acquiring visual anchors at intermediate layers rather than final layers. Based on these insights, we propose CLVA, which stands for Cross-Layer Visual Anchors, a training free method that reinforces critical mid layer features while suppressing regressive noise. This approach effectively pulls deep layer attention back to correct visual regions by utilizing essential anchors captured from attention dynamics. We evaluate our method across diverse architectures and benchmarks, demonstrating outstanding performance without significant increase in computational time and GPU memory.

#### 1. 核心问题与整体含义
本文针对多模态大语言模型（MLLM）中的**物体幻觉（Object Hallucination）**问题展开研究。研究动机源于一个关键发现：MLLM 在推理过程中，其内部注意力机制在中间层通常能准确锁定目标区域，但在进入深层（后期）后，注意力会发生“漂移”，不再关注图像中的实际物体，而是退化并回归到早期层产生的初始视觉噪声或语言先验中。这种**深层注意力漂移**是导致模型生成虚假内容的主要诱因。

#### 2. 方法论：CLVA（跨层视觉锚点）
作者提出了一种名为 **CLVA** 的无需训练（Training-free）的干预方法，核心思想是利用中间层的“正确记忆”来修正深层的“注意力偏差”。
*   **功能头分类**：通过计算注意力强度，将模型中的注意力头分为“视觉敏感头”（关注图像特征）和“视觉不敏感头”（关注噪声或语言先验）。
*   **双锚点提取**：
    *   **正向锚点（Positive Anchor）**：从中间层的视觉敏感头中提取，代表准确的语义对齐区域。
    *   **负向锚点（Negative Anchor）**：从早期层的视觉不敏感头中提取，代表固有的空间偏见和背景噪声。
*   **注意力重锚定（Attention Re-anchoring）**：在深层解码阶段，通过公式调整注意力矩阵：增强正向锚点区域的权重，同时抑制负向锚点区域的权重。
*   **流程**：该方法在推理阶段即插即用，通过修改 Self-Attention 或 Cross-Attention 的权重分布，将模型注意力“拉回”到真实的视觉证据上。

#### 6. 主要结论与发现
*   **幻觉成因**：证实了幻觉并非随机产生，而是深层注意力向早期层噪声分布的系统性回归。
*   **中间层价值**：中间层是视觉接地的“黄金地带”，包含了最纯净的视觉-语义对齐信息。
*   **性能提升**：CLVA 在 POPE 准确率上提升了 0.59%~7.13%，在 CHAIR 幻觉率上降低了约 5%，同时在 MME 感知任务上显著加分。

*   **强解释性**：基于对模型内部注意力演化的深入观察，而非黑盒式的经验调整。
*   **高通用性**：作为一种注意力层面的干预手段，易于集成到各种基于 Transformer 的多模态模型中。

*   **超参数敏感性**：正负锚点的权重（$\alpha, \beta$）以及锚点层的选择可能需要针对特定模型进行少量手动调优。

*   **模型规模覆盖**：论文主要验证了 7B 级别的模型，对于更大规模（如 70B+）或更小规模（端侧模型）的泛化效果有待进一步验证。
