## 摘要
大规模视觉语言模型（LVLMs）在图像和视频理解任务中展现出卓越的性能，但其计算成本随视觉 token 数量的增加而迅速增长。现有的 token 剪枝方法主要通过经验性手段缓解这一问题，却忽视了注意力的内部机制。在本文中，我们提出了一种基于注意力对偶形式视角的新型免训练 token 剪枝框架。我们将注意力重新表述为一个隐式线性层，其权重矩阵是若干秩为 1 的外积之和，每个外积由单个 token 的键值对（key-value pair）生成。因此，token 剪枝被简化为选择这些秩 1 更新的一个最优子集，以最佳地近似原始对偶权重矩阵。将这一视角扩展到 LVLM 中的标准 softmax 注意力后，我们推导出一个能够同时量化 token 信息量级和信息重复度的新型指标。为了利用该指标高效地选择子集，我们引入了渐进式分块最大边际相关性（Progressive Chunked Maximal Marginal Relevance）。大量实验表明，我们的方法在性能和效率之间实现了更好的权衡，同时为现有的剪枝方法提供了另一种视角。

## Abstract
Large Vision Language Models show impressive performance across image and video understanding tasks, yet their computational cost grows rapidly with the number of visual tokens. Existing token pruning methods mitigate this issue through empirical approaches while overlooking the internal mechanism of attention. In this paper, we propose a novel training free token pruning framework grounded in the dual form perspective of attention. We reformulate attention as an implicit linear layer whose weight matrix is the sum of rank 1 outer products, each generated by a single token's key value pair. Token pruning thus reduces to selecting an optimal subset of these rank 1 updates that best approximates the original dual weight matrix. Extending this perspective to standard softmax attention in LVLMs, we derive a novel metric quantifying both a token's information magnitude and information duplication. To efficiently select the subset with the proposed metric, we introduce Progressive Chunked Maximal Marginal Relevance. Extensive experiments demonstrate that our method achieves a better trade off between performance and efficiency, while providing another perspective on existing pruning approaches.

*   **核心问题**：大规模视觉语言模型（LVLMs）在处理高分辨率图像和长视频时，会产生海量的视觉 token。由于自注意力机制的计算复杂度随序列长度呈平方增长，这导致了巨大的计算开销和内存压力。
*   **研究动机**：现有的 token 剪枝方法大多基于经验（如仅依赖注意力分数或简单的多样性约束），缺乏对注意力机制内部运作逻辑的深入理解。本文旨在从**注意力机制的对偶形式（Dual-form）**出发，建立一个有理论支撑的、免训练的剪枝框架，将 token 剪枝视为对隐式权重矩阵的优化。

### 2. 方法论：核心思想与技术细节
*   **核心思想**：将标准注意力机制重新解释为一个隐式线性变换。在这个视角下，每个 token 的键值对（Key-Value pair）实际上是对一个隐式权重矩阵进行了一次“秩-1（Rank-1）”的更新。因此，剪枝的目标是选出一组 token，使它们产生的秩-1更新之和能够最有效地近似原始的完整权重矩阵。
*   **关键技术指标**：
    1.  **信息量级（Information Magnitude）**：衡量单个 token 对权重矩阵贡献的大小。通过结合核空间相似度（Query 与 Key 的对齐）和 Value 向量的范数来定义。
    2.  **信息重复度（Information Duplication）**：衡量不同 token 诱导的更新之间的冗余性。通过计算两个秩-1更新矩阵之间的 Frobenius 内积（可分解为 Key 的核相似度与 Value 的余弦相似度之积）来定义。
*   **算法流程（PC-MMR）**：
    *   引入**渐进式分块最大边际相关性（Progressive Chunked MMR）**算法。
    *   不同于传统的 MMR 逐个筛选（速度慢），PC-MMR 采用分块选择策略，并随着筛选进程动态增加块的大小（Growth Factor）。
    *   在每一步中，选择信息量级最高的 token 块，并根据它们与已选 token 的重复度对剩余候选者进行惩罚，从而在保证信息量的同时最大化多样性。
