## 摘要
我们提出了 Brainstacks，这是一种用于大语言模型持续多领域微调的模块化架构。该架构将领域专业知识封装为冻结的适配器堆栈，在推理时以加法方式组合在共享的冻结基座模型上。它包含五个相互关联的组件：(1) 采用 Shazeer 式噪声 top-2 路由的 MoE-LoRA，在 QLoRA 4 位量化和 rsLoRA 缩放的基础上，覆盖所有七个 Transformer 投影层；(2) 通过冻结已训练堆栈并添加新堆栈来执行残差提升（residual boosting）的内循环；(3) 按照课程顺序依赖关系训练序列化领域特定堆栈的外循环；(4) 通过随机奇异值分解（SVD）进行零空间投影，将新堆栈约束在与先前方向正交的子空间中，从而在隔离状态下实现零遗忘；(5) 一种基于结果的 sigmoid 元路由器，在经验发现的领域组合目标上进行训练，通过选择性地为堆栈分配权重来实现跨领域组合。两个边界实验：(6) 在随机初始化模型上进行 PSN 预训练；(7) 逐领域强化学习（DPO/GRPO），验证了其与 SFT 后对齐的兼容性。在 TinyLlama-1.1B（4 个领域，9 个堆栈）和 Gemma 3 12B IT（5 个领域，10 个堆栈）上的验证表明，MoE-LoRA 的收敛速度比参数匹配的单个 LoRA 快 2.5 倍，残差提升突破了单堆栈的性能上限，且路由系统恢复了因无门控堆栈累积而受损的生成质量。核心发现：基于结果的路由器发现，领域堆栈编码的是可迁移的认知原语（指令遵循的清晰度、数值推理、程序逻辑、思维链结构），而非领域特定知识；在 97% 的情况下，医疗提示词被路由到聊天+数学堆栈，尽管这些堆栈中并不包含医疗数据。

## Abstract
We present Brainstacks, a modular architecture for continual multi-domain fine-tuning of large language models that packages domain expertise as frozen adapter stacks composing additively on a shared frozen base at inference. Five interlocking components: (1) MoE-LoRA with Shazeer-style noisy top-2 routing across all seven transformer projections under QLoRA 4-bit quantization with rsLoRA scaling; (2) an inner loop performing residual boosting by freezing trained stacks and adding new ones; (3) an outer loop training sequential domain-specific stacks with curriculum-ordered dependencies; (4) null-space projection via randomized SVD constraining new stacks to subspaces orthogonal to prior directions, achieving zero forgetting in isolation; (5) an outcome-based sigmoid meta-router trained on empirically discovered domain-combination targets that selectively weights stacks, enabling cross-domain composition. Two boundary experiments: (6) PSN pretraining on a randomly initialized model; (7) per-domain RL (DPO/GRPO) validating compatibility with post-SFT alignment. Validated on TinyLlama-1.1B (4 domains, 9 stacks) and Gemma 3 12B IT (5 domains, 10 stacks), MoE-LoRA achieves 2.5x faster convergence than parameter-matched single LoRA, residual boosting breaks through the single-stack ceiling, and the routed system recovers generation quality destroyed by ungated stack accumulation. The central finding: the outcome-based router discovers that domain stacks encode transferable cognitive primitives (instruction-following clarity, numerical reasoning, procedural logic, chain-of-thought structure) rather than domain-specific knowledge, with medical prompts routing to chat+math stacks in 97% of cases despite zero medical data in those stacks.

### 1. 核心问题与研究动机
*   **核心问题**：当前大语言模型（LLM）的微调方法通常是“单体式”的。在添加新领域知识时，面临三个根本挑战：
    1.  **灾难性遗忘**：新领域的训练会破坏旧领域的性能。
    2.  **缺乏模块化**：无法在部署后独立添加、删除或更新特定领域的模型能力。
    3.  **推理冗余**：推理时无论输入为何，都会激活所有参数，缺乏选择性激活相关专业知识的机制。
*   **研究动机**：受人类大脑功能的启发，旨在构建一种模块化架构，使 LLM 能够通过“堆栈”方式持续学习新领域，同时实现零遗忘和跨领域的灵活组合。

### 2. 方法论：Brainstacks 架构
Brainstacks 由五个核心组件构成的双环训练架构：
*   **MoE-LoRA 构建块**：
    *   在 QLoRA 4-bit 量化基础上，对 Transformer 的所有 7 个投影矩阵应用混合专家 LoRA（MoE-LoRA）。
    *   采用 **Shazeer 式噪声 Top-2 路由**和 **rsLoRA（秩稳定缩放）**。
*   **内循环：残差提升（Residual Boosting）**：
    *   在单一领域内，训练并冻结一个堆栈后，添加新堆栈来学习前一个堆栈未捕获的残差误差，从而突破单堆栈的性能瓶颈。
*   **外循环：持续领域训练**：
    *   按照课程顺序（如 Chat -> Code -> Math -> Medical -> Reasoning）顺序训练领域特定堆栈。
*   **零空间投影（Null-Space Projection）**：
    *   利用**随机奇异值分解（SVD）**计算先前领域激活的子空间，并将新堆栈的梯度投影到该子空间的正交补空间（零空间）中。这在数学上保证了新训练不会干扰旧领域的表示方向。
*   **基于结果的元路由器（Outcome-Based Meta-Router）**：
    *   推理时，一个轻量级路由器根据提示词（Prompt）的语义特征，输出各领域堆栈的 Sigmoid 概率权重。
    *   **创新点**：路由器的训练目标不是基于领域标签，而是通过经验测试不同堆栈组合对 Loss 的降低程度来确定的（即“结果导向”）。

### 3. 实验设计
*   **实验场景与模型**：
    *   **TinyLlama-1.1B**：验证 4 个领域（聊天、代码、医疗、数学），共 9 个堆栈。
    *   **Gemma 3 12B IT**：验证 5 个领域（增加推理领域），共 10 个堆栈。
*   **数据集**：使用了 Alpaca、GSM8K、MedAlpaca、Python Code Instructions、OpenThoughts 等多个专业领域数据集。
*   **Benchmark**：在 HellaSwag、ARC、MMLU、TruthfulQA、GSM8K、MedQA 等 8 个零样本（Zero-shot）基准上进行评估。
*   **对比方法**：主要对比了参数量匹配的**单 LoRA（Single LoRA）**以及无门控的堆栈累积模式。

### 4. 资源与算力
*   **算力设备**：
    *   Gemma 3 12B 实验在 **Google Colab G4 (96GB RAM)** 上完成。
    *   使用了 4-bit NF4 量化以降低显存占用。
*   **训练时长**：
    *   TinyLlama 4 领域总训练时间约为 **485 分钟**（约 8 小时）。
    *   单个领域（如 Chat）在 TinyLlama 上耗时约 49 分钟，Math 领域约 202 分钟。
*   **推理优化**：提出了“叠加 LLM（Superposition LLM）”原则，支持将冻结堆栈离线存储在磁盘，仅根据路由器预测按需加载，实现常数级的 GPU 显存占用。

### 5. 实验数量与充分性
*   **实验规模**：论文涵盖了从 1.1B 到 12B 不同规模的模型，并进行了多达 10 个堆栈的持续学习实验。
*   **消融与边界实验**：
    *   **零空间投影消融**：对比了有无投影下的干扰矩阵，证明了正交约束的有效性。
    *   **PSN 预训练实验**：在随机初始化模型上测试，证明了该架构依赖于预训练的几何结构。
    *   **强化学习实验**：测试了 DPO/GRPO 与堆栈架构的兼容性。
*   **客观性**：实验设计较为严谨，通过 Loss 曲线、干扰矩阵和标准化 Benchmark 多维度评估，不仅展示了成功案例，也诚实记录了 GRPO 训练不稳等失败教训。

### 6. 主要结论与发现
*   **认知原语发现（核心贡献）**：微调堆栈学习的是**可迁移的认知原语**（如指令遵循、逻辑结构、思维链），而非单纯的领域知识。证据是：97% 的医疗提示词被路由到了“聊天+数学”堆栈，尽管这两个堆栈从未见过医疗数据。
*   **性能提升**：MoE-LoRA 的收敛速度比单 LoRA 快 **2.5 倍**；残差提升显著降低了验证集 Loss。
*   **零遗忘**：通过零空间投影和元路由，模型在独立评估旧领域时实现了**零遗忘**，并解决了堆栈累积导致的量级爆炸问题。

### 7. 优点与亮点
*   **真正的模块化**：实现了领域能力的“插件化”，支持独立更新和按需组合。
*   **数学保障的抗遗忘**：不同于传统的正则化方法，零空间投影提供了硬性的几何约束。
*   **推理效率**：磁盘卸载（Disk-offloading）机制允许在有限显存下运行包含无限领域能力的模型。
*   **深刻的洞察**：重新定义了微调的本质，即注入可组合的认知能力而非简单的知识检索。

### 8. 不足与局限
*   **推理延迟**：每个 Token 需要流经所有加载的冻结堆栈，虽然显存占用低，但增加了计算延迟。
*   **数据敏感性**：系统对训练顺序和数据集质量高度敏感，数据污染（如 Chat 数据中混入代码）会导致后续领域训练崩溃。
*   **预训练依赖**：无法从零开始训练，必须依赖已经具备相干隐藏状态几何结构的预训练基座。
*   **容量上限**：随着领域增加，隐藏层维度的子空间可能会被耗尽（尽管在 12B+ 模型中这还不是即时威胁）。
