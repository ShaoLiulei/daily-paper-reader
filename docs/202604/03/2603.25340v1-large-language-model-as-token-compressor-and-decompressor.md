## 摘要
在本文中，我们提出了一个新颖的见解：现成的大语言模型（LLM）可以充当出色的 Token 压缩器和解压器。为了证明这一点，我们设计了一个自表达自动编码学习框架，通过微调预训练的 LLM，将长文本转换为一种由离散、变长潜码组成的紧凑内部语言（称为 Z-tokens），并能从中精确地重建原始文本。所生成的表示具有内容自适应性：通过轻量级的基于 LoRA 的适配器头，语义密集的片段会分配到更多的 Z-tokens，而冗余或可预测的区域则会被大幅压缩。实验表明，我们的方法在 Wikipedia、CNN/DailyMail、HotpotQA 和 Qulac 风格的长查询数据集上实现了高达 18 倍的 Token 缩减，同时保持了重建保真度和下游任务性能。这种简单而有效的设计支持包括提示词压缩和直接在 Z-token 空间中进行自回归生成在内的多种应用，为实现 Token 高效的长上下文推理提供了一条潜在路径。

## Abstract
In this paper, we establish the novel insight that an off-the-shelf LLM can function as an excellent token compressor and decompressor. To demonstrate, we design a self-expressive autoencoding learning framework fine-tunes a pretrained LLM to translate long texts into a compact internal language of discrete, variable-length latent codes, termed Z-tokens, and to reconstruct the original text exactly from them. The resulting representation is content-adaptive: semantically dense segments receive more Z-tokens, while redundant or predictable regions are aggressively compressed, via lightweight LoRA-based adapter heads. Empirically, our method achieves up to 18 times token reduction on Wikipedia, CNN/DailyMail, HotpotQA, and Qulac-style long-query datasets, while preserving reconstruction fidelity and downstream performance. This simple yet effective design supports applications including prompt compression and autoregressive generation directly in the Z-token space, offering a potential pathway toward token-efficient long-context reasoning.

### 2. 方法论
*   **核心思想**：利用 LLM 自身的语义知识进行“自表达”压缩。将输入文本 $X$ 映射为离散的潜码序列 $Z$（Z-tokens），并能从 $Z$ 精确还原 $X$ 或直接进行推理。
*   **关键技术细节**：
    *   **变长自回归压缩**：不同于以往固定长度的压缩，模型根据内容密度动态决定 Z-token 数量。语义复杂处分配更多 Token，冗余处则激进压缩。
    *   **离散化瓶颈**：扩展原词表，加入专用 Z-vocabulary。使用 **Gumbel-Softmax** 估计器配合 **Pass-through** 技巧，解决离散符号在端到端训练中的梯度回传问题。
    *   **滑动窗口压缩**：针对超长文本，采用带重叠的滑动窗口，并通过一致性约束损失（Cosine Similarity）确保相邻窗口间的语义衔接。
    *   **双重解压范式**：
        1.  **作为推理器**：直接从 Z-tokens 生成下游任务答案（如 QA）。
        2.  **作为重构器**：先在 Z-token 抽象空间完成逻辑推理，再将结果还原为自然语言。
    *   **训练策略**：采用 LoRA 轻量化微调，并引入 **Schedule Sampling（计划采样）** 策略来缓解自回归解码中的曝光偏差（Exposure Bias）。

*   **Z-token 的多义性**：发现 Z-tokens 并非简单的 1:1 映射，而是具有“多义性”的抽象语义单元，其具体含义取决于上下文，这证明了模型学习到了一种高效的内部语言。

### 7. 优点
*   **内容自适应**：变长压缩机制比固定比例压缩更符合自然语言的逻辑。
*   **高保真度**：通过自编码框架确保了压缩过程中的信息无损或低损。
*   **可解释性**：离散的 Z-tokens 相比连续向量更具可解释性，且支持直接在潜空间进行“思考”和推理。
*   **即插即用**：基于 LoRA 的设计使其易于适配现有的预训练 LLM。

### 8. 不足与局限
*   **长程依赖协调**：虽然使用了滑动窗口，但在处理极长文档时，如何实现跨窗口的全局 Z-token 协调仍有提升空间。

*   **模型规模限制**：实验主要集中在 4B 以下的中小规模模型，在超大规模模型（如 70B+）上的表现尚未验证。
