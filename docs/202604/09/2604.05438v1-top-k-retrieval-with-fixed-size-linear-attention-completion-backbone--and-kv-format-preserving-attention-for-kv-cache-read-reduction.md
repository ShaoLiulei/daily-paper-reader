## 摘要
长上下文生成日益受到解码时键值（KV）缓存传输流量的限制，特别是当 KV 缓存被卸载到 GPU 显存之外时。查询感知检索（如 Top-K 选择）通过仅加载 KV 对的子集来减少此类流量，但当注意力权重分散在未检索到的标记（tokens）上时，对该子集进行 Softmax 重新归一化会引入偏差。我们提出了一种检索-补全注意力模块，该模块保持骨干网络权重和 KV 缓存格式不变。对于每个查询，我们计算针对 sink/tail 锚点和查询相关的 Top-K 检索标记的精确注意力，并使用预填充阶段计算的固定大小特征图摘要来估计剩余中间区域的分子和分母。我们在未归一化域中累加精确贡献和估计贡献，并进行单次归一化，从而在不增加额外注意力端 KV 读取的情况下恢复缺失的 Softmax 权重。在长上下文基准测试中，所提方法在相同的等效标记读取预算下优于仅采用选择策略的 Top-K，且在高熵注意力头中增益最为显著。

## Abstract
Long-context generation is increasingly limited by decode-time key-value (KV) cache traffic, particularly when KV is offloaded beyond GPU memory. Query-aware retrieval (e.g., Top-K selection) reduces this traffic by loading only a subset of KV pairs, but renormalizing the softmax over the subset introduces bias when attention mass is spread over unretrieved tokens. We propose a retrieval-completion attention module that keeps backbone weights and the KV-cache format unchanged. For each query, we compute exact attention over sink/tail anchors and the query-dependent retrieved Top-K tokens, and estimate the remaining mid-region numerator and denominator using a fixed-size feature-map summary computed at prefill time. We add the exact and estimated contributions in the unnormalized domain and apply a single normalization, recovering the missing softmax mass without additional attention-side KV reads. Across long-context benchmarks, the proposed method improves over selection-only Top-K at matched token-equivalent read budgets, with the largest gains in high-entropy heads.

### 2. 方法论
*   **核心思想**：将注意力计算分为“精确部分”和“估计部分”。精确部分处理关键令牌，估计部分利用预计算的固定大小摘要处理剩余令牌。
*   **关键技术细节**：
    *   **分区策略**：将 KV 缓存分为锚点区（Sink 和 Tail 令牌，始终精确读取）和中间区（Mid Region）。
    *   **线性补全缓存**：在预填充（Prefill）阶段，利用学习到的正特征图（Positive Feature Maps）为中间区生成固定大小的摘要（类似于线性注意力）。
    *   **单向减法（Subtractive Completion）**：解码时，从中间区摘要中减去 Top-K 检索到的令牌在特征空间中的贡献，确保补全项仅针对“未被检索”的残差部分。
    *   **统一归一化**：在非归一化域（Unnormalized Domain）合并精确项和补全项的分子/分母，最后执行单次归一化，从而纠正 Softmax 偏差。
*   **算法流程**：预填充生成摘要 -> 解码时检索 Top-K -> 计算精确项 -> 减法更新摘要 -> 计算补全项 -> 合并并归一化。

### 6. 主要结论与发现
*   **精度提升**：在相同的 KV 读取预算下，带补全的 Top-K 显著优于纯 Top-K 检索，尤其在 Llama 模型上表现突出。

*   **非侵入性**：不需要重新训练骨干模型，也不改变 KV 缓存的存储格式，对现有推理引擎友好。
*   **数学完备性**：通过非归一化域合并，从理论上解决了子集归一化导致的概率质量丢失问题。
*   **开销可控**：补全缓存的大小固定，其读取成本随生成长度增加而迅速摊销。

### 8. 不足与局限
*   **预处理依赖**：需要针对每个模型进行特征图蒸馏，且特征图与特定的上下文长度绑定。
*   **计算开销**：虽然减少了 I/O，但增加了特征图映射和减法操作的计算量，在计算受限（Compute-bound）的场景下可能不划算。

*   **检索器假设**：实验主要基于理想的穷举 Top-K，实际应用中若配合近似最近邻搜索（ANNS），其端到端表现仍需进一步验证。
