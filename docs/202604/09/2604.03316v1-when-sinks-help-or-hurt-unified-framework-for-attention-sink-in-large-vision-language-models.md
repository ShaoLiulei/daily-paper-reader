## 摘要
注意力汇聚（Attention sinks）被定义为吸引不成比例的大量注意力的 Token。虽然这些现象在单模态 Transformer 中已有研究，但它们在大语言视觉模型（LVLM）中的跨模态影响在很大程度上仍未被探索：它们是冗余的伪影，还是不可或缺的全局先验？本文首先将视觉汇聚分为两个不同的类别：从视觉编码器传播而来的 ViT 产生汇聚（V-sinks），以及在 LLM 深层中产生的 LLM 产生汇聚（L-sinks）。基于这一新定义，我们的分析揭示了一个基本的性能权衡：虽然汇聚能有效地编码全局场景级先验，但其主导地位可能会抑制局部感知所需的细粒度视觉证据。此外，我们识别出了调节这些汇聚对下游性能影响最显著的特定功能层。为了利用这些见解，我们提出了逐层汇聚门控（Layer-wise Sink Gating, LSG），这是一个轻量级、即插即用的模块，能够动态缩放 V-sink 与其余视觉 Token 的注意力贡献。LSG 通过标准的下一个 Token 预测进行训练，无需特定任务的监督，同时保持 LVLM 主干网络冻结。在大多数层中，LSG 在代表性的多模态基准测试上均取得了改进，有效地平衡了全局推理与精确的局部证据。

## Abstract
Attention sinks are defined as tokens that attract disproportionate attention. While these have been studied in single modality transformers, their cross-modal impact in Large Vision-Language Models (LVLM) remains largely unexplored: are they redundant artifacts or essential global priors? This paper first categorizes visual sinks into two distinct categories: ViT-emerged sinks (V-sinks), which propagate from the vision encoder, and LLM-emerged sinks (L-sinks), which arise within deep LLM layers. Based on the new definition, our analysis reveals a fundamental performance trade-off: while sinks effectively encode global scene-level priors, their dominance can suppress the fine-grained visual evidence required for local perception. Furthermore, we identify specific functional layers where modulating these sinks most significantly impacts downstream performance. To leverage these insights, we propose Layer-wise Sink Gating (LSG), a lightweight, plug-and-play module that dynamically scales the attention contributions of V-sink and the rest visual tokens. LSG is trained via standard next-token prediction, requiring no task-specific supervision while keeping the LVLM backbone frozen. In most layers, LSG yields improvements on representative multimodal benchmarks, effectively balancing global reasoning and precise local evidence.

*   **研究动机**：在纯文本或纯视觉模型中，Sink Token 已被研究，但在多模态 LVLM 中，它们究竟是无用的“伪影”（Artifacts），还是携带关键全局信息的“先验”（Priors），目前尚无定论。
*   **核心问题**：这些 Sink Token 从何而来？它们编码了什么信息？它们对下游任务（全局推理 vs. 局部感知）有何影响？

## 2. 方法论
论文提出了一个统一的分析框架和一种动态调节机制：
*   **Sink 分类**：
    *   **V-sinks**：源自视觉编码器（如 ViT），通过投影层进入 LLM，表现为高范数（High-norm）特征。
    *   **L-sinks**：在 LLM 内部深层产生，表现为特定维度上的巨大激活值。
*   **核心思想**：Sink Token 编码全局信息，但过度主导注意力会抑制局部细节。因此，需要根据任务动态调节其权重。
*   **关键技术：层级汇聚门控（LSG）**：
    *   **模块设计**：在 LLM 的自注意力层中插入轻量级的 2 层 MLP 门控模块。
    *   **输入信号**：使用当前层最后一个 Token 的隐藏状态（$h_{last}^\ell$）作为输入，因为它聚合了视觉上下文和查询语义。
    *   **调节机制**：门控模块预测缩放因子 $\rho$，动态调整 V-sink 与普通视觉 Token 的 Key 向量大小，从而改变注意力分布。
    *   **训练流程**：保持 LVLM 主干冻结，仅使用标准的**下一个 Token 预测（NTP）**损失在通用多模态数据上训练门控模块，无需任务特定监督。

## 6. 主要结论与发现
*   **信息编码**：V-sinks 和 L-sinks 均稳定编码全局场景属性（如物体总数），且这种信息在 LLM 深层中得以保留。
*   **性能权衡**：增强 Sink 注意力有助于逻辑推理任务，但会显著损害需要精确局部证据的任务（如细粒度计数、距离估计）。
*   **层级特性**：调节效果在中间层（第 4-20 层）最为显著，因为这是跨模态信息交换最活跃的阶段。
*   **LSG 效果**：LSG 能够根据输入自动识别任务类型，在细粒度任务中抑制 Sink，在推理任务中适度保留 Sink，从而实现全方位的性能提升。

## 7. 优点
*   **理论深刻**：首次统一了大模型中两种不同来源的视觉汇聚点，并厘清了它们的形成机制。
*   **即插即用**：LSG 模块极轻量，不需要重新训练昂贵的 LVLM 主干，易于集成。
*   **任务自适应**：通过 NTP 训练实现了无需标签的任务感知调节，解决了“全局 vs 局部”的性能矛盾。

## 8. 不足与局限
*   **堆叠效应递减**：独立训练的门控模块在简单堆叠时存在“子加性”效应，即多个模块组合的效果低于各模块增量之和，联合训练（Joint Training）的稳定性仍有提升空间。
*   **阈值敏感性**：识别 Sink Token 依赖于特定的激活阈值 $\tau$，虽然文中证明了其稳定性，但在全新架构上可能需要重新校准。
*   **训练数据规模**：目前仅在 10K 数据上验证，若在更大规模、更多样化的指令微调数据上训练，可能会有更强的泛化表现。
