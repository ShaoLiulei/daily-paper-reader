## 摘要
大语言模型 (LLMs) 将海量的世界知识内化为参数化记忆，但不可避免地继承了源语料库的陈旧性和错误。因此，确保这些内部表示的可靠性和可塑性对于实现可信的现实世界部署至关重要。知识编辑提供了一种关键范式，可以在无需重新训练的情况下对记忆进行手术式修改。然而，尽管近期的编辑器在标准基准测试中表现出极高的成功率，但现有的评估框架（依赖于特定提示条件下的输出评估）是否能可靠地验证真实的记忆修改仍存疑问。在这项工作中，我们引入了一个简单的诊断框架，让模型在更贴近现实应用环境的上下文学习 (ICL) 设置下进行判别性自我评估，旨在专门审视由记忆修改引起的细微行为差异。这种探测揭示了一种普遍存在的“表面顺从” (Surface Compliance) 现象，即编辑器仅通过模仿目标输出来获得高基准分数，而未能在结构上重写内部信念。此外，我们发现递归修改会积累表示残留，引发认知不稳定，并永久性地降低模型记忆状态的可逆性。这些见解强调了当前编辑范式的风险，并突出了稳健的记忆修改在构建可信、长期可持续的 LLM 系统中的关键作用。代码可在 https://github.com/XiaojieGu/SA-MCQ 获取。

## Abstract
Large Language Models (LLMs) internalize vast world knowledge as parametric memory, yet inevitably inherit the staleness and errors of their source corpora. Consequently, ensuring the reliability and malleability of these internal representations is imperative for trustworthy real-world deployment. Knowledge editing offers a pivotal paradigm for surgically modifying memory without retraining. However, while recent editors demonstrate high success rates on standard benchmarks, it remains questionable whether current evaluation frameworks that rely on assessing output under specific prompting conditions can reliably authenticate genuine memory modification. In this work, we introduce a simple diagnostic framework that subjects models to discriminative self-assessment under in-context learning (ICL) settings that better reflect real-world application environments, specifically designed to scrutinize the subtle behavioral nuances induced by memory modifications. This probing reveals a pervasive phenomenon of Surface Compliance, where editors achieve high benchmark scores by merely mimicking target outputs without structurally overwriting internal beliefs. Moreover, we find that recursive modifications accumulate representational residues, triggering cognitive instability and permanently diminishing the reversibility of the model's memory state. These insights underscore the risks of current editing paradigms and highlight the pivotal role of robust memory modification in building trustworthy, long-term sustainable LLM systems. Code is available at https://github.com/XiaojieGu/SA-MCQ.

### 1. 核心问题与研究动机
*   **研究背景**：LLM 的参数化记忆具有静态性，容易过时或包含错误。知识编辑（Knowledge Editing, KE）旨在手术式地修改特定记忆而不影响其他知识。
*   **核心问题**：现有的评估指标（如 Exact Match, LLM-as-judge）主要关注模型在特定提示下能否输出目标文本。作者质疑：**模型输出正确答案是否意味着它真正“学会”并重写了内部记忆？**
*   **研究动机**：揭示“表面顺从”（Surface Compliance）现象，即模型虽然在生成任务中表现良好，但在判别式测试中仍持有原始错误信念。

### 2. 方法论
*   **核心思想**：引入 **SA-MCQ（Self-Assessment Multiple Choice Question）** 框架，通过判别式压力测试来探测模型的真实内部信念。
*   **关键技术细节**：
    *   **判别式评估**：将原始答案、编辑后的目标答案以及“不确定”选项同时呈现，强迫模型进行选择，而非简单的文本补全。
    *   **似然边际（Likelihood Margin）**：通过计算目标答案与原始答案之间的对数似然差异，量化概率分布的偏移。
    *   **外部证据刺激**：设计了四种上下文证据来模拟真实应用环境：
        1.  **参数化证据 (PE)**：支持原始错误记忆的文本。
        2.  **黄金证据 (GE)**：支持编辑目标答案的文本。
        3.  **无关证据 (IE)**：与任务无关的噪声干扰。
        4.  **反事实证据 (CE)**：与原始记忆和目标答案都冲突的错误信息。
    *   **逻辑验证**：使用 NLI 模型（DeBERTa）确保生成的证据与答案之间存在严格的逻辑蕴含关系。

### 3. 实验设计
*   **数据集**：主要使用 **ZsRE**（零样本关系抽取）数据集，因其包含丰富的反事实标注。
*   **对比方法**：选取了三种主流编辑器：**AlphaEdit**（空间约束更新）、**RLEdit**（强化学习驱动）和 **UltraEdit**（轻量级控制器）。
*   **基准模型**：LLaMA-3-8B-Instruct 和 Qwen2.5-7B-Instruct。
*   **评估场景**：
    *   传统指标对比（EM w/ TF, EM w/o TF, LLM-as-judge）。
    *   SA-MCQ 压力测试。
    *   多轮递归编辑（事实 -> 反事实 -> 事实），观察记忆的可逆性和稳定性。
    *   通用能力测试（MMLU, GLUE 等）以监测副作用。

### 4. 资源与算力
*   **硬件环境**：实验在单张 **NVIDIA A800 GPU** 上完成。
*   **算力细节**：
    *   模型规模限制在 8B 参数以下。

    *   评估效率方面，SA-MCQ 比 LLM-as-judge 快约 700 倍以上。

### 5. 实验数量与充分性
*   **实验规模**：使用了 1000 个经过严格筛选的测试样本（确保证据逻辑一致）。
*   **充分性评价**：实验设计非常全面。不仅对比了多种编辑器和模型，还通过多轮编辑探讨了记忆的长期演变。作者还进行了敏感性分析（如选项顺序、提示词变体），确保了实验结果的客观性和公平性。

### 6. 主要结论与发现
*   **表面顺从普遍存在**：许多编辑器在传统指标上得分很高，但在 SA-MCQ 中却暴露出并未真正修改内部信念，模型只是被提示词“诱导”输出了目标词。
*   **认知不稳定**：编辑操作往往会破坏模型的内部稳定性，导致模型在面对冲突时更容易陷入“不确定”状态。
*   **上下文超敏感性**：编辑后的模型对外部证据极度敏感，反事实证据可以轻易抑制编辑效果，使其退回到原始状态。
*   **表征残留与不可逆性**：递归编辑（反复修改同一知识）会积累“表征残留”，导致模型性能逐轮下降，且无法完全恢复到初始的准确度。

### 7. 优点
*   **诊断视角独特**：首次系统性地定义并量化了知识编辑中的“表面顺从”问题。
*   **评估框架高效且严谨**：SA-MCQ 既考虑了判别能力，又通过引入“不确定”选项捕捉了模型的认知冲突。
*   **揭示了长期风险**：通过多轮编辑实验，指出了当前编辑范式在构建可持续进化系统方面的根本缺陷。

### 8. 不足与局限
*   **模型规模受限**：由于算力限制，实验未能在 70B 或更大规模的模型上验证。
*   **任务类型单一**：主要集中在短文本 QA 和关系抽取，未涉及长文本生成或复杂逻辑推理中的知识编辑。
*   **依赖外部模型**：生成高质量证据链仍需依赖更强大的外部模型（如 DeepSeek-V3），这在一定程度上增加了评估流程的复杂性。
