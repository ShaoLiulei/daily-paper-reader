## 摘要
大语言模型通过扩展能力以在通用场景下运行取得了巨大成功，但解释性方法的发展却相对滞后。当前机械解释性（mechanistic interpretability）的趋势是在受控设置下对特定行为提供精确解释，而这些解释往往难以泛化，或者对于大规模研究而言资源消耗过高。在本文中，我们提出通过利用代码的结构化特性，在 Java 代码数据集中挖掘补全场景，从而研究大语言模型中的重复行为。我们收集了注意力头中生成的注意力模式，证明它们是模型组件全局可解释性的可扩展信号。我们展示了视觉模型为大规模分析注意力模式提供了一个充满前景的方向。为此，我们引入了注意力模式-掩码自编码器（AP-MAE），这是一种基于 Vision Transformer 的模型，能够高效重建被掩码的注意力模式。在 StarCoder2 上的实验表明，AP-MAE 能够：(i) 高精度重建掩码注意力模式；(ii) 在未见模型上表现出极小的性能退化，具有良好的泛化性；(iii) 揭示跨推理过程的循环模式；(iv) 在无需访问地面真值（ground truth）的情况下预测生成结果是否正确，准确率在 55% 到 70% 之间（视任务而定）；(v) 实现有针对性的干预，选择性应用时可提升 13.6% 的准确率，但过度应用会导致模型崩溃。这些结果确立了注意力模式作为可解释性可扩展信号的地位，并证明了 AP-MAE 为大语言模型的分析与干预提供了可迁移的基础。除了其独立价值外，AP-MAE 还可以作为一种筛选程序来指导细粒度的机械方法。我们开源了代码和模型，以支持大规模可解释性领域的未来研究。

## Abstract
Large language models have found success by scaling up capabilities to work in general settings. The same can unfortunately not be said for interpretability methods. The current trend in mechanistic interpretability is to provide precise explanations of specific behaviors in controlled settings. These often do not generalize, or are too resource intensive for larger studies. In this work we propose to study repeated behaviors in large language models by mining completion scenarios in Java code datasets, through exploiting the structured nature of code. We collect the attention patterns generated in the attention heads to demonstrate that they are scalable signals for global interpretability of model components. We show that vision models offer a promising direction for analyzing attention patterns at scale. To demonstrate this, we introduce the Attention Pattern - Masked Autoencoder(AP-MAE), a vision transformer-based model that efficiently reconstructs masked attention patterns. Experiments on StarCoder2 show that AP-MAE (i) reconstructs masked attention patterns with high accuracy, (ii) generalizes across unseen models with minimal degradation, (iii) reveals recurring patterns across inferences, (iv) predicts whether a generation will be correct without access to ground truth, with accuracies ranging from 55% to 70% depending on the task, and (v) enables targeted interventions that increase accuracy by 13.6% when applied selectively, but cause collapse when applied excessively. These results establish attention patterns as a scalable signal for interpretability and demonstrate that AP-MAE provides a transferable foundation for both analysis and intervention in large language models. Beyond its standalone value, AP-MAE also serves as a selection procedure to guide fine-grained mechanistic approaches. We release code and models to support future work in large-scale interpretability.

#### 1. 核心问题与整体含义
论文针对当前**机械可解释性（Mechanistic Interpretability）**研究中的瓶颈提出解决方案。目前的方法（如电路发现、稀疏自编码器等）虽然能提供精确解释，但通常局限于人工设计的受控场景，且计算成本极高，难以扩展到大规模模型或复杂的真实数据。

本研究的核心动机是：**注意力模式（Attention Patterns）**作为 Transformer 混合信息的核心机制，包含了丰富的模型行为信号。通过将注意力模式视为二维图像信号，并利用视觉模型进行大规模自动化挖掘，可以更高效地识别模型在处理真实世界任务（如代码补全）时的重复行为和关键组件。

#### 2. 方法论：AP-MAE
论文提出了 **AP-MAE (Attention Pattern – Masked Autoencoder)**，其核心思想是将注意力矩阵作为单通道图像处理：
*   **架构设计**：基于 Vision Transformer (ViT-L) 架构。由于 Decoder-only 模型的注意力矩阵是下三角的，研究者移除了右上角数据，并对对角线补丁进行了特殊填充。
*   **关键技术：对数缩放（Logarithmic Scaling）**：由于注意力权重通常集中在极少数 token 上（Attention Sink 现象），直接训练会导致损失函数被高值主导。通过对注意力模式进行自然对数缩放，平衡了数值分布，使模型能够捕捉到细微的结构特征。
*   **流程**：
    1.  从目标 LLM 中提取注意力模式。
    2.  使用 AP-MAE 进行掩码重建训练（掩码率 0.5）。
    3.  利用训练好的 Encoder 提取 [CLS] token 的嵌入表示。
    4.  通过聚类（UMAP + HDBSCAN）发现重复出现的模式。
    5.  利用 CatBoost 分类器结合 SHAP 值，根据注意力模式预测生成结果的正确性。

#### 3. 实验设计
*   **目标模型**：StarCoder2 系列（3B, 7B, 15B）。
*   **数据集**：**The Heap**，这是一个针对 StarCoder2 训练集进行了严格去重的 Java 代码数据集，确保了实验的客观性。
*   **任务场景**：设计了 11 个任务，包括：
    *   **标识符（Identifiers）**：模拟 IOI 电路。
    *   **字面量（Literals）**：布尔值、字符串、数字。
    *   **运算符（Operators）**：布尔、算术、赋值运算符。
    *   **结构补全**：语句结尾（End of Line）、闭合括号。
    *   **基准（Baselines）**：随机掩码任务和纯噪声输入任务。
*   **对比与评估**：进行了跨模型泛化评估（在 3B 上训练，在 15B 上测试）以及针对干预效果的消融对比。

#### 4. 资源与算力
*   **硬件**：使用了 **8 张 NVIDIA A100 GPU**。
*   **训练细节**：总训练步数为 150,000 个 batch，使用了约 7200 万个注意力模式样本。
*   **时长**：总训练时间**少于 100 GPU 小时**。
*   **部署性**：论文指出，AP-MAE 模型较小（Encoder 101M, Decoder 25M），推理时可与目标 LLM 共同部署在单张 A100 上。

#### 5. 实验数量与充分性
实验设计非常充分且具有多维度视角：
*   **规模性**：涵盖了从 3B 到 15B 不同参数规模的模型。
*   **泛化性实验**：通过跨模型评估证明了 AP-MAE 学习到的是通用的注意力特征，而非特定模型的过拟合。
*   **消融实验**：明确对比了有无“对数缩放”对重建效果的影响（图 1）。
*   **统计显著性**：分类任务采用了 10 折交叉验证，并提供了 95% 置信区间。
*   **干预实验**：通过对数千次推理进行“头置零（Zeroing heads）”操作，验证了 SHAP 值定位关键组件的有效性。

#### 6. 主要结论与发现
*   **高效重建**：AP-MAE 能以极低误差重建掩码注意力模式，并能跨模型迁移。
*   **正确性预测**：仅凭注意力模式，分类器就能以 **55% - 70%** 的准确率预判 LLM 的生成是否正确，且无需参考标准答案。
*   **模式分布**：随着模型规模增大，注意力头表现出更强的专业化，少数特定的头对预测正确性起决定性作用。
*   **干预收益**：通过 SHAP 值识别并关闭“干扰”头，可将特定任务的下个 token 预测准确率提升 **13.6%**。
*   **资源竞争**：实验观察到，移除少量头能提升性能，但超过阈值会导致模型崩溃，这暗示了模型内部存在多个竞争电路。

#### 7. 优点
*   **可扩展性**：将复杂的机械解释性问题转化为视觉模式识别问题，极大地降低了分析成本。
*   **自动化程度高**：无需人工设计复杂的探测任务，通过代码解析器即可自动挖掘大规模任务场景。
*   **跨模型能力**：证明了注意力模式在不同规模模型间具有相似的几何特征，具有很强的通用性。

#### 8. 不足与局限
*   **输入长度限制**：受限于视觉模型的输入规格，实验固定了 256 tokens 的上下文长度，未探讨长文本下的模式演变。
*   **领域局限**：目前仅在 Java 代码上验证，虽然代码具有结构化优势，但在自然语言等非结构化领域的表现尚待验证。
*   **解释深度**：AP-MAE 更多是作为一种“定位工具”，能告诉研究者“哪里重要”，但无法像电路分析那样给出“为什么重要”的底层逻辑解释。
*   **解析器依赖**：在扩展到自然语言时，可能面临概率解析器带来的不确定性风险。
