## 摘要
视频大语言模型 (VideoLLMs) 在视频理解方面展现出了卓越的能力，但海量的输入视频 Token 给部署带来了巨大的计算负担。现有方法主要在输入层级对视频 Token 进行剪枝，却忽略了视频和语言大模型 (LLMs) 中固有的信息结构。针对这一问题，我们提出了 HieraVid，这是一个层级化剪枝框架，能够逐步且动态地减少视觉冗余。基于视频具有“片段-帧”结构以及 LLM 内部单向传播多模态信息这两个观察结果，我们将剪枝分解为三个层级：1) 片段级，首先在时间上对视频 Token 进行分段并在空间上进行合并；2) 帧级，对同一片段内的相似帧进行联合剪枝以保持多样性；3) 层级级，随着 LLM 层数的增加，冗余在不损害性能的情况下逐渐减少。我们在四个广泛使用的视频理解基准测试上进行了大量实验，以全面评估 HieraVid 的有效性。值得注意的是，在仅保留 30% Token 的情况下，HieraVid 达到了新的最先进性能，同时分别保持了 LLaVA-Video-7B 和 LLaVA-OneVision-7B 98% 和 99% 以上的性能。

## Abstract
Video Large Language Models (VideoLLMs) have demonstrated impressive capabilities in video understanding, yet the massive number of input video tokens incurs a significant computational burden for deployment. Existing methods mainly prune video tokens at input level while neglecting the inherent information structure embedded in videos and large language models (LLMs). To address this, we propose HieraVid, a hierarchical pruning framework that progressively and dynamically reduces visual redundancy. Based on two observations that videos possess the segment-frame structure and LLMs internally propagate multi-modal information unidirectionally, we decompose pruning into three levels: 1) segment-level, where video tokens are first temporally segmented and spatially merged; 2) frame-level, where similar frames within the same segment are jointly pruned to preserve diversity; 3) layer-level, redundancy gradually shrinks as LLM layer increases w/o compromising performance. We conduct extensive experiments on four widely used video understanding benchmarks to comprehensively evaluate the effectiveness of HieraVid. Remarkably, with only 30% of tokens retained, HieraVid achieves new state-of-the-art performance, while maintaining over 98% and 99% of the performance of LLaVA-Video-7B and LLaVA-OneVision-7B, respectively.

#### 1. 核心问题与整体含义（研究动机和背景）
视频大语言模型（VideoLLMs）在理解动态内容方面表现出色，但其面临的核心瓶颈是**计算开销巨大**。由于视频帧数多，产生的视觉 Token 数量远超图像，而大语言模型（LLM）核心的自注意力机制具有平方复杂度，导致推理延迟和内存占用极高。
现有剪枝方法存在两个主要缺陷：
*   **忽视视频结构**：大多在输入端进行简单的空间或时间采样，忽略了视频固有的“片段-帧”语义结构。
*   **忽视模型内部特性**：未考虑 LLM 内部多模态信息流的单向传播特性（视觉信息随层数加深逐渐向指令 Token 聚合）。
**HieraVid** 的提出旨在通过一种**无需训练（Training-free）**的层级化剪枝框架，在大幅减少 Token 数量的同时，最大限度保留关键语义信息。

#### 2. 方法论：核心思想与关键技术
HieraVid 将剪枝过程分解为三个协同工作的层级：

*   **片段级合并（Segment-level Merging）**：
    *   **合并率引导的分段**：计算相邻帧之间对应位置 Token 的空间相似度，当重叠率低于阈值 $\beta$ 时划定语义边界，将视频切分为多个片段。
    *   **空间合并**：在每个片段内，对时间上静态、空间上冗余的 Token 进行合并，仅保留首个出现位置的代表性特征。
*   **帧级 DPP 剪枝（Frame-level DPP Pruning）**：
    *   **多样性最大化**：引入行列式点过程（DPP）算法，在每个片段内选择一组多样性最高的帧，避免信息重复。
    *   **指令相关性引导**：将视觉 Token 与最后一位指令 Token 的相关性分数融入 DPP 核矩阵，确保保留的 Token 既具多样性又与用户问题高度相关。
    *   **动态预算分配**：根据片段的丰富度动态分配剪枝比例，而非一刀切。
*   **层级级平衡（Layer-level Balancing）**：
    *   **多阶段逐步剪枝**：基于 LLM 逐层处理信息的特性，将模型划分为多个阶段（如 4 个阶段）。随着层数加深，逐步提高剪枝比例，平衡浅层的视觉感知与深层的语义推理。

*   **效率与精度平衡**：通过层级化设计，巧妙地解决了“浅层剪枝损性能，深层剪枝不减速”的矛盾。

#### 8. 不足与局限
*   **超参数依赖**：分段阈值 $\beta$ 和分配权重 $\lambda$ 可能需要针对不同风格的视频（如快节奏动作 vs. 慢节奏 VLOG）进行微调以达到最优效果。

*   **模型规模覆盖**：实验主要集中在 7B 规模的模型上，对于 72B 或更大规模的模型，其层级信息流特性是否完全一致尚待验证。
