## 摘要
脉冲神经网络 (SNN) 在严格功耗限制下需要实时处理时间稀疏数据流的应用中，展现出优于传统人工神经网络 (ANN) 的显著优势，这一概念被称为“类脑优势” (Neuromorphic Advantage)。然而，类脑硬件的有限可用性造成了巨大的仿真与硬件之间的鸿沟，阻碍了算法创新、软硬件协同设计以及成熟开源生态系统的发展。为了应对这一挑战，我们推出了 YANA (Yet Another Neuromorphic Accelerator)，这是一款基于 FPGA 的数字 SNN 加速器，旨在通过提供易于获取的类脑计算软硬件框架来弥合这一鸿沟。YANA 实现了五级事件驱动处理流水线，在通过点对点神经元连接支持任意 SNN 拓扑的同时，充分利用了时间与空间稀疏性。该架构采用了一种输入预处理方案，可在无缓冲区溢出风险的情况下保持每周期处理一个事件的稳定速度，并利用查找表进行泄漏计算，实现了硬件高效的事件驱动神经元更新。我们通过在 Spiking Heidelberg Digits 数据集上的实验展示了 YANA 的稀疏性利用能力，结果表明推理时间随空间和时间稀疏度水平呈近线性缩放。在易于获取的 AMD Kria KR260 平台上部署时，单个 YANA 核心仅消耗 740 个 LUT、918 个寄存器、7 个 BRAM 和 24 个 URAM，支持多达 $2^{17}$ 个突触和 $2^{10}$ 个神经元。我们将 YANA 框架作为开源项目发布，提供了一个用于训练、优化和部署 SNN 的端到端解决方案，并通过类脑中间表示 (NIR) 与现有的类脑计算工具集成。

## Abstract
Spiking Neural Networks (SNNs) promise significant advantages over conventional Artificial Neural Networks (ANNs) for applications requiring real-time processing of temporally sparse data streams under strict power constraints -- a concept known as the Neuromorphic Advantage. However, the limited availability of neuromorphic hardware creates a substantial simulation-to-hardware gap that impedes algorithmic innovation, hardware-software co-design, and the development of mature open-source ecosystems. To address this challenge, we introduce Yet Another Neuromorphic Accelerator (YANA), an FPGA-based digital SNN accelerator designed to bridge this gap by providing an accessible hardware and software framework for neuromorphic computing. YANA implements a five-stage, event-driven processing pipeline that fully exploits temporal and spatial sparsity while supporting arbitrary SNN topologies through point-to-point neuron connections. The architecture features an input preprocessing scheme that maintains steady event processing at one event per cycle without buffer overflow risks, and implements hardware-efficient event-driven neuron updates using lookup tables for leak calculations. We demonstrate YANA's sparsity exploitation capabilities through experiments on the Spiking Heidelberg Digits dataset, showing near-linear scaling of inference time with both spatial and temporal sparsity levels. Deployed on the accessible AMD Kria KR260 platform, a single YANA core utilizes 740 LUTs, 918 registers, 7 BRAMS and 24 URAMs, supporting up to $2^{17}$ synapses and $2^{10}$ neurons. We release the YANA framework as an open-source project, providing an end-to-end solution for training, optimizing, and deploying SNNs that integrates with existing neuromorphic computing tools through the Neuromorphic Intermediate Representation (NIR).

### 1. 核心问题与研究动机
*   **核心问题**：尽管 SNN 在理论上具有低功耗和实时处理稀疏数据的“类脑优势”，但由于缺乏易于获取且可编程的硬件平台，大多数研究停留在仿真阶段。这种“仿真-硬件鸿沟”阻碍了算法创新、软硬件协同设计以及开源生态的成熟。
*   **研究动机**：现有的 FPGA 加速器多采用时钟驱动（Clock-driven）而非事件驱动（Event-driven），且往往局限于顺序层级结构，无法支持复杂的递归拓扑。YANA 旨在提供一个全栈开源框架，让研究者能在廉价 FPGA 上验证任意拓扑的事件驱动 SNN。

### 2. 方法论：核心思想与技术细节
*   **五级事件驱动流水线**：包括输入（RX）、突触（Synapse）、神经元（Neuron）、轴突（Axon）和输出（TX）五个阶段。系统仅在事件到达时处理，平时处于空闲状态。
*   **输入预处理方案**：采用一种无需原始事件缓冲的机制，通过 BRAM 存储每个神经元的权重累加和，实现每周期处理一个事件的稳定吞吐量。
*   **延迟神经元更新（Deferred Updates）**：
    *   神经元仅在变为“活跃”（接收到事件）时才更新状态。
    *   **关键公式**：使用前向欧拉法求解 LIF 模型。为了避免在硬件中计算复杂的指数幂运算，YANA 使用**查找表（LUT）**预存不同时间间隔下的泄漏因子（Leak term），从而高效实现状态更新。
*   **支持任意拓扑**：通过点对点（Point-to-point）连接表实现，每个事件包包含目标核心、神经元和突触的索引，支持权重重用和高度剪枝的图结构。
*   **软件栈集成**：
    *   **YANA train**：基于 Norse 和 PyTorch，支持硬件感知训练（如量化和 LUT 泄漏模拟）。
    *   **YANA deploy**：利用**神经形态中间表示（NIR）**，将训练好的模型映射到硬件内存布局。
    *   **YANA runtime**：基于 PYNQ 框架，在 SoC 的处理系统（PS）上运行，控制 FPGA 逻辑。

*   **数据集**：使用 **Spiking Heidelberg Digits (SHD)** 语音数据集。
*   **实验场景**：
    *   部署了一个包含 100 个隐藏层 LIF 单元的网络。
    *   **Benchmark 重点**：测量推理延迟如何随**空间稀疏度**（通过权重剪枝）和**时间稀疏度**（通过丢弃输入事件）的变化而缩放。

### 5. 实验数量与充分性
*   **实验规模**：进行了 20 组样本的平均推理时间测量，覆盖了从 0% 到 90% 的空间剪枝率，以及不同等级的时间稀疏度。
*   **充分性评价**：实验充分证明了其“事件驱动”架构的有效性——推理时间随稀疏度增加而近乎线性下降。但实验目前仅限于单层隐藏层的简单网络，对于大规模多层网络或复杂递归结构的验证尚显不足。

### 6. 主要结论与发现
*   **稀疏性红利**：YANA 成功将 SHD 数据集（原始时长 500-1000ms）的推理时间缩短至 1ms 到 16ms 之间，证明了事件驱动流水线在处理稀疏数据时的极高效率。
*   **线性缩放**：推理延迟与非零权重数量和输入事件数量呈近线性关系，验证了硬件对时空稀疏性的充分利用。
*   **数值一致性**：通过硬件感知训练，仿真精度可以完美迁移至硬件部署。

### 7. 优点
*   **开源与兼容性**：支持 NIR 标准，能够轻松接入现有的类脑软件生态。
*   **极低资源消耗**：在低端 FPGA 上即可部署，门槛极低。
*   **灵活性**：点对点连接机制使其能够支持未来可能出现的各种非规则 SNN 拓扑。
*   **高效能**：通过 LUT 巧妙解决了硬件计算指数幂的难题。

*   **层类型支持有限**：目前主要支持全连接层，尚未原生支持卷积层（虽然架构上支持权重重用，但软件映射尚未完全实现）。
