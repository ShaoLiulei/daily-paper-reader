## 摘要
大语言模型通过扩展能力以在通用场景下运行取得了成功。然而，解释性方法的情况却并非如此。目前机械解释性（mechanistic interpretability）的趋势是在受控设置下对特定行为提供精确解释，但这些解释通常难以泛化，或者对于更大规模的研究而言资源消耗过高。在这项工作中，我们提出通过利用代码的结构化特性，在 Java 代码数据集中挖掘补全场景，从而研究大语言模型中的重复行为。我们收集注意力头中生成的注意力模式，以证明它们是模型组件全局可解释性的可扩展信号。我们展示了视觉模型为大规模分析注意力模式提供了一个充满前景的方向。为此，我们引入了注意力模式-掩码自编码器（AP-MAE），这是一种基于视觉 Transformer 的模型，能够高效地重建被掩码的注意力模式。在 StarCoder2 上的实验表明，AP-MAE (i) 以高精度重建掩码注意力模式，(ii) 在未见过的模型上表现出极小的泛化性能下降，(iii) 揭示了跨推理过程的循环模式，(iv) 在无需访问地面真值（ground truth）的情况下预测生成是否正确，准确率根据任务不同在 55% 到 70% 之间，(v) 支持有针对性的干预，选择性应用时可将准确率提高 13.6%，但过度应用时会导致性能崩溃。这些结果确立了注意力模式作为可解释性的可扩展信号，并证明了 AP-MAE 为大语言模型的分析和干预提供了可迁移的基础。除了其独立价值外，AP-MAE 还可以作为一种选择程序来指导细粒度的机械化方法。我们发布了代码和模型，以支持大规模可解释性领域的未来工作。

## Abstract
Large language models have found success by scaling up capabilities to work in general settings. The same can unfortunately not be said for interpretability methods. The current trend in mechanistic interpretability is to provide precise explanations of specific behaviors in controlled settings. These often do not generalize, or are too resource intensive for larger studies. In this work we propose to study repeated behaviors in large language models by mining completion scenarios in Java code datasets, through exploiting the structured nature of code. We collect the attention patterns generated in the attention heads to demonstrate that they are scalable signals for global interpretability of model components. We show that vision models offer a promising direction for analyzing attention patterns at scale. To demonstrate this, we introduce the Attention Pattern - Masked Autoencoder(AP-MAE), a vision transformer-based model that efficiently reconstructs masked attention patterns. Experiments on StarCoder2 show that AP-MAE (i) reconstructs masked attention patterns with high accuracy, (ii) generalizes across unseen models with minimal degradation, (iii) reveals recurring patterns across inferences, (iv) predicts whether a generation will be correct without access to ground truth, with accuracies ranging from 55% to 70% depending on the task, and (v) enables targeted interventions that increase accuracy by 13.6% when applied selectively, but cause collapse when applied excessively. These results establish attention patterns as a scalable signal for interpretability and demonstrate that AP-MAE provides a transferable foundation for both analysis and intervention in large language models. Beyond its standalone value, AP-MAE also serves as a selection procedure to guide fine-grained mechanistic approaches. We release code and models to support future work in large-scale interpretability.

#### 1. 核心问题与整体含义（研究动机和背景）
当前大语言模型（LLM）的**机械可解释性（Mechanistic Interpretability）**研究主要集中在受控环境下的特定行为（如发现微小电路），难以扩展到大规模、真实且多噪声的场景。此外，现有方法往往针对一维特征（如激活值），忽略了二维的**注意力模式（Attention Patterns）**中蕴含的丰富结构化信息。
本研究的动机在于：利用源代码（Java）的强结构化特性，通过视觉模型自动化地挖掘和分析 LLM 在大规模推理过程中的注意力模式，从而实现一种低成本、可扩展的全局可解释性分析框架。

#### 2. 方法论：核心思想与技术细节
论文提出了 **AP-MAE (Attention Pattern – Masked Autoencoder)**，其核心思想是将 LLM 的二维注意力矩阵视为单通道图像，利用计算机视觉中的掩码自编码技术进行特征提取。
*   **核心架构**：基于 ViT-L 架构，包含一个编码器（Encoder）和一个轻量化解码器（Decoder）。
*   **关键预处理（对数缩放）**：由于注意力权重通常集中在极少数 token 上（长尾分布），直接训练会导致损失函数被高值主导。作者引入了**自然对数缩放（Logarithmic Scaling）**，在保持单调性的同时平衡了权重的强度分布，这是模型收敛的关键。
*   **训练任务**：随机掩盖 50% 的注意力矩阵补丁（Patches），要求模型重建缺失部分。
*   **下游流程**：
    1.  **模式挖掘**：利用编码器的 `[CLS]` token 表示进行 UMAP 降维和 HDBSCAN 聚类，识别重复出现的注意力基元（如对角线、垂直条纹、方块结构）。
    2.  **正确性分类**：将各头的聚类标签作为特征，使用 CatBoost 分类器预测 LLM 的生成是否正确。
    3.  **干预实验**：基于 SHAP 值识别对正确性贡献最大的头，并在推理时将其贡献置零（Zeroing）。

#### 3. 实验设计
*   **目标模型**：StarCoder2 系列（3B, 7B, 15B）。
*   **数据集**：使用经过去重处理的 Java 代码数据集 *The Heap*，确保不包含模型预训练数据。
*   **任务场景**：设计了 11 类代码补全任务，包括标识符（Identifiers）、字面量（Literals）、运算符（Operators）、语句结尾（End of Line/Closing Bracket）以及随机掩码和纯噪声基准。
*   **对比与验证**：
    *   **跨模型验证**：在 3B 模型上训练的 AP-MAE 直接用于 7B/15B 模型的模式重建。
    *   **消融实验**：对比了有无对数缩放对重建效果的影响。
    *   **基准对比**：在干预实验中，对比了基于 SHAP 值的选择性置零与随机置零的效果。

*   **硬件**：使用了 **8 台 NVIDIA A100 GPU**。
*   **训练细节**：本地 Batch Size 为 60，共训练 150,000 个 batches（涉及约 7200 万个注意力模式）。
*   **时长**：总训练时间**少于 100 GPU 小时**。
*   **部署成本**：作者指出，AP-MAE 模型较小（编码器 101M，解码器 25M），推理时可与目标 LLM 共同部署在单块 A100 上。

#### 5. 实验数量与充分性
实验设计较为全面且具有说服力：
*   **规模覆盖**：涵盖了从 3B 到 15B 不同参数规模的模型，验证了方法的可扩展性。
*   **数据量**：使用了数千万个注意力模式进行训练，聚类分析涉及样本量高达 2.1 亿（15B 模型）。
*   **客观性**：通过 10 折交叉验证评估分类准确率，并使用 SHAP 值进行量化解释，避免了人工主观标注注意力模式的偏差。
*   **消融与迁移**：跨模型的泛化实验证明了该方法捕捉的是通用的注意力结构，而非特定模型的过拟合特征。

#### 6. 主要结论与发现
*   **高效重建与泛化**：AP-MAE 能高精度重建掩码模式，且具备极强的跨模型迁移能力，无需为每个新模型重新训练。
*   **模式多样性**：随着模型规模增大，注意力头表现出更高的专业化程度，产生更丰富的模式类别。
*   **正确性预判**：仅凭注意力模式（不看文本内容），分类器预测生成正确性的准确率可达 **55% - 70%**。
*   **性能提升**：通过 SHAP 值引导，移除少量“干扰”头可使特定任务（如行尾预测）的准确率提升 **13.6%**。
*   **临界崩溃**：发现模型存在“资源竞争”现象，移除关键头超过一定阈值后，模型性能会发生断崖式崩溃。

#### 7. 优点
*   **视角新颖**：将注意力模式视为图像，成功引入了成熟的视觉自监督学习方法解决 NLP 的解释性问题。
*   **自动化程度高**：摆脱了以往机械可解释性研究中依赖人工观察和启发式规则的束缚。
*   **实用性强**：不仅能用于分析，还能直接指导模型干预和性能优化，且计算开销相对较低。

#### 8. 不足与局限
*   **输入长度限制**：受限于视觉 Transformer 的固定输入尺寸，实验中将上下文统一截断为 256 tokens，未能探讨长文本下的模式演变。
*   **语言局限性**：目前仅在 Java 语言上验证，虽然代码具有结构化优势，但在自然语言等弱结构化数据上的表现尚待观察。
*   **缺乏底层因果解释**：AP-MAE 更多是识别“相关性”模式，虽然能定位关键头，但仍需结合更细粒度的电路分析来解释这些模式背后的具体逻辑。
*   **架构开销**：虽然比训练 LLM 便宜，但对于实时性要求极高的在线推理场景，运行一个额外的 ViT 编码器仍有一定延迟压力。
