## 摘要
视觉 Transformer (ViTs) 取得了最先进的性能，但受限于自注意力机制的 $O(N^2)$ 复杂度，使得高分辨率输入的推理成本高昂。为了解决这一瓶颈，Token 剪枝已成为加速推理的关键技术。大多数现有方法依赖 [CLS] token 来估计 patch 的重要性。然而，我们认为在语义表示尚不成熟的早期层中，[CLS] token 可能是不可靠的。因此，在早期层进行剪枝往往会导致重要性估计不准确以及不必要的信息损失。在这项工作中，我们提出了一种无需训练的 Token 重要性指标，即 Col-Ln，它源自 Rényi 熵，能够从网络的第一层开始识别信息丰富的 Token，从而在 Token 缩减中实现更可靠的剪枝。在 ViTs 和大型视觉语言模型 (LVLMs) 上的广泛实验表明，我们的方法在不同基准测试中始终优于最先进的剪枝方法。

## Abstract
Vision Transformers (ViTs) achieve state-of-the-art performance but suffer from the $O(N^2)$ complexity of self-attention, making inference costly for high-resolution inputs. To address this bottleneck, token pruning has emerged as a critical technique to accelerate inference. Most existing methods rely on the [CLS] token to estimate patch importance. However, we argue that the [CLS] token can be unreliable in early layers where semantic representations are still immature. As a result, pruning in the early layer often leads to inaccurate importance estimation and unnecessary information loss. In this work, we propose a training-free token importance metric, namely Col-Ln, which is derived from Rényi entropy that enables the identification of informative tokens from the first layer of the network, thereby enabling more reliable pruning in token reduction. Extensive experiments on ViTs and Large Vision-Language Models (LVLMs) demonstrate that our approach consistently outperforms state-of-the-art pruning methods across diverse benchmarks.

*   **研究动机**：现有的 Token 剪枝方法（如 EViT）主要依赖 `[CLS]` Token 的注意力权重作为衡量 Patch 重要性的指标。然而，作者发现 `[CLS]` Token 在网络的**早期层（如 0-3 层）语义尚未成熟**，其注意力分布往往是噪声或误导性的，导致错误地剪掉了关键的前景对象。这限制了剪枝只能在深层进行，无法在早期层实现更大幅度的计算节省。

### 2. 方法论：Col-Ln 指标
*   **核心思想**：放弃依赖单一的 `[CLS]` 代理，转而利用所有 Patch 之间的**集体共识（Collective Consensus）**。作者认为，信息量大的 Token 会吸引来自多个其他 Token 的集中注意力，而冗余 Token 接收到的注意力则较为分散。
*   **关键技术细节**：
    *   **Rényi 熵**：使用 Rényi 熵来量化注意力矩阵中每一列（即每个 Token 接收到的注意力分布）的集中程度。低熵意味着注意力高度集中（尖峰状），代表该 Token 重要。
    *   **Col-Ln 指标推导**：作者在数学上证明了，在特定条件下，最小化 Rényi 熵等价于最大化注意力矩阵的**列向 $\ell_n$ 范数（Column-wise $\ell_n$-norm）**。
    *   **算法流程**：
        1.  计算自注意力矩阵 $A$。
        2.  对 $A$ 的每一列计算 $\ell_n$ 范数（通常 $n \in [2, 4]$）。
        3.  根据范数大小对 Token 进行排序，保留得分最高的 $K$ 个 Token。
    *   **纠错机制（Correcting Mechanism）**：该指标既可以独立作为剪枝依据，也可以作为 `[CLS]` 指标的补充，用于“拯救”那些被 `[CLS]` 误判但具有高集体共识的 Token。
