## 摘要
视频大语言模型 (VideoLLMs) 在视频理解方面展现了出色的能力，但海量的输入视频 Token 给部署带来了沉重的计算负担。现有方法主要在输入层面剪枝视频 Token，而忽略了视频和语言模型 (LLMs) 中固有的信息结构。针对这一问题，我们提出了 HieraVid，这是一个逐步且动态减少视觉冗余的分层剪枝框架。基于视频具有“片段-帧”结构以及 LLM 内部单向传播多模态信息这两个观察结果，我们将剪枝分解为三个层面：1) 片段级，首先对视频 Token 进行时间分段和空间合并；2) 帧级，对同一片段内的相似帧进行联合剪枝以保持多样性；3) 层级，随着 LLM 层数的增加，在不损害性能的前提下逐渐减少冗余。我们在四个广泛使用的视频理解基准测试上进行了大量实验，以全面评估 HieraVid 的有效性。值得注意的是，在仅保留 30% Token 的情况下，HieraVid 达到了新的最先进性能，同时分别保持了 LLaVA-Video-7B 和 LLaVA-OneVision-7B 98% 和 99% 以上的性能。

## Abstract
Video Large Language Models (VideoLLMs) have demonstrated impressive capabilities in video understanding, yet the massive number of input video tokens incurs a significant computational burden for deployment. Existing methods mainly prune video tokens at input level while neglecting the inherent information structure embedded in videos and large language models (LLMs). To address this, we propose HieraVid, a hierarchical pruning framework that progressively and dynamically reduces visual redundancy. Based on two observations that videos possess the segment-frame structure and LLMs internally propagate multi-modal information unidirectionally, we decompose pruning into three levels: 1) segment-level, where video tokens are first temporally segmented and spatially merged; 2) frame-level, where similar frames within the same segment are jointly pruned to preserve diversity; 3) layer-level, redundancy gradually shrinks as LLM layer increases w/o compromising performance. We conduct extensive experiments on four widely used video understanding benchmarks to comprehensively evaluate the effectiveness of HieraVid. Remarkably, with only 30% of tokens retained, HieraVid achieves new state-of-the-art performance, while maintaining over 98% and 99% of the performance of LLaVA-Video-7B and LLaVA-OneVision-7B, respectively.

#### 1. 论文的核心问题与整体含义
视频大语言模型（VideoLLMs）在处理视频时，由于密集的帧采样会产生海量的视觉 Token。由于 LLM 中自注意力机制具有平方级计算复杂度，这些冗余 Token 导致了巨大的计算负担、内存消耗和推理延迟，尤其是在长视频处理场景下。
**研究动机**：现有的剪枝方法通常只在输入端进行简单空间剪枝，或在 LLM 内部固定层进行剪枝，忽略了视频特有的“片段-帧”语义结构，以及 LLM 内部多模态信息随层数加深而向指令 Token 聚集的单向传播特性。

#### 2. 论文提出的方法论
HieraVid 提出了一个**三层级（Hierarchical）**的动态剪枝框架，旨在实现计算效率与模型性能的最优权衡：

*   **片段级合并与分段（Segment-level Merging）**：
    *   **合并率引导的分段**：计算相邻帧之间对应位置 Token 的空间相似度，当重叠率低于阈值 $\beta$ 时划定语义边界，将视频切分为多个片段。
    *   **空间合并**：在每个片段内，对时间维度上高度相似的静态 Token 进行合并（取平均值），消除背景等静态区域的冗余。
*   **帧级多样性剪枝（Frame-level DPP Pruning）**：
    *   **动态预算分配**：根据片段与前后文的相似度，动态为每个片段分配剪枝预算（重要片段保留更多 Token）。
    *   **DPP 算法应用**：引入行列式点过程（Determinantal Point Process, DPP）来选择 Token。通过构建包含“视觉多样性”和“指令相关性”的核矩阵，筛选出既能代表片段特征又与用户指令高度相关的 Token 子集。
*   **层级平衡剪枝（Layer-level Balancing）**：
    *   **多阶段递进剪枝**：将 LLM 的 Transformer 层分为多个阶段（如 4 个阶段）。随着层数加深，逐步加大剪枝比例。这符合 LLM 浅层提取特征、深层融合语义的规律，减少了深层不必要的计算。

*   **消融实验**：非常充分。作者分别验证了层级平衡、片段分段、DPP 剪枝组件的有效性，并对分段阈值 $\beta$、预算分配因子 $\lambda$、指令相关性计算方式等超参数进行了详细探讨。
*   **客观性**：通过与多种最新的 SOTA 方法在相同 Token 预算下对比 FLOPs 和准确率，证明了其在效率和精度上的双重优势，实验设计公平合理。

#### 6. 主要结论与发现
*   **性能卓越**：在保留 30% Token 的情况下，HieraVid 在 LLaVA-OneVision-7B 上保留了 **99.3%** 的原始性能；在 10% 的极低保留率下，依然能维持约 **95%** 的性能，远超其他对比方法。
*   **长视频优势**：在 VideoMME 等长视频任务中，HieraVid 的分段策略显著优于传统的全局剪枝方法。
*   **信息流规律**：实验证实了使用 LLM **最后一个指令 Token** 来计算视觉相关性比使用平均 Token 更有效，这揭示了多模态 LLM 内部信息流动的特定模式。

#### 7. 优点
*   **即插即用**：无需任何微调或重新训练，可直接应用于现有的预训练 VideoLLMs。
*   **结构化感知**：不同于随机或纯注意力驱动的剪枝，它利用了视频的时间连续性和 LLM 的层级特性，逻辑更符合物理直觉。
*   **多样性保证**：引入 DPP 算法有效解决了剪枝过程中容易丢失关键细节的问题，保证了保留 Token 的信息熵。

#### 8. 不足与局限
*   **计算开销偏移**：虽然减少了 LLM 的计算量，但 DPP 算法和分段时的相似度计算会引入额外的 CPU/GPU 预处理开销（尽管文中提到仅为毫秒级）。
*   **超参数依赖**：分段阈值 $\beta$ 和阶段划分可能需要针对不同风格的视频（如快节奏动作 vs. 慢节奏监控）进行微调以达到最佳效果。
*   **模型规模覆盖**：实验主要集中在 7B 规模的模型上，对于 72B 或更大规模的模型，其层级剪枝策略的阶段划分是否需要调整尚待验证。
