## 摘要
长上下文生成日益受到解码阶段键值（KV）缓存传输流量的限制，特别是当 KV 缓存被卸载到 GPU 显存之外时。查询感知检索（如 Top-K 选择）通过仅加载 KV 对的子集来减少此类流量，但当注意力权重分散在未检索到的标记上时，对该子集进行 softmax 重新归一化会引入偏差。我们提出了一种检索-补全注意力模块，该模块保持骨干网络权重和 KV 缓存格式不变。对于每个查询，我们计算针对 sink/tail 锚点和查询相关的 Top-K 检索标记的精确注意力，并利用预填充阶段计算的固定大小特征图摘要来估计剩余中间区域的分子和分母。我们在未归一化域中将精确贡献和估计贡献相加，并执行统一归一化，从而在不增加额外 KV 读取的情况下恢复缺失的 softmax 权重。在长上下文基准测试中，在相同的等效标记读取预算下，所提方法优于仅采用选择的 Top-K 方法，且在高熵注意力头中提升最为显著。

## Abstract
Long-context generation is increasingly limited by decode-time key-value (KV) cache traffic, particularly when KV is offloaded beyond GPU memory. Query-aware retrieval (e.g., Top-K selection) reduces this traffic by loading only a subset of KV pairs, but renormalizing the softmax over the subset introduces bias when attention mass is spread over unretrieved tokens. We propose a retrieval-completion attention module that keeps backbone weights and the KV-cache format unchanged. For each query, we compute exact attention over sink/tail anchors and the query-dependent retrieved Top-K tokens, and estimate the remaining mid-region numerator and denominator using a fixed-size feature-map summary computed at prefill time. We add the exact and estimated contributions in the unnormalized domain and apply a single normalization, recovering the missing softmax mass without additional attention-side KV reads. Across long-context benchmarks, the proposed method improves over selection-only Top-K at matched token-equivalent read budgets, with the largest gains in high-entropy heads.

### 1. 核心问题与整体含义（研究动机与背景）
在长文本生成任务中，Transformer 模型的解码速度受限于 **KV Cache 的内存访问带宽（Memory-bound）**，而非计算能力。当上下文极长且 KV 缓存被卸载（Offload）到 CPU 内存或 SSD 时，读取完整的 KV 缓存会产生巨大的延迟。
*   **现有方案的缺陷**：目前的 Top-K 检索或剔除方法（如 Quest、H2O）虽然减少了 KV 读取量，但仅对检索到的子集进行 Softmax 归一化。当注意力权重分布较为分散（高熵状态）时，这种“子集归一化”会忽略未检索 Token 的贡献，导致严重的精度偏差。
*   **研究目标**：在**不修改模型权重**、**不改变 KV 缓存格式**的前提下，通过一种“检索+补全”的混合机制，在减少 KV 读取的同时，补偿未检索部分的注意力质量。

### 2. 方法论：核心思想与关键技术
论文提出了一种**混合注意力模块（Hybrid Attention）**，其核心流程如下：

*   **区域划分**：将预填充（Prefill）阶段的 KV 缓存分为三部分：
    1.  **锚点（Anchors）**：包括起始的 Sink Token 和末尾的 Tail Token，这部分始终精确读取。
    2.  **中间区域（Mid Region）**：应用 Top-K 检索的部分。
    3.  **补全项（Completion）**：针对中间区域未被检索到的 Token。
*   **预填充阶段（构建摘要）**：利用**线性注意力（Linear Attention）**的思想，为中间区域计算一个固定大小的特征图摘要（Feature-map Summary）。通过蒸馏学习到的正向特征映射 $\phi$，将 KV 信息压缩进固定维度的缓存中。
*   **解码阶段（减法补全与统一归一化）**：
    1.  **精确计算**：读取锚点和 Top-K 检索到的 Token，计算其非归一化的注意力分子（Numerator）和分母（Denominator）。
    2.  **减法补全（Subtractive Completion）**：为了避免重复计算，从预存的特征图摘要中减去已检索到的 Top-K Token 的特征贡献，从而得到纯粹的“未检索部分”估计值。
    3.  **合并与归一化**：在**非归一化域**将精确项与估计项相加，最后执行单次归一化。公式逻辑为：$y_{hybrid} = \frac{N_{exact} + \hat{N}_{remainder}}{Z_{exact} + \hat{Z}_{remainder}}$。

### 3. 实验设计
*   **数据集与基准测试**：
    *   **RULER**：包含 13 个长文本任务的综合基准，测试长度涵盖 4k、8k、16k。
    *   **BABILong**：测试长上下文推理能力（QA1-QA5）。
*   **骨干模型**：Llama-3.2-1B-Instruct 和 Qwen3-1.7B。
*   **对比方法**：

    *   **Lane B（系统级对比）**：Quest、MagicPIG、SnapKV、PyramidKV、StreamingLLM 等。

*   **实验规模**：论文在两个主流开源模型上进行了多长度（4k-16k）、多预算（1%-5% 读取率）的详尽测试。

### 6. 主要结论与发现
*   **精度提升**：在相同的 KV 读取预算下，补全机制显著优于纯 Top-K 检索，尤其是在 Llama 模型上，能将 16k 长度下的 RULER 分数从 0.606 提升至 0.635。
*   **高熵敏感性**：补全机制的增益主要集中在注意力分布分散（高熵）的层和头中。对于注意力集中的低熵头，纯 Top-K 已足够。
*   **I/O 优势**：在 KV 卸载场景（如 SSD 存储）中，通过减少检索数量并使用补全项，可以实现显著的端到端加速。

### 7. 优点与亮点
*   **非侵入性**：不需要重新训练大模型，也不改变现有的 KV Cache 存储格式，极易集成到现有的推理框架（如 vLLM）中。
*   **数学严谨性**：通过在非归一化域合并项，解决了 Softmax 归一化偏差的根本问题。
*   **减法补全创新**：巧妙地利用 Top-K 检索到的 Token 来修正线性注意力的摘要，提高了估计的准确度。

### 8. 不足与局限
*   **模型依赖性**：实验显示 Qwen3 的提升不如 Llama 显著，说明该方法的有效性受骨干模型注意力分布特性的影响。
*   **计算开销**：虽然减少了 I/O，但增加了特征图计算和减法操作的计算量。在计算受限（Compute-bound）而非 I/O 受限的场景下，可能没有速度优势。
*   **蒸馏成本**：需要针对不同的上下文长度预先蒸馏特征映射，这增加了一定的离线准备成本。
*   **长度限制**：实验目前仅验证到 16k 长度，对于更极端的百万级长度（1M+），特征图摘要的压缩比和精度保持能力尚待验证。
