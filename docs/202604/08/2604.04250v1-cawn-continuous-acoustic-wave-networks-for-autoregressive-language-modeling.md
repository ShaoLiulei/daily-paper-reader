## 摘要
现代大语言模型（LLM）依赖于 Transformer 的自注意力机制，其计算复杂度随序列长度呈二次方增长。最近出现的线性时间替代方案，如状态空间模型（SSM），在长上下文处理中往往面临信号衰减的问题。我们提出了连续声波网络（CAWN），这是一种全连续的序列混合架构。CAWN 并非采用基于离散矩阵的注意力机制，而是将隐藏状态投影到多头复数域相量中，通过因果性的 $O(L)$ 相位累积机制实现序列混合。为了防止超长上下文中的信号衰减，我们引入了双门控选择性相位共振机制，该机制结合了频率相关保留、通过直通估计实现的硬阈值门控，以及用于捕获短期局部依赖的临时语法缓存。我们还使用深度谐波卷积取代了标准的稠密线性投影，以实现最优的空间频率混合，并辅以块注意力残差进行深度状态路由。在扩展至 1.5 亿参数模型时，CAWN 利用自定义 Triton 内核在 float32 精度下实现了硬件高效的真复数相位累积。该原型在 1000 亿 token 的语料库上通过连续流式循环进行训练，并在 50 亿 token 的里程碑处进行了评估。通过针对性语义检索协议进行的实证评估表明，该模型具有稳健的词汇习得能力和扩展的显式学习上下文去噪能力。通过利用分块预填充实现的 $O(1)$ 状态传递，该模型能够在 2,000,000 个 token 中检索目标信息，同时显存峰值严格稳定在 8.72 GB，从经验上克服了 $O(L^2)$ 的上下文显存墙。

## Abstract
Modern Large Language Models (LLMs) rely on Transformer self-attention, which scales quadratically with sequence length. Recent linear-time alternatives, like State Space Models (SSMs), often suffer from signal degradation over extended contexts. We introduce the Continuous Acoustic Wave Network (CAWN), a fully continuous sequence-mixing architecture. Instead of discrete matrix-based attention, CAWN projects hidden states into multi-headed complex-domain phasors, achieving sequence mixing through a causal, $O(L)$ Phase Accumulation mechanism. To prevent signal degradation over ultra-long contexts, we introduce a dual-gated Selective Phase Resonance mechanism incorporating Frequency-Dependent Retention, Hard-Threshold Gating via Straight-Through Estimation, and a Temporal Syntax Cache to capture short-term local dependencies. We also replace standard dense linear projections with Depth-wise Harmonic Convolutions for optimal spatial frequency mixing, augmented by Block Attention Residuals for depth-wise state routing. Scaled to a 150M-parameter model, CAWN utilizes custom Triton kernels for hardware-efficient, true-complex phase accumulation in float32. Trained via a continuous streaming loop on a 100-Billion-token corpus, the prototype is evaluated at a 5-Billion-token milestone. Empirical evaluations via a Targeted Semantic Retrieval protocol demonstrate robust vocabulary acquisition and extended explicitly learned contextual denoising. By leveraging $O(1)$ state-passing via chunked prefill, the model retrieves targeted information across 2,000,000 tokens while strictly plateauing at 8.72 GB of Peak VRAM, empirically overcoming the $O(L^2)$ context memory wall.

### 2. 方法论：核心思想与关键技术
CAWN 抛弃了离散的矩阵注意力，转而使用**共振层（Resonance Layer）**。
*   **核心思想**：将离散 token 映射为复数域相量（Phasors），通过波形的相长或相消干涉来模拟语法和语义。
*   **关键技术细节**：
    *   **复数域相位累积（Causal Phase Accumulation）**：利用欧拉公式在复数域进行 $O(L)$ 的线性累积。通过确定性的相位旋转（类似 RoPE 的原理）来编码相对位置信息。
    *   **双门控选择性相位共振**：
        *   **频率相关保留（$\gamma$）**：低频波充当“全局记忆”，高频波充当“局部草稿纸”。
        *   **硬阈值门控（$\beta$）**：使用直通估计器（STE）将微弱信号强制归零，防止数值噪声污染相位状态。
    *   **临时语法缓存（Temporal Syntax Cache）**：在投影前使用 1D 卷积捕获局部语法，使全局相位累积专注于长程语义。
    *   **块注意力残差（Block Attention Residuals）**：为了防止深层网络中的信号稀释，将层分组并切断残差流，通过深度维度的 Softmax 注意力从早期块中提取“纯净”的波形状态。
    *   **卷积 SwiGLU 耳（Convolutional Ear）**：将累积的复数状态通过深度谐波卷积处理，模拟听觉系统过滤噪声，再投影回隐藏维度。

### 6. 主要结论与发现
*   **突破内存墙**：CAWN 实现了严格的 $O(L)$ 显存缩放。在分块预填充模式下，处理 200 万 token 时显存始终稳定在 **8.72 GB**，而 Transformer 在 4000 token 时即发生 OOM。
*   **推理能力涌现**：150M 参数的 CAWN 在 PIQA 和 ARC-Easy 上的表现优于同等训练量的 Pythia，证明连续波干涉可以捕捉离散逻辑。
*   **长程检索极限**：模型能完美检索 100 万 token 距离的信息。在 200 万 token 处出现选择性失效，推测是由于“声学周期性”导致的相位抵消。

### 7. 优点（亮点）
*   **硬件效率极高**：通过 Triton 内核将相位累积限制在 SRAM 中，实现了 $O(1)$ 的状态传递，生成速度不随长度增加而减慢。
*   **创新的物理隐喻**：将复杂的序列建模简化为波形干涉，提供了不同于矩阵运算的新视角。
*   **训练稳定性**：引入了硬阈值门控和 float32 相位稳定协议，解决了递归模型常见的数值爆炸问题。

### 8. 不足与局限
*   **绝对性能差距**：虽然架构效率高，但在相同参数下，其绝对预测精度（PPL）仍落后于经过海量数据（600B+ tokens）训练的饱和 Transformer 模型（如 SmolLM）。
*   **硬件优化依赖**：高度依赖自定义 Triton 内核，在非 CUDA 环境下的移植和优化可能存在挑战。
*   **相位抵消风险**：在极长序列（>200 万）中，波形的周期性可能导致信号被错误抵消，这可能需要更复杂的频率设计来解决。
*   **数据增强依赖**：模型极强的去噪能力部分归功于训练中加入的“垃圾 token”数据增强，这可能掩盖了架构本身在某些自然分布下的局限。
