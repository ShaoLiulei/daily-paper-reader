## 摘要
大型视觉语言模型（VLM）在多模态推理方面取得了显著成功，但由于解码过程中的内存开销，其推理效率仍面临重大挑战，特别是当 VLM 的查询和回答由长序列的视觉和文本标记（tokens）组成时。本文提出了 AttentionPack，这是一个专为大型视觉语言模型定制的自适应且注意力感知的优化框架，旨在提高解码过程中的内存效率，重点解决由于视觉输入和交互数量增加而带来的挑战，特别是在涉及多个高分辨率图像或视频的长上下文任务中。AttentionPack 的创新性体现在两个方面：(i) 我们引入了一种多头注意力压缩方法，通过利用隐式低秩结构来经济地存储键（key）和值（value）矩阵；(ii) 我们开发了一种特定于标记（token-specific）的注意力感知解压缩机制，以减少延迟开销。在多个基准测试上的实验结果表明，AttentionPack 将内存效率提高了高达 8 倍，在保持模型输出质量或支持更长上下文长度以实现卓越检索性能的同时，实现了更大的批处理大小和更快的批处理推理。我们还报告了 AttentionPack 与逐出（eviction）、量化和算子融合（kernel fusion）相结合的有效性，展示了在资源受限环境下进一步的效率提升。

## Abstract
Large Vision-Language Models (VLMs) have achieved remarkable success in multi-modal reasoning, but their inference time efficiency remains a significant challenge due to the memory overhead during decoding, especially when the query and answer of VLMs consist of long sequences of visual and text tokens. This paper presents AttentionPack, an adaptive and attention-aware optimization framework tailored for large vision-language models with improving memory-efficiency during decoding, focusing on addressing the challenges due to the increased high number of visual inputs and interactions, particularly in long-context tasks with multiple high-resolution images or videos. AttentionPack is novel in two aspects: (i) We introduce a multi-head attention compaction method for economically storing key and value matrices by exploiting the implicit low-rank structure, and (ii) we develop a token-specific attention-aware decompression mechanism to reduce latency overhead. Experimental results on multiple benchmarks demonstrate that AttentionPack improves memory efficiency by up to 8x, enabling higher batch sizes and faster batch inference while preserving the model output quality or longer context lengths for superior retrieval performance. We also report the effectiveness of AttentionPack combined with eviction, quantization and kernel fusion, showing further efficiency gains for resource-limited environments.

### 1. 核心问题与研究动机
*   **核心问题**：大型视觉语言模型（VLM）在处理长序列（如多张高分辨率图像或长视频）时，**KV Cache（键值缓存）** 的内存开销呈爆炸式增长。这导致 GPU 显存迅速耗尽，限制了批处理大小（Batch Size）和上下文长度，并因频繁的内存数据交换导致推理延迟高、计算资源利用率低。
*   **研究背景**：现有的优化方法（如 Token 逐出或量化）虽然能减少缓存，但往往存在信息丢失（逐出）或硬件兼容性差（非均匀量化）的问题。本文旨在通过挖掘视觉 Token 在隐藏维度上的**低秩结构**，实现更高效的压缩与检索。

### 2. 方法论
AttentionPack 框架主要包含两个核心技术创新：
*   **多头注意力压缩（Multi-head Compression）**：
    *   **核心思想**：利用奇异值分解（SVD）对 KV 矩阵进行降维。
    *   **技术细节**：研究发现，将多个注意力头的缓存合并后再进行 SVD 压缩，比单独对每个头进行压缩能更好地保留信息（解释方差更高）。
    *   **流程**：在 Prefill（预填充）阶段后，将视觉和文本 Token 分开处理，通过 SVD 将原始 KV 矩阵分解为压缩后的缓存矩阵和解压矩阵（$K \approx K^* D_k$）。
*   **注意力感知解压缩（Attention-aware Decompression）**：
    *   **核心思想**：并非所有 Token 在解码时都同等重要，通过动态调整解压精度来降低计算开销。
    *   **技术细节**：引入重要性分数 $I_{tp}$，利用滑动平均（Moving Average）追踪每个 Token 的累积注意力得分。
    *   **算法流程**：在每个解码步骤中，仅对注意力分数高的 Token 使用全秩（Full Rank）解压，而对不重要的 Token 使用极低秩解压。这种“部分解压”机制显著减少了矩阵乘法的浮点运算量（FLOPs）。
*   **算子融合（Kernel Fusion）**：将解压操作直接集成到 FlashAttention 算子中，在 SRAM 中完成即时解压和计算，减少了 HBM（显存）的读写次数。

*   **实验规模**：涵盖了 5 个多模态数据集和 1 个长文本数据集，测试了从 7B 到 13B 不同规模的模型。

### 6. 主要结论与发现
*   **内存效率**：在 LLaVA 和 VideoLLaVA 上实现了 **5x 到 8x** 的 KV Cache 减小，显存占用显著降低。
*   **推理加速**：由于内存占用减少，支持更大的 Batch Size，批处理推理吞吐量提升了 **50% - 74%**。
*   **性能保持**：在压缩 80% 缓存的情况下，模型在 QA 任务上的性能损失极小（通常在 1% 以内），甚至在某些 OCR 任务中因压缩过滤了噪声而略有提升。
*   **视觉 vs 文本**：视觉 Token 表现出更强的低秩特性，比文本 Token 更适合这种压缩方式。

### 7. 优点
*   **自适应性**：注意力感知解压机制能够根据当前查询动态调整计算量，平衡了速度与精度。
*   **高兼容性**：可以作为插件与现有的量化（KVQuant）或算子优化（FlashAttention）技术结合，产生叠加增益。
*   **多模态针对性**：深入分析了视觉 Token 的冗余性，解决了 VLM 特有的长视觉序列瓶颈。

### 8. 不足与局限
*   **计算开销**：SVD 压缩本身需要额外的计算时间，虽然可以通过周期性压缩（Tp）来缓解，但在极短序列推理中可能收益不明显。
*   **文本压缩限制**：在纯文本长上下文任务中，为了保持性能，所需的秩（Rank）较高，压缩率不如视觉领域理想。
*   **超参数敏感性**：压缩周期 $T_p$、重要性阈值 $\alpha$ 和秩的选择需要针对不同模型进行微调，缺乏完全自动化的参数确定机制。
