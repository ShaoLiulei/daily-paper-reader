## 摘要
大视觉语言模型（VLMs）在多模态推理方面取得了显著成功，但由于解码过程中的内存开销，其推理时间效率仍面临重大挑战，特别是当 VLMs 的查询和回答由长序列的视觉和文本标记（tokens）组成时。本文提出了 AttentionPack，这是一个专为大视觉语言模型定制的自适应且注意力感知的优化框架，旨在提高解码过程中的内存效率，重点解决由于视觉输入和交互数量增加带来的挑战，特别是在涉及多个高分辨率图像或视频的长上下文任务中。AttentionPack 的创新性体现在两个方面：(i) 我们引入了一种多头注意力压缩方法，通过利用隐式低秩结构来经济地存储键（key）和值（value）矩阵；(ii) 我们开发了一种特定于标记的注意力感知解压缩机制，以减少延迟开销。在多个基准测试上的实验结果表明，AttentionPack 将内存效率提高了多达 8 倍，在保持模型输出质量或支持更长上下文长度以实现卓越检索性能的同时，实现了更大的批处理规模和更快的批处理推理。我们还报告了 AttentionPack 与剔除（eviction）、量化和算子融合（kernel fusion）相结合的有效性，展示了在资源受限环境下的进一步效率提升。

## Abstract
Large Vision-Language Models (VLMs) have achieved remarkable success in multi-modal reasoning, but their inference time efficiency remains a significant challenge due to the memory overhead during decoding, especially when the query and answer of VLMs consist of long sequences of visual and text tokens. This paper presents AttentionPack, an adaptive and attention-aware optimization framework tailored for large vision-language models with improving memory-efficiency during decoding, focusing on addressing the challenges due to the increased high number of visual inputs and interactions, particularly in long-context tasks with multiple high-resolution images or videos. AttentionPack is novel in two aspects: (i) We introduce a multi-head attention compaction method for economically storing key and value matrices by exploiting the implicit low-rank structure, and (ii) we develop a token-specific attention-aware decompression mechanism to reduce latency overhead. Experimental results on multiple benchmarks demonstrate that AttentionPack improves memory efficiency by up to 8x, enabling higher batch sizes and faster batch inference while preserving the model output quality or longer context lengths for superior retrieval performance. We also report the effectiveness of AttentionPack combined with eviction, quantization and kernel fusion, showing further efficiency gains for resource-limited environments.

#### 1. 核心问题与整体含义
随着大视觉语言模型（VLM）在处理长视频、高分辨率多图任务中的应用增加，推理阶段的 **KV Cache（键值缓存）** 内存开销成为了核心瓶颈。由于视觉 Token 数量庞大，存储这些中间状态不仅消耗大量显存，还限制了批处理大小（Batch Size），并因频繁的内存读写导致推理延迟增加。本文的研究动机在于：如何在不显著损失模型性能的前提下，通过压缩 KV 缓存来降低内存占用并提升推理吞吐量。

#### 2. 方法论
论文提出了 **AttentionPack** 框架，其核心思想是利用视觉 Token 在隐藏维度上的**隐式低秩结构**进行压缩。

*   **多头注意力压缩（Multi-head Compression）：**
    *   **核心逻辑：** 不同于传统方法对每个注意力头独立处理，AttentionPack 将多个头的 KV 矩阵合并后进行奇异值分解（SVD）。实验发现，合并后的矩阵具有更显著的低秩特性，压缩效率更高。
    *   **操作流程：** 在 Prefill（预填充）阶段后，将视觉 Token 的 K 和 V 矩阵分别分解为低秩分量。存储时仅保留压缩后的矩阵和解压矩阵（Decompression Matrix）。
*   **注意力感知解 decompression（Attention-aware Decompression）：**
    *   **核心逻辑：** 并非所有 Token 在解码时都同等重要。
    *   **技术细节：** 引入一个重要性评分机制（基于移动平均的累积注意力分数）。在解码步骤中，仅对高分 Token 使用全秩解压，而对低分 Token 使用极低秩解压。这显著减少了每一步解码的浮点运算量（FLOPs）。
*   **算法流程：**
    1.  输入处理并生成初始 KV。
    2.  执行 SVD 压缩并存储。
    3.  解码时，根据历史注意力分数决定每个 Token 的解压精度。
    4.  执行注意力计算并更新 Token 重要性权重。
    5.  周期性地重新触发压缩以包含新生成的 Token。

*   **实验规模：** 涵盖了 5 个主流多模态数据集，测试了从 7B 到 13B 不同规模的模型，并验证了在图像和视频两种模态下的表现。

#### 6. 主要结论与发现
*   **内存优化：** 在 LLaVA 和 VideoLLaVA 上实现了 **5.1x 至 8.1x** 的 KV Cache 内存缩减。
*   **性能保持：** 在压缩率高达 80% 的情况下，模型在 QA 任务上的性能损失极小（通常在 1% 以内），甚至在某些 OCR 任务中因“过滤了无关视觉噪声”而略有提升。
*   **吞吐量提升：** 由于内存占用降低，允许更大的 Batch Size，批处理推理吞吐量提升了 **43% - 74%**。
*   **兼容性：** 该方法可以与 4-bit 量化和 FlashAttention 等底层优化无缝结合，进一步压榨硬件性能。

#### 7. 优点
*   **信息无损保留：** 与直接丢弃 Token 的剔除策略不同，AttentionPack 保留了所有 Token，只是降低了非重要 Token 的表示精度，减少了信息丢失风险。
*   **多头合并策略：** 创新性地利用了跨 Head 的冗余性，比单头压缩更有效。
*   **注意力感知解压：** 巧妙地平衡了“压缩带来的存储收益”与“解压带来的计算开销”，解决了 SVD 推理延迟增加的痛点。
*   **算子融合：** 提供了 Fused Kernel 实现，将解压与注意力计算合并，减少了 I/O 开销。

#### 8. 不足与局限
*   **计算开销：** 尽管有解压优化，但 SVD 分解和矩阵乘法解压仍然引入了额外的计算步骤，在 Batch Size 极小或序列极短时，加速效果可能不明显。
*   **文本压缩限制：** 实验表明该方法对视觉 Token 效果极佳，但对文本 Token 的压缩效果相对有限（文本 Token 秩较高），需要分别处理。
*   **超参数敏感性：** 压缩周期 $T_p$ 和重要性阈值等参数可能需要针对不同任务进行微调以达到最优平衡。
