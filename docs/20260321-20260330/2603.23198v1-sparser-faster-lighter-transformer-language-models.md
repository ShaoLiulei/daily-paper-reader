## 摘要
扩展自回归大语言模型（LLMs）推动了前所未有的进步，但也带来了巨大的计算成本。在这项工作中，我们通过利用 LLM 前馈层中的非结构化稀疏性来解决这些成本问题，前馈层是占据模型大部分参数和执行 FLOPs 的主要组件。为了实现这一目标，我们引入了一种新的稀疏打包格式和一组 CUDA 内核，旨在与现代 GPU 的优化执行流水线无缝集成，从而在 LLM 推理和训练期间实现高效的稀疏计算。为了证实我们的收益，我们对 LLM 稀疏性进行了定量研究，证明简单的 L1 正则化可以诱导超过 99% 的稀疏性，且对下游性能的影响微乎其微。当与我们的内核结合使用时，我们展示了这些稀疏水平可以转化为显著的吞吐量、能效和内存使用优势，且这些优势随模型规模的扩大而增加。我们将以开源许可证发布所有代码和内核，以促进采用并加速研究，从而将稀疏性确立为提高现代基础模型效率和可扩展性的实用维度。

## Abstract
Scaling autoregressive large language models (LLMs) has driven unprecedented progress but comes with vast computational costs. In this work, we tackle these costs by leveraging unstructured sparsity within an LLM's feedforward layers, the components accounting for most of the model parameters and execution FLOPs. To achieve this, we introduce a new sparse packing format and a set of CUDA kernels designed to seamlessly integrate with the optimized execution pipelines of modern GPUs, enabling efficient sparse computation during LLM inference and training. To substantiate our gains, we provide a quantitative study of LLM sparsity, demonstrating that simple L1 regularization can induce over 99% sparsity with negligible impact on downstream performance. When paired with our kernels, we show that these sparsity levels translate into substantial throughput, energy efficiency, and memory usage benefits that increase with model scale. We will release all code and kernels under an open-source license to promote adoption and accelerate research toward establishing sparsity as a practical axis for improving the efficiency and scalability of modern foundation models.

以下是对该论文的结构化总结：

### 1. 核心问题与整体含义（研究动机）
*   **研究动机**：尽管 LLM 的前馈层（FFN）占据了模型约 2/3 的参数和 80% 的计算量，且研究表明其激活具有天然的稀疏性，但由于现代 GPU 架构高度优化了稠密矩阵运算，非结构化稀疏运算往往因索引开销和内存访问不连续而导致实际运行速度慢于稠密运算（即“稀疏悖论”）。
*   **核心问题**：如何在不显著损失模型性能的前提下，通过软硬件协同设计，将理论上的稀疏性转化为实际的推理吞吐量提升、训练加速、能效提高和内存占用减少。

### 2. 方法论
*   **核心思想**：引入新型稀疏数据格式和定制化 CUDA 内核，使稀疏计算能无缝集成到 GPU 的优化流水线中。
*   **关键技术细节**：
    *   **TwELL (Tile-wise ELLPACK) 格式**：一种新型稀疏打包格式。它将矩阵划分为水平分块（Tiles），在分块内进行局部 ELLPACK 编码。这种设计允许在矩阵乘法的“收尾阶段”（Epilogue）直接生成稀疏格式，避免了全局同步开销。
    *   **融合推理内核**：将 Gated FFN 的三个投影层（Gate, Up, Down）融合。第一个内核计算 Gate 投影并生成 TwELL 格式；第二个内核利用 TwELL 格式同时完成 Up 和 Down 投影，大幅减少了对全局内存（DRAM）的访问。
    *   **混合训练格式（Hybrid Format）**：针对训练中激活分布极度不均的问题，将行划分为“极度稀疏部分”（存入紧凑的 ELL 矩阵）和“稠密备份部分”（存入稠密矩阵）。这种方式在大幅降低中间激活存储成本的同时，保证了对异常值的鲁棒性。
    *   **稀疏诱导方案**：采用 ReLU 激活函数，并在标准交叉熵损失基础上增加简单的 **L1 正则化** 损失项，以强制诱导激活稀疏性。

### 3. 实验设计
*   **数据集**：使用 FineWeb 数据集（FineWeb-Edu 分片）进行预训练。
*   **模型规模**：涵盖 0.5B、1B、1.5B 和 2B 参数规模的 Transformer++ 架构。
*   **Benchmark**：在 7 个下游任务上评估逻辑和常识推理能力，包括 ARC (Easy/Hard)、HellaSwag、OpenBookQA、PIQA、WinoGrande 和 CommonsenseQA。
*   **对比方法**：
    *   基准线：标准的稠密模型（使用 ReLU 或 SiLU 激活）。
    *   不同 L1 正则化系数下的稀疏模型对比。
    *   在不同硬件（H100 与 RTX 6000）上的性能对比。

### 4. 资源与算力
*   **硬件环境**：主要实验在一台配备 **8 张 NVIDIA H100 PCIe GPU** 的节点上完成。
*   **训练时长**：模型根据 Chinchilla 最优原则训练，例如 2B 模型训练了 40B tokens。
*   **额外测试**：在 RTX 6000 GPU 上进行了训练加速对比实验，验证了该方法在低带宽硬件上的优越性。

### 5. 实验数量与充分性
*   **实验规模**：研究涵盖了从 0.5B 到 2B 的多个尺度，并对 L1 系数进行了详尽的消融实验（从 0 到 $10^{-4}$ 共 8 个量级）。
*   **充分性与公平性**：实验设计较为客观。作者不仅对比了任务准确率，还详细记录了交叉熵损失、激活稀疏度、死神经元比例、推理吞吐量、训练步长耗时、峰值内存和能耗。对比基准包含了目前主流的 Gated FFN 结构，且稀疏模型与稠密模型使用相同的超参数设置，确保了公平性。

### 6. 主要结论与发现
*   **极高稀疏度**：通过轻微的 L1 正则化，可以在 FFN 层诱导超过 **99%** 的稀疏度，而下游任务性能损失微乎其微（准确率下降通常在 1% 以内）。
*   **实际加速效果**：在 2B 规模模型上，稀疏内核使推理吞吐量提升了 **20.5%**，训练速度提升了 **21.9%**。
*   **资源节省**：稀疏化使训练峰值内存减少了约 **28%**，推理能耗降低了约 **17%**。
*   **规模效应**：随着模型规模增大，稀疏性带来的收益（吞吐量和内存节省）呈现增加趋势，说明该方法具有良好的可扩展性。
*   **输入特性**：模型会自动将计算资源分配给信息量大的 Token（如特定名词、动词）和序列起始位置。

### 7. 优点（亮点）
*   **软硬协同**：不只是理论研究，而是提供了切实可用的 CUDA 内核，解决了非结构化稀疏在现代 GPU 上“中看不中用”的问题。
*   **通用性**：TwELL 格式和混合训练算法可以适配现有的 Transformer 训练流水线，无需对架构做根本性改变（仅需将 SiLU 换回 ReLU）。
*   **开源贡献**：作者承诺开源所有代码和内核，有助于稀疏性研究在工业界的落地。

### 8. 不足与局限
*   **激活函数限制**：目前主要针对 ReLU。虽然实验表明 ReLU 与 SiLU 差距较小，但在某些极高性能要求的场景下，SiLU 仍有微弱优势。
*   **死神经元风险**：高强度正则化会导致大量神经元永久失活（死神经元），虽然论文提出了初步的重初始化策略，但这一问题在超大规模模型长期训练中的稳定性仍需验证。
*   **覆盖范围**：目前仅针对 FFN 层进行了稀疏化，未涉及 Attention 层的稀疏化，而后者在长文本场景下也是计算瓶颈。
*   **硬件依赖**：部分优化（如 TMA 访问）针对 NVIDIA Hopper 架构（H100），在旧款或其他厂商硬件上的移植性可能受限。
