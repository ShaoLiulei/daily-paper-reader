## 摘要
仅解码器语言模型是无状态的：隐藏表示在每次前向传播后都会被丢弃，且会话之间没有任何持久化内容。Jeong (2026a) 表明，基于 Jeong (2026b,c) 的侧向存储框架，经过训练的存储适配器能赋予冻结的编码器-解码器骨干网络持久的潜空间存储能力。本文探讨了同样的原理是否适用于仅解码器设置，在这种设置下不存在交叉注意力路径，存储必须仅通过自注意力进入。我们将六种方法——前缀、并行交叉注意力、KV 扩展、赫布存储、上下文门控分支以及基于槽位的稀疏写入——应用于冻结的 GPT-2，仅训练一个微小的适配器 $θ_{mem}$。写入规则是共享的；仅读取注入方式从解码器交叉注意力变为了自注意力 KV 前缀或并行分支。在 LoCoMo 数据集上，我们发现了一个显著的归纳偏置二分现象：在 $1\times$ 容量下，具有强架构先验的三种方法——交叉注意力 (M.2)、赫布存储 (M.4) 和槽位写入 (M.6)——实现了 $7-18\%$ 的记忆保留分数和 $7-10$ 的知识增益 $ΔK$，而其他三种方法则失败了（$< 0.4\%$）。在 $10\times$ 容量下，所有六种方法趋于收敛，表明这种差距是架构性的而非根本性的。结合 Jeong (2026a) 的编码器-解码器结果以及 Jeong (2026b,c) 的类脑模块，这些发现确立了持久化潜空间存储作为一种跨越主要 Transformer 家族的通用范式。

## Abstract
Decoder-only language models are stateless: hidden representations are discarded after every forward pass and nothing persists across sessions. Jeong (2026a) showed that trained memory adapters give a frozen encoder-decoder backbone persistent latent-space memory, building on the lateral-memory framework of Jeong (2026b,c). Here we ask whether the same principle transfers to the decoder-only setting, where no cross-attention pathway exists and memory must enter through self-attention alone. We adapt six methods -- prefix, parallel cross-attention, KV extension, Hebbian memory, context-gated branch, and slot-based sparse write -- to a frozen GPT-2, training only a small adapter $θ_{mem}$. The write rule is shared; only the read injection changes from decoder cross-attention to self-attention KV prefix or parallel branch. On LoCoMo we find a striking inductive-bias dichotomy: at $1\times$ capacity, three methods with strong architectural priors -- cross-attention (M.2), Hebbian (M.4), and slot write (M.6) -- achieve retained-memory scores of $7-18\%$ and knowledge gains $ΔK$ of $7-10$, while the other three fail ($< 0.4\%$). At $10\times$ capacity all six converge, showing the gap is architectural, not fundamental. Together with the encoder-decoder results of Jeong (2026a) and the brain-inspired modules of Jeong (2026b,c), these findings establish persistent latent-space memory as a general paradigm spanning major transformer families.

### 1. 核心问题与整体含义
*   **研究动机**：目前的仅解码器（Decoder-only）大语言模型（如 GPT-4、Llama）本质上是“无状态”的，每次前向传播后的隐藏表示都会被丢弃，无法在不同会话间保留信息。
*   **背景**：作者此前已在编码器-解码器（Encoder-Decoder）架构上实现了持久化潜空间记忆，但该架构拥有天然的“交叉注意力”路径。而 Decoder-only 架构缺乏这一路径，记忆必须通过“自注意力”机制强行注入。
*   **核心问题**：在保持模型主体冻结的情况下，能否通过训练微小的适配器，让 Decoder-only 模型也具备跨越数个会话、甚至无限长文本的持久化记忆能力？

### 2. 方法论
*   **核心思想**：引入一个持久化的记忆库 $P$（Latent-space Memory Bank），通过训练一个小型适配器 $\theta_{Mem}$ 来管理记忆的读取和写入，而模型主体保持冻结。
*   **关键技术细节**：
    *   **通用写入规则**：所有方法共享一种基于注意力耦合的更新机制。公式为 $P_t = \gamma P_{t-1} + A_t^\top V_w$，其中 $\gamma$ 是衰减因子，$A_t$ 是当前输入与记忆的关联权重，$V_w$ 是从当前隐藏状态提取的新信息。
    *   **六种适配方法**：
        1.  **M.1 Prefix**：将记忆投影为 KV 对，作为前缀拼接到每一层自注意力中。
        2.  **M.2 XAttn**：在自注意力层后插入并行的交叉注意力层（类似 Flamingo 架构）。
        3.  **M.3 KV Ext**：每层拥有独立的 KV 扩展投影。
        4.  **M.4 Hebbian**：利用联想记忆矩阵进行外积更新和检索。
        5.  **M.5 Gated**：通过内容相关的门控分支将记忆信息加回隐藏状态。
        6.  **M.6 Slot**：基于槽位的稀疏写入，每次仅更新最相关的 $k$ 个记忆槽位。
*   **算法流程**：在训练阶段（Type 1），通过反向传播优化适配器参数；在推理阶段（Type 2），适配器参数冻结，但记忆库 $P$ 随对话进行实时更新。

*   **数据集与场景**：使用 **LoCoMo**（长程对话记忆数据集），包含跨越 30 个会话的长对话，要求模型回答基于早期会话事实的问题。
*   **Benchmark**：以无状态的冻结 GPT-2 (124M) 作为基准（Baseline）。
*   **对比方法**：横向对比了上述六种记忆注入方法，并设置了两种容量条件：$1\times$（标准容量，约 49K 参数）和 $10\times$（高容量）。
*   **评估指标**：
    *   **Retained-memory score**：通过消融记忆状态来衡量记忆对回答准确率的绝对贡献。
    *   **$\Delta K$ (Knowledge Gain)**：衡量模型在 30 个会话中累积知识的增长情况。

### 4. 资源与算力
*   **硬件使用**：论文提到使用 **单台 NVIDIA GPU** 进行训练。

*   **时长与规模**：虽然未明确给出总训练小时数，但提到 batch size 为 4，梯度累积为 4，且模型规模较小（124M），推测算力消耗属于轻量级。

### 5. 实验数量与充分性
*   **实验规模**：作者针对 6 种方法在 2 种容量下进行了完整测试，并绘制了覆盖 256+ 轮次滞后期的遗忘曲线。
*   **客观性与公平性**：遵循“等投入原则”（Equal-input principle），即所有模型在测试时仅能看到当前轮次的文本，确保任何性能提升都严格源于持久化记忆库 $P$，而非上下文窗口的延伸。
*   **充分性**：实验涵盖了从架构偏置到容量扩展的多个维度，验证了结论的稳健性。但实验仅限于 GPT-2 这一种骨干网络，缺乏在更大规模模型（如 Llama-3）上的验证。

### 6. 主要结论与发现
*   **归纳偏置二分现象**：在低容量（$1\times$）下，只有具有强架构先验的方法（M.2 交叉注意力、M.4 赫布记忆、M.6 槽位写入）能成功保留记忆（得分 7-18%），而简单的前缀或门控方法几乎完全失效。
*   **容量桥接效应**：当容量提升到 $10\times$ 时，所有六种方法性能趋于收敛。这表明 Decoder-only 模型的自注意力路径虽然难以注入外部信息，但可以通过增加参数维度来克服这种架构劣势。
*   **通用范式确立**：证明了持久化潜空间记忆是一个通用的范式，可以跨越 Encoder-Decoder 和 Decoder-only 两大 Transformer 家族。

### 7. 优点
*   **架构优雅**：提出了一种“通用写入、特定读取”的解耦设计，使得该框架易于迁移到不同的模型架构。
*   **非侵入性**：无需重新训练大模型，仅通过极小的适配器（参数量占比极低）即可赋予模型长期记忆。
*   **评估严谨**：采用了绝对遗忘曲线和知识累积双重指标，比单纯的困惑度（Perplexity）更能反映记忆质量。

### 8. 不足与局限
*   **模型规模受限**：实验仅在 124M 参数的 GPT-2 上完成，尚未在大规模参数（7B+）模型上验证其扩展性。
*   **写入侧限制**：写入过程中的投影矩阵是固定的随机映射（基于 Johnson-Lindenstrauss 定理），而非端到端学习，这可能限制了记忆编码的效率。
*   **任务单一**：主要集中在问答和事实召回任务，未探讨记忆对逻辑推理或风格迁移等复杂任务的影响。
*   **隐私风险**：论文也指出，持久化记忆可能导致敏感个人信息的长期留存，需建立配套的记忆删除机制。
