## 摘要
扩展自回归大语言模型（LLMs）推动了前所未有的进步，但也带来了巨大的计算成本。在这项工作中，我们通过利用 LLM 前馈层中的非结构化稀疏性来解决这些成本问题，前馈层是占据模型大部分参数和执行 FLOPs 的组件。为了实现这一目标，我们引入了一种新的稀疏打包格式和一组 CUDA 内核，旨在与现代 GPU 的优化执行流水线无缝集成，从而在 LLM 推理和训练期间实现高效的稀疏计算。为了证实我们的收益，我们对 LLM 稀疏性进行了定量研究，证明简单的 L1 正则化可以诱导超过 99% 的稀疏性，且对下游性能的影响微乎其微。当与我们的内核结合使用时，我们展示了这些稀疏水平可以转化为显著的吞吐量、能效和内存使用优势，且这些优势随模型规模的扩大而增加。我们将以开源许可证发布所有代码和内核，以促进采用并加速研究，从而将稀疏性确立为提高现代基础模型效率和可扩展性的实用维度。

## Abstract
Scaling autoregressive large language models (LLMs) has driven unprecedented progress but comes with vast computational costs. In this work, we tackle these costs by leveraging unstructured sparsity within an LLM's feedforward layers, the components accounting for most of the model parameters and execution FLOPs. To achieve this, we introduce a new sparse packing format and a set of CUDA kernels designed to seamlessly integrate with the optimized execution pipelines of modern GPUs, enabling efficient sparse computation during LLM inference and training. To substantiate our gains, we provide a quantitative study of LLM sparsity, demonstrating that simple L1 regularization can induce over 99% sparsity with negligible impact on downstream performance. When paired with our kernels, we show that these sparsity levels translate into substantial throughput, energy efficiency, and memory usage benefits that increase with model scale. We will release all code and kernels under an open-source license to promote adoption and accelerate research toward establishing sparsity as a practical axis for improving the efficiency and scalability of modern foundation models.

随着 LLM 规模的扩大，其计算成本呈指数级增长。前馈网络（FFN）层占据了模型约 2/3 的参数和超过 80% 的执行 FLOPs。虽然研究表明 FFN 层存在天然的激活稀疏性（仅少数神经元被激活），但由于现代 GPU 架构高度优化了稠密矩阵运算，传统的非结构化稀疏操作在实际运行中往往比稠密运算更慢。论文的核心动机是打破这种“稀疏性悖论”，通过硬件感知的算法设计，使非结构化稀疏性在现代 GPU 上产生实际的加速和节能效果。

### 2. 核心方法论
论文提出了一套完整的稀疏 LLM 训练与推理方案：
*   **稀疏性诱导：** 采用 **ReLU** 作为激活函数，并在训练损失函数中加入简单的 **L1 正则化**，以强制诱导 FFN 层的激活稀疏性。
*   **TwELL 格式（Tile-wise ELLPACK）：** 提出一种新型稀疏数据打包格式。它将矩阵划分为水平分块（Tiles），在分块内部进行局部 ELLPACK 打包。这种设计允许在矩阵乘法的“收尾阶段”（Epilogue）直接生成稀疏格式，避免了昂贵的全局同步和额外的内存读写。
*   **推理内核融合：** 开发了定制的 CUDA 内核，将 Gate、Up 和 Down 三个投影层融合。利用 TwELL 格式，内核仅加载非零激活对应的权重列/行，大幅减少了 DRAM 访问。
*   **训练混合格式（Hybrid Format）：** 针对训练中稀疏模式高度不均匀的特点，设计了“紧凑 ELL + 稠密备份”的混合格式。大部分稀疏行存入 ELL，极少数高激活行存入稠密矩阵，从而在保证内存效率的同时处理离群值。

*   **性能无损：** 简单的 L1 正则化可以诱导 **99% 以上** 的稀疏性，而对下游任务准确率的影响微乎其微（性能损失在 2% 以内）。

*   **规模效应：** 模型规模越大，稀疏性带来的吞吐量和内存收益越显著。
*   **输入特性：** 模型会自动将计算资源分配给信息量大的 token（如特定名词、动词）和序列起始位置。

### 7. 优点
*   **实用性强：** 提供了开源的 CUDA 内核，能够无缝集成到现有的 LLM 流水线中。
*   **硬件感知：** 并非单纯追求理论 FLOPs 的减少，而是针对 GPU 显存带宽和 Tensor Core 特性进行了深度优化。
*   **全生命周期覆盖：** 同时解决了推理加速和训练减负（内存与速度）的问题。

### 8. 不足与局限
*   **激活函数限制：** 虽然 ReLU 效果尚可，但目前主流模型多使用 SiLU，ReLU 在极大规模下的表现仍需进一步验证。

*   **范围局限：** 优化主要集中在 FFN 层，尚未涉及 Attention 层的稀疏化，而后者在长文本场景下也是重要瓶颈。
