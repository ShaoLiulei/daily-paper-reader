## 摘要
现有提高大型视觉语言模型（LVLM）效率的方法主要基于视觉标记（token）缩减的概念。然而，这种方法会产生信息瓶颈，从而损害性能，特别是在需要细粒度理解和推理的挑战性任务上。在这项工作中，我们通过引入 VISion On Request (VISOR) 来挑战这一范式，这是一种在不丢弃视觉信息的情况下降低推理成本的方法。VISOR 并非压缩图像，而是通过使图像和文本标记之间的交互稀疏化来提高效率。具体而言，语言模型通过一组少量且经过策略性布置的注意力层来关注全套高分辨率视觉标记：通用的视觉上下文由文本-图像之间的高效交叉注意力提供，而少量布置得当且动态选择的自注意力层则负责细化视觉表示本身，从而在需要时实现复杂的、高分辨率的推理。基于这一原则，我们首先通过改变自注意力层的数量，在不同的计算预算范围内训练一个单一的通用网络，然后引入一种轻量级的策略机制，根据每个样本的复杂度动态分配视觉计算资源。大量实验表明，VISOR 在大幅降低计算成本的同时，在各种基准测试中达到或超过了最先进的结果，并且在需要详细视觉理解的挑战性任务中表现出色。

## Abstract
Existing approaches for improving the efficiency of Large Vision-Language Models (LVLMs) are largely based on the concept of visual token reduction. This approach, however, creates an information bottleneck that impairs performance, especially on challenging tasks that require fine-grained understanding and reasoning. In this work, we challenge this paradigm by introducing VISion On Request (VISOR), a method that reduces inference cost without discarding visual information. Instead of compressing the image, VISOR improves efficiency by sparsifying the interaction between image and text tokens. Specifically, the language model attends to the full set of high-resolution visual tokens through a small, strategically placed set of attention layers: general visual context is provided by efficient cross-attention between text-image, while a few well-placed and dynamically selected self-attention layers refine the visual representations themselves, enabling complex, high-resolution reasoning when needed. Based on this principle, we first train a single universal network on a range of computational budgets by varying the number of self-attention layers, and then introduce a lightweight policy mechanism that dynamically allocates visual computation based on per-sample complexity. Extensive experiments show that VISOR drastically reduces computational cost while matching or exceeding state-of-the-art results across a diverse suite of benchmarks, and excels in challenging tasks that require detailed visual understanding.

# 论文总结：VISion On Request (VISOR)

## 1. 核心问题与研究动机
*   **背景**：大型视觉语言模型（LVLM）在处理高分辨率图像时，由于视觉标记（Token）数量庞大，推理成本极高。
*   **核心问题**：现有的效率优化方法主要集中在“视觉标记缩减”（如剪枝或合并），这会造成不可逆的**信息瓶颈**。在需要细粒度理解（如文档分析、图表阅读）的复杂任务中，这种信息丢失会导致性能大幅下降。
*   **研究动机**：探索一种在不丢弃任何视觉信息的前提下，通过优化计算频率而非减少数据量来提升效率的新路径。

## 2. 方法论（VISOR）
VISOR 的核心思想是**稀疏化图文交互**，将视觉处理从“全量计算”转变为“按需调用”。
*   **解耦处理**：将语言模型层分为仅文本处理层、交叉注意力（CA）层和自注意力（SA）层。
*   **高效交叉注意力 (CA)**：在预设层引入 CA，让文本 Token 作为 Query 去查询静态的视觉 Token。这种方式只提取信息而不更新视觉表示，计算开销极低。
*   **选择性自注意力 (SA)**：仅在少数关键层执行完整的自注意力，用于更新和细化视觉特征，构建层级化的视觉理解。
*   **通用模型训练**：训练一个单一模型，使其在训练过程中随机采样不同的 SA 层配置，从而能够支持从极低预算到全量计算的多种推理模式。
*   **自适应推理（路由机制）**：引入一个轻量级的 MLP 策略网络（Router），根据输入样本的复杂度，动态预测并选择最经济的 SA 层配置。

## 3. 实验设计
*   **基准模型**：主要基于 LLaVA-OV (0.5B 和 1.5B) 以及 Qwen2-VL (2B) 架构。
*   **数据集**：涵盖 13 个主流基准测试，并将其分为两类：
    *   **简单任务**（Coarse）：如 ScienceQA, POPE, GQA, MMBench 等。
    *   **困难任务**（Fine-grained）：如 DocVQA, InfoVQA, ChartQA, OCR-Bench 等。
*   **对比方法**：对比了多种 SOTA 效率优化方案，包括 VisionZip, VisPruner, HiRED, M3, PyramidDrop 和 SparseVLM。

## 4. 资源与算力
*   **硬件支持**：实验使用了 **16 张 AMD MI300X GPU**。
*   **训练细节**：采用两阶段训练。第一阶段在 4M 知识数据集上微调新增的注意力层；第二阶段在 3.2M 高质量指令微调数据集上进行全参数微调。
*   **优化器**：使用 AdamW，配合 DeepSpeed 框架进行分布式训练。

## 5. 实验数量与充分性
*   **实验规模**：论文在 13 个数据集上进行了详尽的测试，涵盖了从 0.5B 到 2B 不同规模的参数量。
*   **消融实验**：非常充分。作者研究了 CA 和 SA 层数的影响、通用训练 vs 独立训练的效果、路由机制的准确性，以及与现有 Token 缩减方法的结合效果。
*   **公平性**：为了确保对比客观，作者在统一的 LLaVA-OV 框架下重新实现并训练了多个基准方法，避免了因底座模型不同带来的偏差。

## 6 主要结论与发现
*   **效率与性能兼得**：VISOR 在“简单”任务上实现了约 **8.6 倍**的 FLOPs 节省，且性能持平或更优。
*   **困难任务的突破**：在需要细粒度理解的任务中，VISOR 显著优于所有 Token 缩减方法，证明了保留完整视觉上下文对复杂推理至关重要。
*   **正交性**：VISOR 可以与 Token 缩减方法结合（VISOR-TR），在保持高性能的同时实现高达 **18 倍至 35 倍**的计算节省。
*   **任务依赖性**：实验证实，简单任务仅需静态视觉特征，而困难任务则需要通过 SA 层进行动态特征细化。

## 7. 优点与亮点
*   **范式转移**：挑战了主流的“缩减 Token”思路，提出了“缩减交互层数”的新视角。
*   **动态适配**：通过路由机制实现了真正的“按需分配计算资源”，使模型在处理简单问题时极快，处理复杂问题时极准。
*   **通用性强**：一个模型即可适配多种计算预算，无需为不同场景重复训练多个模型。

## 8. 不足与局限
*   **训练依赖**：虽然推理是高效的，但 VISOR 需要两阶段的微调过程，对于完全无法进行训练的纯“插件式”应用场景不够友好。
*   **路由策略风险**：路由器的训练依赖于离线生成的伪标签，如果测试样本与训练分布差异极大，可能会出现配置选择失误。
*   **架构局限**：目前主要针对类 Transformer 的 LLM 架构，对于其他新兴的非注意力机制架构（如 Mamba）的适用性尚未验证。
