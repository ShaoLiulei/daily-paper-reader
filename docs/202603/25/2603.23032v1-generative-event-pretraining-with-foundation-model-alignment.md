## 摘要
事件相机凭借其微秒级延迟和高动态范围，在快速运动和挑战性光照条件下能提供鲁棒的视觉信号。然而，其独特的传感特性和有限的有标签数据，使得训练基于事件的视觉基础模型（VFM）变得具有挑战性，而这些模型对于学习跨任务的可迁移视觉特征至关重要。为了解决这一问题，我们提出了 GEP（生成式事件预训练），这是一个两阶段框架，旨在将从互联网规模图像数据集中学习到的语义知识迁移到事件数据中，同时学习事件特有的时间动力学。首先，通过联合回归-对比目标将事件编码器与冻结的 VFM 对齐，使事件特征植根于图像语义中。其次，在混合的事件-图像序列上对 Transformer 骨干网络进行自回归预训练，以捕捉事件特有的时间结构。我们的方法在包括物体识别、分割和深度估计在内的多种下游任务上，性能均优于最先进的事件预训练方法。总之，VFM 引导的对齐和生成式序列建模产生了一个语义丰富、具备时间感知能力的事件模型，该模型在不同领域间具有鲁棒的泛化能力。

## Abstract
Event cameras provide robust visual signals under fast motion and challenging illumination conditions thanks to their microsecond latency and high dynamic range. However, their unique sensing characteristics and limited labeled data make it challenging to train event-based visual foundation models (VFMs), which are crucial for learning visual features transferable across tasks. To tackle this problem, we propose GEP (Generative Event Pretraining), a two-stage framework that transfers semantic knowledge learned from internet-scale image datasets to event data while learning event-specific temporal dynamics. First, an event encoder is aligned to a frozen VFM through a joint regression-contrastive objective, grounding event features in image semantics. Second, a transformer backbone is autoregressively pretrained on mixed event-image sequences to capture the temporal structure unique to events. Our approach outperforms state-of-the-art event pretraining methods on a diverse range of downstream tasks, including object recognition, segmentation, and depth estimation. Together, VFM-guided alignment and generative sequence modeling yield a semantically rich, temporally aware event model that generalizes robustly across domains.

    1.  **数据稀缺**：缺乏像互联网规模图像那样庞大的有标签事件数据集。
    2.  **模态差异**：事件流是稀疏、异步的，与传统的纹理丰富、静态的RGB图像存在巨大的表征鸿沟，导致难以直接迁移图像领域的语义知识。

### 2. 方法论：核心思想与技术细节
论文提出了 **GEP (Generative Event Pretraining)** 框架，分为两个关键阶段：
*   **阶段一：VFM 引导的语义对齐（Alignment）**
    *   **核心思想**：将事件编码器作为“学生”，冻结的图像基础模型（DINOv2）作为“老师”，进行跨模态蒸馏。
    *   **技术细节**：使用联合损失函数，包括**余弦相似度（回归）**以对齐特征方向、**InfoNCE（对比学习）**以增强特征的判别性，以及**能力保持损失（Preservation loss）**以防止事件编码器在处理图像输入时发生表征漂移。
*   **阶段二：自回归事件预训练（Pretraining）**
    *   **核心思想**：在对齐后的特征空间中，通过预测未来序列来学习时间演化规律。
    *   **技术细节**：将对齐后的事件和图像特征交织成多模态序列，输入到一个**因果 Transformer（Causal Transformer）**中。模型通过**自回归（Autoregressive）**方式预测未来的 Token 序列。这种生成式任务迫使模型理解长程的时间依赖关系和运动动力学。

### 6. 主要结论与发现
*   **语义对齐是关键**：单纯在事件数据上预训练难以获得强语义，引入图像 VFM 的引导能显著提升模型在识别和分割任务中的表现。
*   **自回归建模优于掩码建模**：在处理具有连续时间属性的事件流时，自回归预测比传统的掩码自编码（MAE）更能捕捉运动动力学。
*   **泛化性极强**：GEP 在仅使用少量训练轮数的情况下，在所有 10 项指标上均刷新了纪录，且在跨领域测试中表现稳健。

### 7. 优点（亮点）
*   **高效性**：通过冻结 VFM 老师模型，极大地降低了训练成本，实现了“小算力、高性能”。
*   **统一性**：一个预训练骨干网络可以同时适配分类（全局特征）和分割/深度估计（局部密集特征）任务。
*   **时间感知**：不同于以往只关注静态空间特征的方法，GEP 通过生成式任务赋予了模型预测未来的能力。

### 8. 不足与局限
*   **模态依赖**：模型性能在很大程度上受限于所选用的图像 VFM（如 DINOv2）的质量。
*   **输入表征**：虽然使用了自回归 Transformer，但输入仍需先将事件累积为“伪帧”（Xe），这在一定程度上牺牲了事件相机原始的极高时间分辨率（微秒级）。
*   **实时性挑战**：虽然预训练高效，但推理时使用 Transformer 骨干网络对于某些资源受限的嵌入式事件感知平台可能仍存在计算压力。
