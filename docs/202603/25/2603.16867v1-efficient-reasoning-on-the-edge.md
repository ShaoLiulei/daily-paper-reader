## 摘要
具有思维链（CoT）推理能力的大语言模型（LLMs）在复杂问题解决任务中取得了最先进的性能，但其冗长的推理轨迹和庞大的上下文需求使其在边缘端部署变得不切实际。这些挑战包括高昂的 Token 生成成本、巨大的 KV 缓存占用，以及在将推理能力蒸馏到适用于移动设备的较小模型时效率低下。现有方法通常依赖于将大模型的推理轨迹蒸馏到小模型中，而这些轨迹往往冗长且风格冗余，不符合端侧推理的需求。在本研究中，我们提出了一种轻量化方法，通过结合 LoRA 适配器与有监督微调（SFT），使小型 LLM 具备推理能力。我们进一步在这些适配器上通过强化学习引入了预算强制（budget forcing）机制，在精度损失极小的情况下显著缩短了响应长度。为了解决受内存限制的解码问题，我们利用并行测试时缩放（test-time scaling），在延迟略微增加的情况下提高了准确率。最后，我们提出了一种动态适配器切换机制（仅在需要时激活推理）以及 Prompt 编码期间的 KV 缓存共享策略，从而减少了端侧推理的首字延迟（TTFT）。在 Qwen2.5-7B 上的实验表明，我们的方法在严格的资源限制下实现了高效、准确的推理，使 LLM 推理在移动场景中变得切实可行。展示我们方案在移动设备上运行的视频可在项目主页查看。

## Abstract
Large language models (LLMs) with chain-of-thought reasoning achieve state-of-the-art performance across complex problem-solving tasks, but their verbose reasoning traces and large context requirements make them impractical for edge deployment. These challenges include high token generation costs, large KV-cache footprints, and inefficiencies when distilling reasoning capabilities into smaller models for mobile devices. Existing approaches often rely on distilling reasoning traces from larger models into smaller models, which are verbose and stylistically redundant, undesirable for on-device inference. In this work, we propose a lightweight approach to enable reasoning in small LLMs using LoRA adapters combined with supervised fine-tuning. We further introduce budget forcing via reinforcement learning on these adapters, significantly reducing response length with minimal accuracy loss. To address memory-bound decoding, we exploit parallel test-time scaling, improving accuracy at minor latency increase. Finally, we present a dynamic adapter-switching mechanism that activates reasoning only when needed and a KV-cache sharing strategy during prompt encoding, reducing time-to-first-token for on-device inference. Experiments on Qwen2.5-7B demonstrate that our method achieves efficient, accurate reasoning under strict resource constraints, making LLM reasoning practical for mobile scenarios. Videos demonstrating our solution running on mobile devices are available on our project page.

大型语言模型（LLM）通过思维链（CoT）推理在复杂任务中表现卓越，但其**冗长的推理过程**和**巨大的资源需求**（Token 生成成本、KV 缓存占用、内存带宽限制）使其难以在移动设备等边缘端部署。
*   **研究动机**：现有的推理模型（如 DeepSeek-R1）通常过于臃肿，且蒸馏后的小模型往往继承了冗长且重复的推理风格，导致端侧推理延迟高、功耗大。
*   **核心目标**：在严格的内存、延迟和功耗预算下，为小型 LLM（3B/7B）开启高效的推理模式，实现“按需推理”和“精简推理”。

#### 2. 方法论：核心思想与关键技术
论文提出了一个端到端的优化框架，涵盖了从训练到部署的全流程：
*   **模块化推理适配器 (LoRA SFT)**：使用高质量推理轨迹（如 OpenThoughts3）对冻结的基座模型进行 LoRA 微调。通过这种方式，模型可以动态切换“聊天模式”和“推理模式”。
*   **预算强制强化学习 (Budget Forcing RL)**：采用 GRPO 算法，引入**乘法性软屏障（Soft-Barrier）奖励函数**。该函数在保证准确率的同时，对超过设定长度（如 1k, 3k tokens）的响应进行惩罚，迫使模型生成更精简的推理过程。
*   **动态路由切换器 (Switcher)**：在基座模型上添加轻量级分类头（MLP），在 Prefill 阶段判断查询复杂度。简单问题直接由基座模型回答，复杂问题才激活推理适配器。
*   **掩码 LoRA 训练与 KV 缓存共享**：在 Prefill 阶段禁用 LoRA 权重，使其仅在解码阶段激活。这允许基座模式和推理模式共享同一个 KV 缓存，避免了切换模式时的重复编码延迟。
*   **并行测试时缩放 (Parallel TTS)**：利用边缘端 NPU 的并行计算能力，同时生成多个推理流，并通过一个轻量级的**验证器头 (Verifier Head)** 进行加权投票，以极小的延迟代价提升准确率。
*   **量化感知推理 (QAMR)**：采用 W4A16KV8 量化方案（4位权重、16位激活、8位 KV 缓存），并结合函数保持变换（FPTQuant）来减少量化损失。

#### 6. 主要结论与发现
*   **LoRA 的有效性**：Rank 为 128 的 LoRA 适配器在 7B 模型上几乎能追平全参数微调的推理性能。

#### 7. 优点（亮点）
*   **端到端协同设计**：不仅关注算法，还考虑了 KV 缓存复用、NPU 并行特性等硬件底层优化。
*   **实用性极强**：解决了“推理模型太啰嗦”这一痛点，通过 RL 成功实现了推理逻辑的压缩。
*   **模块化**：Switcher + LoRA 的设计允许模型在低功耗和高性能模式间无缝切换。

#### 8. 不足与局限
*   **模型规模限制**：在更小的 3B 模型上，LoRA 适配器的表现与全参数微调仍有较大差距，说明小模型对适配器容量更敏感。

*   **预算桶固定**：目前的预算强制采用固定的长度桶（如 1k, 4k），未来可能需要更细粒度的语义感知预算分配。
