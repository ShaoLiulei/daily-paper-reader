## 摘要
大语言模型（LLMs）正越来越多地应用于推荐、检索和推理，但在大型异构目录上部署一个能够共同支持这些行为的单一端到端模型仍然具有挑战性。此类系统必须生成对真实物品的明确引用，处理多种实体类型，并在严格的延迟和可靠性约束下运行，而这些要求仅靠纯文本生成很难满足。虽然工具增强型推荐系统解决了部分问题，但它们引入了编排复杂性并限制了端到端优化。我们将这一场景视为一个更广泛研究问题的实例：如何使 LLMs 以完全自包含的方式对多领域实体、用户和语言进行联合推理。为此，我们引入了 NEO，这是一个将预训练的仅解码器（decoder-only）LLM 适配为无需工具、基于目录生成的框架。NEO 将物品表示为语义标识符（SIDs），并训练单一模型在共享序列中交织自然语言和有类型的物品标识符。文本提示控制任务、目标实体类型和输出格式（ID、文本或混合），而受限解码在不限制自由文本的情况下保证了生成目录有效的物品。我们将这种受指令调节的可控性称为“语言可操控性”（language-steerability）。我们将 SIDs 视为一种独特的模态，并研究了通过阶段性对齐和指令微调将离散实体表示集成到 LLMs 中的设计选择。我们在包含超过 1000 万个物品、跨越多种媒体类型和发现任务（包括推荐、搜索和用户理解）的真实世界目录上对 NEO 进行了大规模评估。在离线实验中，NEO 一贯优于强大的特定任务基准模型，并表现出跨任务迁移能力，展示了将大规模发现能力整合到单一语言可操控生成模型中的可行路径。

## Abstract
LLMs are increasingly applied to recommendation, retrieval, and reasoning, yet deploying a single end-to-end model that can jointly support these behaviors over large, heterogeneous catalogs remains challenging. Such systems must generate unambiguous references to real items, handle multiple entity types, and operate under strict latency and reliability constraints requirements that are difficult to satisfy with text-only generation. While tool-augmented recommender systems address parts of this problem, they introduce orchestration complexity and limit end-to-end optimization. We view this setting as an instance of a broader research problem: how to adapt LLMs to reason jointly over multiple-domain entities, users, and language in a fully self-contained manner. To this end, we introduce NEO, a framework that adapts a pre-trained decoder-only LLM into a tool-free, catalog-grounded generator. NEO represents items as SIDs and trains a single model to interleave natural language and typed item identifiers within a shared sequence. Text prompts control the task, target entity type, and output format (IDs, text, or mixed), while constrained decoding guarantees catalog-valid item generation without restricting free-form text. We refer to this instruction-conditioned controllability as language-steerability. We treat SIDs as a distinct modality and study design choices for integrating discrete entity representations into LLMs via staged alignment and instruction tuning. We evaluate NEO at scale on a real-world catalog of over 10M items across multiple media types and discovery tasks, including recommendation, search, and user understanding. In offline experiments, NEO consistently outperforms strong task-specific baselines and exhibits cross-task transfer, demonstrating a practical path toward consolidating large-scale discovery capabilities into a single language-steerable generative model.

论文探讨了如何在大规模（千万级物品）、异构（多种媒体类型）的工业级场景下，构建一个**统一的、自包含的生成式语言模型**来同时处理搜索、推荐和推理任务。
*   **研究动机**：传统的搜索和推荐系统通常是独立的架构，导致模型冗余、目标碎片化且运维成本高。
*   **现有挑战**：纯文本 LLM 在引用真实物品时存在歧义；工具增强型（Tool-augmented）系统编排复杂且延迟高；传统的生成式推荐模型通常只处理单一任务或单一物品类型，难以处理复杂的自然语言指令。
*   **核心目标**：开发名为 **NEO** 的框架，将 LLM 适配为无需外部工具、语言可操控（Language-steerable）且基于真实目录（Catalog-grounded）的生成器。

### 2. 方法论：核心思想与关键技术
NEO 的核心思想是将物品视为一种特殊的“模态”，通过**语义标识符（Semantic IDs, SIDs）**将其集成到 LLM 的词表和推理过程中。

*   **语义标识符 (SIDs)**：
    *   利用残差 K-means（Residual K-means）对物品的稠密向量进行层次化离散化，生成短序列（如 4 个 token）。
    *   这种结构保证了语义相近的物品在 ID 空间上也相近，有利于模型泛化。
*   **三阶段训练流程**：
    1.  **语义基础 (Stage 1)**：构建 SIDs，将物品内容转化为离散 token 序列。
    2.  **领域对齐 (Stage 2)**：在冻结 LLM 主干的情况下，训练 SID 的输入嵌入和输出头。通过“SID $\leftrightarrow$ 文本描述”的双向预测任务，让模型理解 SID 的语义含义，同时保留 LLM 的语言能力。
    3.  **能力诱导 (Stage 3)**：全参数微调（或 LoRA），进行多任务指令微调。任务包括：下一项推荐、基于文本的检索、推荐理由生成（Recsplanation）和用户兴趣画像。
*   **受限解码 (Constrained Decoding)**：
    *   在推理时，利用前缀树（Trie）强制模型在生成 SID 跨度内只能输出目录中真实存在的物品 ID，确保 100% 的有效性。

### 6. 主要结论与发现
*   **性能卓越**：NEO 在推荐和检索任务上均显著优于经过多年优化的生产级基准模型（如在有声读物推荐上 HR@10 提升了 46%）。
*   **语义 ID 的必要性**：相比原子 ID，SIDs 显著提升了模型在长尾物品和冷启动场景下的泛化能力。
*   **阶段性训练的价值**：先对齐再微调的策略比直接进行连续预训练（CPT）更能保留 LLM 的指令遵循能力和通用知识（MMLU 分数几乎无损）。
*   **语言可操控性**：模型能够根据自然语言指令灵活切换任务（如“推荐播客”或“解释为什么推荐这个艺人”）。

### 7. 优点
*   **架构统一**：成功将搜索、推荐和推理整合进单一模型，简化了系统栈。
*   **无需工具**：端到端的生成方式避免了 RAG 或工具调用带来的编排复杂性和高延迟。
*   **工业级扩展性**：证明了生成式检索在千万级异构目录上的可行性。
*   **可解释性**：能够同时输出物品 ID 和自然语言解释，增强了用户体验。

### 8. 不足与局限
*   **冷启动用户挑战**：对于完全没有历史行为的新用户，NEO 的表现仍略逊于使用了大量侧边特征（Side Features）的专门基准模型。
*   **ID 冲突处理**：当多个物品映射到同一个 SID 时，目前采用简单的流行度启发式方法处理，可能存在优化空间。
*   **训练复杂性**：虽然推理简单，但三阶段的训练流程比传统的监督微调更复杂，且对 SID 的质量依赖较高。
*   **实时性限制**：虽然比工具增强型快，但自回归生成多个 token 的延迟在极高性能要求的实时推荐场景下仍需进一步优化。
