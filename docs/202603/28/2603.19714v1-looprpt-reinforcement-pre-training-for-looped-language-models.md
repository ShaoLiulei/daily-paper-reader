## 摘要
循环语言模型 (LoopLMs) 通过执行迭代潜层计算来优化内部表示，为显式思维链 (CoT) 推理提供了一种极具前景的替代方案。然而，现有的强化学习 (RL) 范式主要针对输出 token，这与推理过程隐式展开的循环架构在结构上存在不匹配。在这项工作中，我们提出了 LoopRPT，这是一个专为 LoopLMs 定制的强化预训练框架。通过将下一 token 预测重新定义为下一 token 推理任务，LoopRPT 利用 EMA 教师参考和噪声潜层展开，将强化信号直接分配给潜层步骤。这种形式化方法使 RL 能够直接塑造中间表示，从而将有效的推理压缩到更少的迭代次数中。我们在多种模型规模的 Ouro 架构上实例化了 LoopRPT。结果表明，LoopRPT 持续提升了每步表示的质量，在准确率与计算量的权衡中实现了帕累托占优。值得注意的是，在困难 token 上的显著提升表明 LoopRPT 增强了早期推理，而不仅仅是鼓励提前退出。我们的研究结果强调，强化预训练是学习 LoopLMs 中高效潜层推理的一种原则性范式。

## Abstract
Looped language models (LoopLMs) perform iterative latent computation to refine internal representations, offering a promising alternative to explicit chain-of-thought (CoT) reasoning. However, existing reinforcement learning (RL) paradigms primarily target output tokens, creating a structural mismatch with looped architectures whose reasoning unfolds implicitly. In this work, we propose LoopRPT, a reinforcement pre-training framework tailored for LoopLMs. By reframing next-token prediction as a next-token reasoning task, LoopRPT assigns reinforcement signals directly to latent steps using an EMA teacher reference and noisy latent rollouts. This formulation enables RL to directly shape intermediate representations, compressing effective reasoning into fewer iterations. We instantiate LoopRPT on the Ouro architecture across multiple model scales. Results demonstrate that LoopRPT consistently improves per-step representation quality, achieving Pareto dominance in accuracy-computation trade-offs. Notably, significant gains on hard tokens indicate that LoopRPT enhances early-stage reasoning rather than merely encouraging premature exits. Our findings highlight reinforcement pre-training as a principled paradigm for learning efficient latent reasoning in LoopLMs.

### 1. 核心问题与整体含义（研究动机和背景）
*   **核心问题**：现代大语言模型（LLM）主要通过显式的“思维链”（CoT）生成来推理，这会消耗大量 token 且推理成本高。**循环语言模型（LoopLMs）**（如 Ouro 架构）通过在潜空间（Latent Space）进行迭代计算来优化内部表示，从而实现隐式推理。然而，现有的强化学习（RL）范式（如 RLVR）主要针对最终输出的 token，与循环架构中隐式展开的推理过程存在**结构性不匹配**，导致难以有效激励潜空间的迭代推理。
*   **整体含义**：本文提出了 **LoopRPT**，这是首个将**强化预训练（RPT）**引入循环语言模型的框架。它将“下一 token 预测”重构为“下一 token 推理”任务，通过直接对潜层迭代步骤施加强化信号，使模型在更少的迭代次数内实现更高效的推理。

### 2. 方法论：核心思想与关键技术
LoopRPT 的核心思想是利用教师模型的反馈为每一个潜层计算步骤提供密集的奖励信号。
*   **基于熵的困难 Token 选择**：并非所有 token 都需要强化。LoopRPT 使用教师模型的预测熵（Entropy）识别“困难 token”，仅在这些具有高信息量的位置进行强化训练，以提高采样效率。
*   **带有 EMA 教师的步进式奖励**：
    *   维护一个**指数移动平均（EMA）教师模型**作为稳定的参考基准。
    *   **准确率增益**：计算学生模型在每个迭代步 $k$ 的对数概率与教师模型参考步的差值。
    *   **难度感知的时间惩罚**：引入惩罚项以鼓励模型尽早退出，但对于高熵（困难）token，惩罚力度会减小，以确保充分推理。
*   **噪声潜层回测（Noisy Latent Rollouts）**：在循环隐藏状态中注入高斯噪声，通过多次随机采样（Rollouts）获得策略变体，并使用 **GRPO 风格**的分组归一化来优化退出策略（Exit Policy）。
*   **步权重的表示学习**：除了优化退出策略，还通过加权交叉熵损失显式强化中间步骤的表示质量，使早期步骤也能具备准确预测的能力。

### 3. 实验设计
*   **数据集**：主要使用 **OMNI-MATH**（包含 4,428 个竞赛级数学问题）进行强化预训练。
*   **模型规模**：在 **Ouro-1.4B** 和 **Ouro-2.6B** 两种规模上进行验证。
*   **Benchmark 与对比方法**：
    *   **下一 token 推理（NTR）**：在验证集上按难度（简单/中等/困难）评估准确率与平均计算步数。
    *   **下游任务**：通用任务（MMLU, BBH, ARC-C 等）、数学（GSM8K）和代码（HumanEval, MBPP）。
    *   **对比对象**：包括原始 Ouro 模型、Qwen2.5/3 系列、Llama3.1/3.2、Gemma3 等同规模的非循环 Transformer 模型。

### 4. 资源与算力
*   **硬件环境**：使用了 **8 台 NVIDIA A100 (80GB) GPU**。
*   **训练时长**：Ouro-1.4B 训练约 **2 小时**，Ouro-2.6B 训练约 **4 小时**。
*   **软件框架**：基于 Hugging Face 和 Accelerate 实现，采用混合精度和梯度检查点技术。

### 5. 实验数量与充分性
*   **实验规模**：涵盖了从 1.4B 到 2.6B 的模型缩放实验，并在 11 个主流 benchmark 上进行了广泛测试。
*   **消融实验**：详细分析了高斯噪声、策略梯度损失（LPG）、表示学习损失（Lrep）、Token 选择和时间惩罚对性能的影响。
*   **敏感性分析**：探讨了序列长度、KL 正则化系数和 GRPO 分组大小对结果的影响。
*   **充分性评价**：实验设计较为全面，通过帕累托曲线（精度 vs. 计算量）直观展示了方法的优越性，对比实验涵盖了多种主流开源模型，结果具有较强的说服力和客观性。

### 6. 主要结论与发现
*   **帕累托占优**：LoopRPT 在所有难度级别上均实现了比原始 Ouro 模型更高的准确率和更少的平均推理步数。
*   **早期推理增强**：LoopRPT 显著提升了中间步骤（尤其是第 1、2 步）的表示质量，证明其不仅是让模型“早退”，而是让模型“学得更快、更准”。
*   **下游迁移能力**：在数学和代码任务上提升显著，例如在 2.6B 规模下，GSM8K 准确率从 81.76 提升至 85.36，MBPP+ 提升了 2.91 个百分点。
*   **退出策略校准**：模型能够根据 token 难度更智能地分配计算资源，困难 token 保留深度推理，简单 token 快速通过。

### 7. 优点
*   **解决信度分配问题**：通过步进式奖励（Step-wise Rewards）解决了循环架构中 token 级奖励过于稀疏、难以指导中间迭代的问题。
*   **计算效率极高**：相比显式 CoT，LoopRPT 在不增加参数量和 token 成本的前提下，通过潜层迭代提升了推理深度。
*   **训练稳定**：引入 EMA 教师和 K3 风格的 KL 散度约束，有效缓解了强化学习过程中的策略坍塌和不稳定性。

### 8. 不足与局限
*   **模型规模限制**：目前实验最高仅达到 2.6B 规模，尚未在百亿或千亿级参数模型上验证其扩展性。
*   **数据领域偏差**：预训练主要集中在数学竞赛数据（OMNI-MATH），虽然在通用任务上有提升，但其在更广泛、非推理类任务上的泛化表现仍有待观察。
*   **强制深度退化**：实验发现，如果强制模型运行到最大深度，性能有时会下降（非单调提升），这反映出循环模型在极深迭代时可能存在表示偏移或过拟合风险。
