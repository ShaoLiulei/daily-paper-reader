## 摘要
本研究介绍了 AdditiveLLM2，这是一种多模态、领域自适应的大语言模型，基于 Gemma 3 模型的指令微调变体构建，并使用了约 5000 万个 token 的相对较小的数据集。该数据集（AdditiveLLM2-OA）由开放获取的增材制造期刊文章组成，提取的数据用于领域自适应预训练和视觉指令微调过程。所开发模型的各个阶段均使用 Additive-Manufacturing-Benchmark 进行评估，该基准由从已发表资源中汇编的增材制造领域特定任务组成。AdditiveLLM2 在基于语言和视觉的任务中均表现出极高的熟练度，在通用增材制造知识方面的准确率超过 90%。这种领域自适应预训练和指令微调策略为大语言模型在增材制造等领域的专业化提供了一种易于实现的途径。

## Abstract
This work presents AdditiveLLM2 a multi-modal, domain adapted large language model built upon the instruction tuned variant of the Gemma 3 model using a relatively small dataset of around 50 million tokens. The dataset (AdditiveLLM2-OA) consists of open-access additive manufacturing journal articles with data extracted for the domain adaptive pretraining and visual instruction tuning processes. Various stages of the developed model are evaluated with the Additive-Manufacturing-Benchmark which consists of additive manufacturing domain specific tasks compiled published resources. AdditiveLLM2 exhibits proficiency in both language and vision based tasks, achieving accuracies upwards of 90% in general additive manufacturing knowledge. This domain adaptive pretraining and instruction tuning strategy outline an accessible specialization method for large language models to a domain such as additive manufacturing.

### 2. 方法论：核心思想与关键技术
*   **核心思想**：采用分阶段的领域适配策略，利用相对较小但高质量的专业数据集（约5000万token），通过参数高效微调技术（LoRA）对多模态模型进行专业化改造。
*   **关键技术流程**：
    1.  **数据构建 (AdditiveLLM2-OA)**：从《Journal of Additive Manufacturing》等四本顶级开源期刊中提取1,704篇文章，包含2900万文本token和2.4万张专业图像及其说明文字。
    2.  **三阶段训练方案**：
        *   **阶段1：文本领域自适应预训练 (DAPT-Text)**：在AM专业文本上进行次标记预测训练，学习领域术语和逻辑。
        *   **阶段2：图像领域自适应预训练 (DAPT-Images)**：冻结语言权重，训练视觉塔（Vision Tower）将AM专业图像（如显微组织、设备图）与文本说明关联。
        *   **阶段3：视觉指令微调 (VIT)**：利用由 GPT-OSS 120B 生成的2万组对话和详细描述数据，对语言和视觉权重进行联合微调，提升问答和推理能力。
    3.  **微调技术**：使用 LoRA（秩 $r=16$，$\alpha=32$），仅针对自注意力机制中的 Q、K、V 和 O 投影层进行更新。

### 3. 实验设计
*   **数据集**：训练使用自建的 **AdditiveLLM2-OA** 数据集；评估使用新开发的 **Additive-Manufacturing-Benchmark**。

*   **实验规模**：针对每个基准任务进行了 **5 次独立试验**并取平均值，以确保结果的统计显著性。

### 6. 主要结论与发现
*   **性能卓越**：AdditiveLLM2 在通用 AM 知识任务中达到了 **90% 以上的准确率**，显著超过基座模型。
*   **多模态优势**：经过视觉指令微调（VIT）后，模型在机器识别和 LPBF 异常检测等视觉任务上表现最佳。

*   **高效适配**：展示了一种在有限算力和数据下，快速将通用大模型转化为工业专家模型的可行路径。
