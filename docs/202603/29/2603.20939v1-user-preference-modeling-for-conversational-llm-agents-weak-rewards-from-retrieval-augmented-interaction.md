## 摘要
大语言模型越来越多地被用作个人助手，但大多数模型缺乏持久的用户模型，导致用户在不同会话中不得不重复陈述偏好。我们提出了向量自适应检索评分（VARS），这是一个与流水线无关且采用冻结主干的框架。该框架在共享偏好空间中利用长期和短期向量来表示每个用户，并使用这些向量来偏置结构化偏好记忆上的检索评分。这些向量根据用户反馈的弱标量奖励进行在线更新，从而在无需针对每个用户进行微调的情况下实现个性化。我们在 MultiSessionCollab 上进行了评估，这是一个具有丰富用户偏好配置文件的在线多会话协作基准，涵盖了数学和代码任务。在冻结主干的情况下，用户感知检索的主要优势在于提高交互效率，而非大幅提升原始任务准确率：我们的完整 VARS 智能体实现了最强的综合性能，在任务成功率上与强大的 Reflection 基准相当，并降低了超时率和用户工作量。学习到的长期向量还与跨用户偏好重叠相一致，而短期向量则捕捉到了特定会话的适应性，这支持了双向量设计的可解释性。代码、模型和数据可在 https://github.com/YurenHao0426/VARS 获取。

## Abstract
Large language models are increasingly used as personal assistants, yet most lack a persistent user model, forcing users to repeatedly restate preferences across sessions. We propose Vector-Adapted Retrieval Scoring (VARS), a pipeline-agnostic, frozen-backbone framework that represents each user with long-term and short-term vectors in a shared preference space and uses these vectors to bias retrieval scoring over structured preference memory. The vectors are updated online from weak scalar rewards from users' feedback, enabling personalization without per-user fine-tuning. We evaluate on \textsc{MultiSessionCollab}, an online multi-session collaboration benchmark with rich user preference profiles, across math and code tasks. Under frozen backbones, the main benefit of user-aware retrieval is improved interaction efficiency rather than large gains in raw task accuracy: our full VARS agent achieves the strongest overall performance, matches a strong Reflection baseline in task success, and reduces timeout rate and user effort. The learned long-term vectors also align with cross-user preference overlap, while short-term vectors capture session-specific adaptation, supporting the interpretability of the dual-vector design. Code, model, and data are available at https://github.com/YurenHao0426/VARS.

*   **研究背景**：虽然现有的检索增强生成（RAG）或长文本技术可以回顾历史，但它们通常仅依赖查询相似度进行检索，而没有一个持续更新的“用户状态”来优先处理对特定用户最重要的偏好。
*   **整体含义**：本文旨在开发一种轻量级框架，在不微调大模型主干参数的前提下，通过交互产生的弱反馈信号来学习用户表征，从而优化偏好信息的检索质量。

### 2. 方法论：VARS 框架
VARS（Vector-Adapted Retrieval Scoring）由四个核心组件组成，构建在冻结的 LLM、嵌入模型和重排序器之上：
*   **偏好提取（Preference Extraction）**：使用一个轻量级微调模型（Qwen3-0.6B）将对话窗口转换为结构化的 JSON 偏好卡片（条件-动作规则）。
*   **双向量用户状态（Dual-Vector User State）**：
    *   **长期向量 ($z^{(L)}$)**：跨会话持久存在，捕捉用户稳定的风格偏好。
    *   **短期向量 ($z^{(S)}$)**：会话内更新并随时间衰减，捕捉瞬时上下文。
    *   **有效向量**：$z_{eff} = \beta_L z^{(L)} + \beta_S z^{(S)}$。
*   **用户感知检索评分**：在原始重排序分数的基础上，增加一个用户向量与记忆项向量（通过 PCA 投影到共享空间）的点积偏置项。
*   **在线强化学习更新**：
    *   **弱奖励获取**：通过启发式规则（关键词匹配如“谢谢”、“错误”及主题连贯性）从用户的下一轮回复中提取标量奖励 $\hat{r}_t$。
    *   **更新机制**：采用 REINFORCE 风格的算法，根据奖励信号调整用户向量，使其向被选中的记忆项靠近（正反馈）或远离（负反馈）。

### 3. 实验设计
*   **数据集/场景**：使用 **MultiSessionCollab** 基准测试，包含数学（Math-hard, Math-500）和代码（BigCodeBench）任务。
*   **Benchmark 设置**：模拟 60 个具有独特偏好配置文件的用户，每个用户进行 60 个会话，总计 3600 个会话。
*   **对比方法（Baselines）**：
    *   **Vanilla**：无记忆。
    *   **Contextual**：全历史拼接。
    *   **All-memory**：拼接所有提取的偏好。
    *   **Reflection**：基于会话总结的反射机制（强基准）。
    *   **RAG**：标准检索重排序，无用户向量。

### 4. 资源与算力
*   **模型使用**：智能体使用 Llama-3.1-8B，用户模拟器使用 Llama-3.3-70B，嵌入和重排序使用 Qwen3-8B 系列。
*   **训练算力**：偏好提取器（0.6B 模型）在 **H200 GPU** 上进行了全参数微调（SFT），使用了约 56.4 万条样本。
*   **推理算力**：主干模型保持冻结，用户向量更新仅涉及低维向量运算（256维），计算开销极低。

### 5. 实验数量与充分性
*   **实验规模**：进行了 3600 个完整会话的评估，规模较大，足以覆盖长程交互的动态变化。
*   **消融实验**：针对长期向量与短期向量的作用进行了专门的消融研究（见表5），验证了双向量设计的必要性。
*   **客观性**：使用了配对 t 检验（Paired t-tests）来验证 VARS 相对于 Reflection 基准的显著性，实验设计较为严谨。

### 6. 主要结论与发现
*   **效率提升是核心**：在冻结主干模型的情况下，VARS 的主要贡献不是大幅提升任务成功率（与 Reflection 相当），而是显著**提高了交互效率**。它降低了超时率，并减少了用户为了纠正模型而输入的 Token 数量。
*   **缓解偏好过载**：相比于简单的 RAG，VARS 通过用户向量过滤了无关偏好，避免了模型因注入过多冲突信息而产生的“无所适从”。
*   **向量的可解释性**：学习到的长期向量在空间上的分布与用户真实的偏好重叠度（Jaccard 相似度）呈正相关，证明向量确实捕捉到了用户身份。

### 7. 优点
*   **非侵入性**：无需对每个用户进行模型微调，仅通过更新轻量级向量即可实现个性化，适合大规模部署。
*   **冷启动与自适应平衡**：双向量机制既保留了历史记忆，又能快速响应当前会话的特殊需求。
*   **结构化记忆**：将偏好存储为“条件-动作”卡片，比纯文本历史更易于精准检索和利用。

### 8. 不足与局限
*   **奖励信号较弱**：目前依赖关键词匹配和启发式规则获取奖励，可能无法捕捉复杂的、隐含的用户不满。
*   **模拟器偏差**：实验完全依赖 LLM 模拟用户，模拟器的耐心程度和反馈模式可能与真实人类用户存在差异。
*   **超参数敏感性**：学习率、衰减率和向量权重等超参数需要手动调优，目前缺乏自动化的优化手段。
*   **隐私风险**：持久化的用户偏好建模和向量存储涉及用户画像，需严格的隐私保护机制。
