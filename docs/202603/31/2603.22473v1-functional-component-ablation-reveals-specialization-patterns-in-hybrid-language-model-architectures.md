## 摘要
结合了注意力机制与状态空间模型（SSM）或线性注意力的混合语言模型提升了效率，但这两个组件是否都得到了真实利用仍不明确。我们提出了一个功能组件消融框架，并将其应用于两个 1B 参数量以下的混合模型——Qwen3.5-0.8B（串联结构：Gated DeltaNet + softmax 注意力）和 Falcon-H1-0.5B（并联结构：Mamba-2 + 注意力），并以纯 Transformer 模型（Qwen2.5-0.5B）作为对照。通过在五个基准测试上进行分组消融、逐层扫描、位置消融、匹配随机对照以及困惑度分析，我们得出了四个发现：(1) 两种组件类型都是必不可少的，且都没有被绕过；(2) 替代组件（线性注意力或 SSM）是主要的语言建模骨干，移除后会导致困惑度恶化超过 35,000 倍，而移除注意力机制仅导致约 82 倍的恶化；(3) 组件重要性遵循位置梯度，早期层具有不成比例的关键性；(4) 混合架构对随机层移除的韧性比纯 Transformer 高出 20-119 倍，揭示了组件类型之间内置的功能冗余。这些结果为混合模型的压缩、架构设计和容错部署提供了可操作的指导。

## Abstract
Hybrid language models combining attention with state space models (SSMs) or linear attention offer improved efficiency, but whether both components are genuinely utilized remains unclear. We present a functional component ablation framework applied to two sub-1B hybrid models -- Qwen3.5-0.8B (sequential: Gated DeltaNet + softmax attention) and Falcon-H1-0.5B (parallel: Mamba-2 + attention) -- with a pure Transformer control (Qwen2.5-0.5B). Through group ablations, layer-wise sweeps, positional ablations, matched random controls, and perplexity analysis across five benchmarks, we establish four findings: (1) both component types are essential and neither is bypassed; (2) the alternative component (linear attention or SSM) is the primary language modeling backbone, causing >35,000x perplexity degradation when removed versus ~82x for attention; (3) component importance follows a positional gradient, with early layers being disproportionately critical; and (4) hybrid architectures exhibit 20-119x greater resilience to random layer removal than pure Transformers, revealing built-in functional redundancy between component types. These results provide actionable guidance for hybrid model compression, architecture design, and fault-tolerant deployment.

### 1. 核心问题与整体含义（研究动机和背景）
随着 Transformer 架构在处理长序列时面临二次方复杂度的挑战，结合了**状态空间模型（SSM，如 Mamba）**或**线性注意力（Linear Attention）**与传统 **Softmax 注意力**的混合架构应运而生。然而，学术界一直存在疑问：这些模型在训练后，替代组件是否真的发挥了作用，还是仅仅作为“摆设”被模型绕过而主要依赖注意力路径？本研究通过系统性的消融实验，试图厘清混合模型中各组件的真实贡献、位置敏感性以及架构韧性。

### 2. 论文提出的方法论
研究者提出了一个**可逆的功能组件消融框架**，针对两种截然不同的混合架构设计了特定的消融机制：
*   **核心思想**：在推理阶段通过前向钩子（Forward Hooks）动态禁用特定组件，观察模型性能的变化，而不改变模型权重。
*   **关键技术细节**：
    *   **串联跳过（Sequential Skip）**：针对 **Qwen3.5**（层间交替架构），将目标层的输出替换为输入，使其在残差流中变为恒等函数（$h_{l+1} = h_l$）。
    *   **并联归零（Parallel Zeroing）**：针对 **Falcon-H1**（层内并联架构），将特定组件（如 SSM 路径）的输出贡献设为零，仅保留另一路径（如注意力路径）的输出。
*   **分析维度**：包括分组消融（禁用所有同类组件）、逐层扫描（每次禁用一层）、位置消融（按前、中、后段禁用）以及匹配的随机对照实验。

### 3. 实验设计
*   **研究对象**：
    *   **Qwen3.5-0.8B**：串联混合（18层线性注意力 + 6层全注意力）。
    *   **Falcon-H1-0.5B**：并联混合（36个 Block，每个 Block 同时包含 Mamba-2 和注意力）。
    *   **Qwen2.5-0.5B**：纯 Transformer 对照组。
*   **数据集与 Benchmark**：
    *   **任务性能**：MMLU（知识）、GSM8K（数学推理）、ARC-Challenge（科学推理）、HellaSwag（常识）、TruthfulQA（事实性）。
    *   **语言建模能力**：WikiText-2 上的困惑度（Perplexity, PPL）。
*   **对比方法**：将针对性消融与“随机移除相同数量层”的基准进行对比，以排除单纯因层数减少导致性能下降的干扰。

### 4. 资源与算力
*   论文明确指出选择 **sub-1B（10亿参数以下）** 模型是为了确保实验的详尽性（如 84 种以上的消融组合）和可复现性。

### 5. 实验数量与充分性
*   **实验规模**：每台模型进行了超过 **84 种消融条件**的测试，涵盖了从宏观（全组件）到微观（单层）的各个层面。
*   **充分性与客观性**：
    *   引入了**自助法（Bootstrap）置信区间**进行统计验证。
    *   设置了**随机对照组**，证明了性能下降并非随机干扰。
    *   对比了串联与并联两种主流混合架构，实验设计严谨且具有代表性。

### 6. 主要结论与发现
1.  **组件不可或缺**：没有任何组件是被绕过的。移除任一类型组件都会导致性能严重下降，尤其在数学推理（GSM8K）上几乎完全崩溃。
2.  **替代组件是“骨干”**：困惑度分析显示，线性注意力或 SSM 承担了主要的语言建模任务。移除它们会导致 PPL 爆炸式增长（最高达 35,000 倍），而移除注意力机制的影响相对较小（约 3-82 倍）。
3.  **位置梯度效应**：早期层（Early Layers）的重要性远高于后期层。消融第一层组件造成的损害通常是消融最后一层的 2-5 倍。
4.  **混合架构的韧性**：混合模型对随机层移除的容错能力显著强于纯 Transformer（韧性高出 20-119 倍），这表明不同组件间存在功能冗余和互补。

### 7. 优点
*   **系统性强**：首次全面对比了串联和并联两种混合架构的内部运作机制。
*   **指标灵敏**：发现困惑度（PPL）比标准 Benchmark 评分更能揭示组件间的本质差异。
*   **实用价值高**：为模型剪枝（Pruning）和蒸馏（Distillation）提供了直接指导（如应优先保留早期层和骨干组件）。

### 8. 不足与局限
*   **模型规模限制**：研究集中在 sub-1B 模型，虽然结论具有启发性，但尚不确定这些模式在 7B 或 70B 等更大规模模型中是否会发生改变（如专业化程度是否会进一步加深）。
*   **消融非重训**：功能消融反映的是推理时的依赖性，并不完全等同于“如果从头开始不训练该组件”的结果。
*   **长文本评估不足**：实验主要基于标准 Benchmark，未充分测试 SSM 在极长上下文场景下的组件依赖变化。
