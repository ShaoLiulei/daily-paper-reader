## 摘要
注意力机制一直是现代 Transformer 架构的核心组件。然而，标准全注意力的计算量随序列长度呈二次方增长，成为长上下文语言建模的主要瓶颈。滑动窗口注意力通过限制上下文长度来提高效率，但代价是感受野变窄。虽然现有研究尝试通过构建混合模型来兼顾两者的优点，但它们通常采用静态的、基于启发式设计的交替模式，这限制了在各种场景下计算资源的有效分配。在本文中，我们提出了 Switch Attention (SwiAttn)，这是一种新型混合 Transformer，能够在全注意力和滑动窗口注意力之间实现动态且细粒度的路由。对于每个 Transformer 层中的每个 token，SwiAttn 动态地将计算路由到用于全局信息聚合的全注意力分支，或用于高效局部模式匹配的滑动窗口分支。我们设计了一个自适应正则化目标，以鼓励模型提高效率。此外，我们采用持续预训练来优化模型，将全注意力架构转换为混合架构。我们在 23 个基准数据集上进行了广泛实验，涵盖了常规（4K）和长（32K）上下文长度，证明了所提方法的有效性。

## Abstract
The attention mechanism has been the core component in modern transformer architectures. However, the computation of standard full attention scales quadratically with the sequence length, serving as a major bottleneck in long-context language modeling. Sliding window attention restricts the context length for better efficiency at the cost of narrower receptive fields. While existing efforts attempt to take the benefits from both sides by building hybrid models, they often resort to static, heuristically designed alternating patterns that limit efficient allocation of computation in various scenarios. In this paper, we propose Switch Attention (SwiAttn), a novel hybrid transformer that enables dynamic and fine-grained routing between full attention and sliding window attention. For each token at each transformer layer, SwiAttn dynamically routes the computation to either a full-attention branch for global information aggregation or a sliding-window branch for efficient local pattern matching. An adaptive regularization objective is designed to encourage the model towards efficiency. Moreover, we adopt continual pretraining to optimize the model, transferring the full attention architecture to the hybrid one. Extensive experiments are conducted on twenty-three benchmark datasets across both regular (4K) and long (32K) context lengths, demonstrating the effectiveness of the proposed method.

#### 1. 核心问题与整体含义（研究动机和背景）
现代 Transformer 架构的核心是注意力机制，但标准全注意力（Full Attention）的计算复杂度随序列长度呈二次方增长（$O(L^2)$），成为处理长文本的主要瓶颈。为了平衡效率与性能，现有研究通常采用“混合模型”（如滑动窗口注意力 SWA 与全注意力的结合），但这些模型大多依赖**静态、启发式**的设计（例如固定每隔几层使用一次全注意力）。这种静态分配无法根据输入内容的复杂程度灵活调整计算资源。本文旨在提出一种**动态且细粒度**的路由机制，让模型在 Token 级别和层级别自主决定计算路径。

#### 2. 方法论：核心思想与关键技术
SwiAttn 的核心是引入了一个**动态路由分支结构**，主要包含以下技术细节：
*   **双分支路由（Dual-branch Routing）**：在每个 Transformer 层的注意力模块前放置一个轻量级路由器（Router）。对于每个输入 Token，路由器输出一个门控值（Gate），决定该 Token 是进入“全注意力分支”（获取全局信息）还是“滑动窗口分支”（高效局部匹配）。
*   **共享机制**：为了保证效率，两个分支共享相同的查询（Q）、键（K）、值（V）线性映射。在推理阶段，两个分支共享同一个 KV Cache。
*   **自适应正则化（Adaptive Regularization）**：为了防止模型过度依赖全注意力，设计了正则化损失函数。该函数具有自适应性：当 Token 预测难度大（负对数似然 NLL 高）或两个分支输出差异大（MSE 高）时，减小正则化强度，允许模型使用全注意力；反之则强制模型使用更高效的 SWA。
*   **持续预训练（Continual Pretraining, CPT）**：SwiAttn 不需要从头训练，而是通过持续预训练从现有的全注意力预训练模型转换而来，继承其已有的语言建模能力，显著降低了训练成本。

*   **数据集与场景**：涵盖了 23 个基准数据集，分为三类：

    2.  **上下文检索**（如 SWDE, TriviaQA, SQuAD 等 6 个）：验证 4K 长度内的信息提取能力。
    3.  **长文本理解**（LongBench-E 中的 7 个任务）：验证高达 32K 长度的上下文处理能力。
*   **对比方法（Baselines）**：
    *   **FullAttn**：标准全注意力模型。

    *   **StaticHybrid**：工业界常用的静态混合方案（全注意力与 SWA 比例为 1:3）。

*   **硬件平台**：所有实验均在 **Ascend 910C NPU** 上完成。
*   **训练细节**：

*   **模型配置**：22 层，隐藏层维度 2048，SWA 窗口大小设为 1024。

#### 5. 实验数量与充分性
*   **实验规模**：论文在 23 个数据集上进行了详尽测试，并额外进行了“大海捞针”（Needle-in-a-Haystack）测试。
*   **消融实验**：针对自适应正则化中的 NLL 项、MSE 项以及超参数 $\alpha, \epsilon$ 进行了 7 组变体对比（V1-V7），验证了各组件的必要性。
*   **充分性评价**：实验设计较为全面，覆盖了从短文本到长文本、从基础推理到复杂检索的多个维度。通过可视化路由比例和推理效率曲线，客观展示了动态路由的优越性。

#### 6. 主要结论与发现
*   **性能卓越**：SwiAttn 在长文本任务上超越了所有基线（包括全注意力模型），在常识推理和检索任务上与全注意力模型持平。
*   **极高效率**：在 32K 上下文下，SwiAttn 在解码阶段实现了 **4x 至 12x 的加速**。

#### 7. 优点与亮点
*   **细粒度动态化**：打破了层级静态混合的传统，实现了 Token 级别的按需计算分配。
*   **训练效率高**：通过持续预训练（CPT）实现架构转换，避免了昂贵的从头预训练过程。
*   **自适应正则化设计**：巧妙地结合了模型预测的不确定性（NLL）来动态调整计算开销。
*   **KV Cache 友好**：共享 KV Cache 的设计解决了混合模型在推理时的内存管理难题。

*   **硬件算子优化**：论文提到目前在 Prefill（预填充）阶段尚缺乏针对这种动态双分支结构的硬件级高效算子实现，实际加速比仍有提升空间。
*   **模型规模限制**：实验主要集中在 1.5B 参数规模，尚未在百亿（10B+）或千亿级参数的大模型上验证其扩展性（Scaling Law）。
*   **复杂度增加**：引入路由器和双分支结构增加了模型实现的复杂度和训练时的超参数调优难度。
