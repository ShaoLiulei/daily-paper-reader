## 摘要
扩展自回归大语言模型（LLM）推动了前所未有的进步，但也带来了巨大的计算成本。在这项工作中，我们通过利用 LLM 前馈层中的非结构化稀疏性来解决这些成本问题，前馈层是占据模型大部分参数和执行 FLOPs 的组件。为了实现这一目标，我们引入了一种新的稀疏打包格式和一组 CUDA 内核，旨在与现代 GPU 的优化执行流水线无缝集成，从而在 LLM 推理和训练期间实现高效的稀疏计算。为了证实我们的收益，我们对 LLM 稀疏性进行了定量研究，证明简单的 L1 正则化可以诱导超过 99% 的稀疏性，且对下游性能的影响微乎其微。当与我们的内核结合使用时，我们展示了这些稀疏水平可以转化为显著的吞吐量、能效和内存使用优势，且这些优势随模型规模的扩大而增加。我们将以开源许可证发布所有代码和内核，以促进采用并加速相关研究，旨在将稀疏性确立为提高现代基础模型效率和可扩展性的实用维度。

## Abstract
Scaling autoregressive large language models (LLMs) has driven unprecedented progress but comes with vast computational costs. In this work, we tackle these costs by leveraging unstructured sparsity within an LLM's feedforward layers, the components accounting for most of the model parameters and execution FLOPs. To achieve this, we introduce a new sparse packing format and a set of CUDA kernels designed to seamlessly integrate with the optimized execution pipelines of modern GPUs, enabling efficient sparse computation during LLM inference and training. To substantiate our gains, we provide a quantitative study of LLM sparsity, demonstrating that simple L1 regularization can induce over 99% sparsity with negligible impact on downstream performance. When paired with our kernels, we show that these sparsity levels translate into substantial throughput, energy efficiency, and memory usage benefits that increase with model scale. We will release all code and kernels under an open-source license to promote adoption and accelerate research toward establishing sparsity as a practical axis for improving the efficiency and scalability of modern foundation models.

### 1. 核心问题与整体含义（研究动机和背景）
*   **研究动机**：随着大语言模型（LLM）规模的不断扩大，计算成本、能耗和内存需求急剧增加。前馈网络（FFN）层占据了模型约 2/3 的参数和超过 80% 的计算量（FLOPs）。
*   **核心矛盾**：虽然研究表明 LLM 的 FFN 层存在天然的激活稀疏性，但由于现代 GPU 架构（如 NVIDIA H100）是为稠密矩阵运算高度优化的，传统的非结构化稀疏操作在实际运行中往往比稠密运算更慢。
*   **整体含义**：本文旨在打破“稀疏计算在 GPU 上不实用”的悖论，通过软硬件协同设计，使非结构化稀疏性成为提升 LLM 效率的实际手段。

### 2. 方法论：核心思想与技术细节
*   **核心思想**：引入新型稀疏数据格式 **TwELL** 和 **Hybrid 格式**，并开发定制化的 CUDA 内核，将稀疏操作无缝集成到 GPU 的执行流水线中。
*   **关键技术细节**：
    *   **TwELL (Tile-wise ELLPACK)**：一种专为内核融合设计的稀疏格式。它将矩阵列划分为 1D Tile，在计算门控激活（Gate Activation）的同时，直接在 GPU 共享内存中完成非零值的提取和索引打包，避免了额外的全局内存访问和同步开销。
    *   **推理内核融合**：在推理阶段，将 Up Projection 和 Down Projection 融合进单个内核。利用 TwELL 格式，仅对非零激活对应的权重进行点积运算，大幅减少 DRAM 带宽占用。
    *   **训练 Hybrid 格式**：针对训练中稀疏模式极度不均匀的特点，采用“紧凑 ELL + 稠密备份（Dense Backup）”的混合方案。绝大多数稀疏行存入 ELL，极少数稠密行（离群值）存入稠密矩阵，确保计算负载均衡。
    *   **稀疏诱导机制**：采用 ReLU 激活函数代替 SiLU，并引入简单的 **L1 正则化损失** 来鼓励激活稀疏化。

### 6. 主要结论与发现
*   **极高稀疏度**：通过轻微的 L1 正则化，可以诱导超过 **99%** 的激活稀疏度，而下游任务性能几乎无损（性能下降在 2% 以内）。
*   **显著提速**：在 2B 规模模型上，稀疏内核使推理前向传播提速 **20.5%**，训练步骤提速 **21.9%**。
*   **资源节省**：训练时的峰值内存需求降低了约 **28%**，能效提升显著。
*   **规模效应**：模型规模越大，稀疏性带来的效率收益越明显，这符合当前 LLM 的缩放趋势。
*   **输入特性**：模型会自动将计算资源分配给信息量更高的 Token（如特定名词、动词）以及序列起始位置的 Token。

### 7. 优点：亮点与创新
*   **软硬结合**：不只是理论研究，而是提供了能在现代 GPU 上跑出真实加速比的 CUDA 内核。
*   **全生命周期优化**：同时解决了推理和训练两个阶段的稀疏加速问题。
*   **开源贡献**：作者承诺开源所有代码和内核，有助于稀疏性研究在社区的普及。
*   **实用性强**：不需要对 Transformer 架构做根本性改变（如 MoE 那样复杂的路由），只需更换激活函数和增加正则项。

### 8. 不足与局限
*   **激活函数限制**：必须使用 ReLU 才能获得最佳稀疏效果，虽然实验证明 ReLU 与 SiLU 差距微小，但在某些极高性能要求的场景下，SiLU 仍有微弱优势。
*   **超参数敏感性**：L1 正则化系数需要针对不同规模的模型进行微调，以平衡稀疏度与性能。
*   **覆盖范围**：目前优化主要集中在 FFN 层，虽然 FFN 占大头，但 Attention 层的稀疏化未在本文中深入探讨。
*   **死神经元风险**：高稀疏度下容易出现神经元永久失活，虽然文中提出了缓解策略，但这仍是稀疏训练的一个潜在不稳定性因素。
