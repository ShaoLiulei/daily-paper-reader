## 摘要
在本文中，我们提出了一个新颖的见解：现成的大语言模型（LLM）可以作为出色的 Token 压缩器和解压器。为了证明这一点，我们设计了一个自表达自编码学习框架，通过微调预训练 LLM，将长文本转换为一种由离散、变长潜码组成的紧凑内部语言（称为 Z-token），并能从中精确重建原始文本。所生成的表示具有内容自适应性：通过轻量级的基于 LoRA 的适配器头，语义密集的片段会分配到更多 Z-token，而冗余或可预测的区域则会被大幅压缩。实验表明，我们的方法在 Wikipedia、CNN/DailyMail、HotpotQA 和 Qulac 风格的长查询数据集上实现了高达 18 倍的 Token 缩减，同时保持了重建保真度和下游任务性能。这种简单而有效的设计支持包括提示词压缩和直接在 Z-token 空间进行自回归生成在内的多种应用，为实现 Token 高效的长上下文推理提供了一条潜在路径。

## Abstract
In this paper, we establish the novel insight that an off-the-shelf LLM can function as an excellent token compressor and decompressor. To demonstrate, we design a self-expressive autoencoding learning framework fine-tunes a pretrained LLM to translate long texts into a compact internal language of discrete, variable-length latent codes, termed Z-tokens, and to reconstruct the original text exactly from them. The resulting representation is content-adaptive: semantically dense segments receive more Z-tokens, while redundant or predictable regions are aggressively compressed, via lightweight LoRA-based adapter heads. Empirically, our method achieves up to 18 times token reduction on Wikipedia, CNN/DailyMail, HotpotQA, and Qulac-style long-query datasets, while preserving reconstruction fidelity and downstream performance. This simple yet effective design supports applications including prompt compression and autoregressive generation directly in the Z-token space, offering a potential pathway toward token-efficient long-context reasoning.

### 1. 核心问题与整体含义（研究动机和背景）
大语言模型（LLM）在处理长上下文时面临核心瓶颈：注意力机制的计算复杂度随序列长度呈平方级增长。现有的 Token 压缩技术主要分为两类：
*   **启发式方法**（如 Token 合并或剪枝）：虽然简单，但容易丢失难以恢复的语用信息。
*   **学习型方法**（如 ICAE、AutoCompressor）：通常将上下文压缩为固定长度的连续向量（Soft Embeddings），缺乏透明度、不可解释，且无法根据信息密度动态调整压缩率。

**本研究的核心动机**是利用 LLM 自身的语义抽象能力，将其视为一种“翻译器”，将自然语言翻译成一种更紧凑的内部离散语言（Z-tokens），从而实现高效、变长且可还原的文本压缩。

### 2. 方法论：核心思想与关键技术
该研究提出了一个自表达的自动编码框架，包含三个核心组件：**压缩器（Compressor）**、**解压器（Decompressor）**和**推理器（Inferencer）**。

*   **核心思想**：将压缩视为一种“双语翻译”，即 LLM 将原始文本编码为内部的离散符号（Z-tokens），并能从这些符号中精确重建原文或进行推理。
*   **关键技术细节**：
    *   **变长压缩**：不同于固定长度的向量，压缩器通过自回归方式生成 Z-tokens，语义复杂的片段分配更多 Token，冗余部分则压缩。
    *   **离散化瓶颈**：在原始词表 $V_{base}$ 基础上扩展了 Z-词表 $V_z$。训练时使用 **Gumbel-Softmax** 估计器和直通估计器（Pass-through Estimator）来解决离散符号不可导的问题。
    *   **滑动窗口压缩**：针对超长文本，采用带重叠的滑动窗口，并通过一致性约束（Cosine Similarity）确保相邻窗口的语义衔接。
    *   **两种使用范式**：
        1.  **作为推理器**：解压器直接消耗 Z-tokens 生成下游任务答案（如 QA）。
        2.  **作为重构器**：解压器还原原文，而推理器在纯 Z-token 空间内进行抽象推理。
    *   **训练策略**：引入 **Schedule Sampling**（计划采样），在训练中逐渐从 Teacher Forcing 转向自由解码，以缓解自回归生成的曝光偏差（Exposure Bias）。

### 6. 主要结论与发现
*   **极高的压缩比**：在保持高性能的同时，实现了最高 **18 倍** 的 Token 缩减。
*   **推理加速**：在实际推理中实现了 **2.1x 至 4.6x** 的速度提升，并显著降低了显存占用。
*   **Z-token 的多义性（Polysemy）**：发现 Z-tokens 并非简单的 1:1 映射，而是具有上下文相关性的抽象语义单元。相同的 Z-token 在不同语境下可解压为不同的表达，这证明了其作为“内部语言”的灵活性。
*   **性能保持**：在 4 倍压缩下，下游任务（如 QA 和摘要）的性能几乎与原始全量 Token 模型持平，甚至在某些指标上有所超越。

### 7. 优点（亮点）
*   **内容自适应性**：变长压缩机制比固定长度压缩更符合自然语言的信息分布规律。
*   **离散且可解释**：Z-tokens 是离散符号，比连续向量更容易被 LLM 原生处理，且具有一定的语义一致性。
*   **端到端集成**：将压缩与生成统一在同一个 LLM 架构内，无需引入复杂的外部模块。
*   **鲁棒性**：通过计划采样解决了长序列生成的漂移问题。

### 8. 不足与局限
*   **全局协调能力**：目前的滑动窗口机制虽然能处理长文本，但缺乏一个全局的 Z-token 协调机制来处理跨窗口的超长程依赖。
*   **任务感知能力**：压缩过程目前是通用的，尚未实现根据特定任务（如只关注事实或只关注逻辑）进行定向压缩。
*   **训练成本**：虽然推理高效，但训练过程涉及离散化采样和多任务微调，对高质量对齐数据的依赖程度较高。
