## 摘要
事件相机产生异步、高动态范围的数据流，非常适合检测小型、快速移动的无人机，但大多数基于事件的检测器将稀疏事件流转换为稠密张量，从而丢弃了神经形态感知的表示效率。我们提出了 SparseVoxelDet，据我们所知，这是首个用于事件相机的全稀疏目标检测器，其中骨干特征提取、特征金字塔融合以及检测头均通过 3D 稀疏卷积仅在被占用的体素位置上运行；在流水线的任何阶段都不会实例化稠密特征张量。在 FRED 基准测试（629,832 个标注帧）上，SparseVoxelDet 在每帧仅处理 14,900 个活跃体素（占 T.H.W 网格的 0.23%）的情况下，实现了 83.38% 的 mAP@50，而稠密 YOLOv11 基准模型处理 409,600 个像素（mAP@50 为 87.68%）。将 IoU 阈值从 0.50 放宽到 0.40 后，mAP 恢复至 89.26%，这表明剩余的精度差距主要由边界框回归精度而非检测能力决定。与等效的稠密 3D 体素张量相比，稀疏表示实现了 858 倍的 GPU 显存压缩和 3,670 倍的存储缩减，其数据结构大小随场景动态变化而非传感器分辨率而缩放。对 119,459 个测试帧的误差取证确认，71% 的失败属于定位偏差，而非漏检目标。这些结果表明，原生稀疏处理是事件相机目标检测的一种可行范式，它在不需要神经形态计算硬件的情况下利用了神经形态传感器数据的结构稀疏性，并提供了一个表示成本由场景活动而非像素数量决定的框架，随着事件相机向更高分辨率发展，这一特性变得越来越有价值。

## Abstract
Event cameras produce asynchronous, high-dynamic-range streams well suited for detecting small, fast-moving drones, yet most event-based detectors convert the sparse event stream into dense tensors, discarding the representational efficiency of neuromorphic sensing. We propose SparseVoxelDet, to our knowledge the first fully sparse object detector for event cameras, in which backbone feature extraction, feature pyramid fusion, and the detection head all operate exclusively on occupied voxel positions through 3D sparse convolutions; no dense feature tensor is instantiated at any stage of the pipeline. On the FRED benchmark (629,832 annotated frames), SparseVoxelDet achieves 83.38% mAP at 50 while processing only 14,900 active voxels per frame (0.23% of the T.H.W grid), compared to 409,600 pixels for the dense YOLOv11 baseline (87.68% mAP at 50). Relaxing the IoU threshold from 0.50 to 0.40 recovers mAP to 89.26%, indicating that the remaining accuracy gap is dominated by box regression precision rather than detection capability. The sparse representation yields 858 times GPU memory compression and 3,670 times storage reduction relative to the equivalent dense 3D voxel tensor, with data-structure size that scales with scene dynamics rather than sensor resolution. Error forensics across 119,459 test frames confirms that 71 percent of failures are localization near-misses rather than missed targets. These results demonstrate that native sparse processing is a viable paradigm for event-camera object detection, exploiting the structural sparsity of neuromorphic sensor data without requiring neuromorphic computing hardware, and providing a framework whose representation cost is governed by scene activity rather than pixel count, a property that becomes increasingly valuable as event cameras scale to higher resolutions.

#### 1. 核心问题与整体含义（研究动机和背景）
事件相机（Event Cameras）具有高动态范围和低延迟的特性，非常适合检测微小且快速移动的无人机。然而，现有的主流算法通常将异步、稀疏的事件流转换为稠密的图像帧或张量，以便使用传统的卷积神经网络（如 YOLO）。这种做法不仅丢弃了神经形态传感器原生的**稀疏性**，还导致了巨大的计算浪费：在典型的场景中，只有不到 1% 的体素包含有效数据，但稠密检测器仍需处理所有像素。
**研究动机**：验证是否可以构建一个完全在稀疏域运行的检测器，使计算成本随场景活动（事件数量）而非传感器分辨率缩放，从而实现极高的计算和存储效率。

#### 2. 方法论：核心思想与关键技术
论文提出了 **SparseVoxelDet**，其核心思想是**全流程稀疏处理**，从输入到检测头均不实例化任何稠密张量。
*   **事件体素化（Sparse Voxelization）**：将事件流划分为 $T$ 个时间仓，构建 $T \times H \times W$ 的稀疏体素网格。每个活跃体素提取 6 维特征：正/负事件计数、指数衰减的往复性（Recency）以及时间标准差。
*   **SparseSEResNet 骨干网络**：采用 3D 稀疏卷积（Sparse 3D Convolutions）构建残差网络，并引入挤压-激励（SE）注意力机制。它仅在有事件的坐标及其邻域执行乘加运算。
*   **SparseFPN（稀疏特征金字塔）**：通过稀疏转置卷积进行上采样，并通过稀疏加法融合多尺度特征。特征仅传播到有证据支持的活跃位置。
*   **SparseDetHead（稀疏检测头）**：在时间维度进行最大池化后，使用共享的 MLP（等效于点对点卷积）预测分类、边界框回归（LTRB 格式）和中心度（Centerness），遵循无锚点的 FCOS 范式。
*   **算法流程**：输入稀疏坐标与特征 $\rightarrow$ 3D 稀疏卷积提取特征 $\rightarrow$ 跨尺度稀疏融合 $\rightarrow$ 时间压缩 $\rightarrow$ 逐点预测 $\rightarrow$ 非极大值抑制（NMS）输出结果。

#### 3. 实验设计
*   **数据集**：使用 **FRED (Florence RGB-Event Drone)** 基准测试集，这是目前最大的事件相机无人机检测数据集，包含 231 个序列、629,832 个标注帧，涵盖白天、黄昏、黑夜及多种天气。
*   **对比方法**：对比了 YOLOv11 (Event/RGB)、RT-DETR、Faster R-CNN 以及多模态融合模型 ER-DETR。
*   **评估指标**：标准 COCO 指标（mAP@50, mAP@50:95）以及针对稀疏性的内存和存储压缩率。

#### 4. 资源与算力
*   **硬件**：使用单块 **NVIDIA RTX 3090 (24 GB)** GPU 进行训练。
*   **训练细节**：采用 AdamW 优化器，余弦退火学习率调度。最大训练 50 个 epoch，但在第 4 个 epoch 时因验证集损失达到最小而触发早停（Early Stopping）。
*   **批大小**：每块 GPU 的 Batch Size 为 2。

#### 5. 实验数量与充分性
*   **实验规模**：在 119,459 帧测试集上进行了全面评估，并进行了多随机种子（Seed 42, 123）实验以验证稳定性。
*   **消融实验**：对比了 640×640 分辨率与 1280×720 原生分辨率的表现，探讨了空间分辨率与体素占用率之间的权衡。
*   **误差取证（Error Forensics）**：对所有失败案例进行了系统性分类（定位误差、置信度排名、目标大小等），分析了 9,673 个负样本。
*   **充分性评价**：实验设计非常充分且客观。通过大规模误差分析，作者诚实地指出了稀疏模型在边界框精度上的局限性，而非仅仅堆砌高分指标。

#### 6. 主要结论与发现
*   **性能**：SparseVoxelDet 达到了 **83.38% 的 mAP@50**，虽然比最强的稠密基准 YOLOv11 (87.68%) 低 4.3 个百分点，但远超 RGB 基准和部分融合模型。
*   **效率**：相比等效稠密张量，实现了 **858 倍的显存压缩**和 **3,670 倍的存储缩减**。
*   **可扩展性**：当分辨率从 640 增加到 1280（像素增加 2.25 倍）时，活跃体素仅增加 9%，证明了计算成本与分辨率解耦。
*   **误差根源**：71% 的失败源于“定位偏差”（IoU 在 0 到 0.5 之间）。若将 IoU 阈值放宽至 0.40，mAP 可提升至 89.26%，说明模型能“看到”目标，但框得不够准。

#### 7. 优点
*   **范式创新**：首次在事件相机领域实现全流程 3D 稀疏卷积检测，真正发挥了神经形态传感器的效率优势。
*   **极高效率**：极大地降低了显存占用和存储需求，为资源受限的边缘设备（如嵌入式无人机平台）部署提供了可能。
*   **深度分析**：误差取证分析非常深入，揭示了稀疏表示中“缺乏稠密邻域上下文”对边界框回归的影响。

#### 8. 不足与局限
*   **精度差距**：在严格的 IoU 阈值下（如 mAP@50:95），性能明显落后于稠密模型（39.23% vs 49.25%），这限制了其在需要极高定位精度场景下的应用。
*   **FPN 膨胀**：虽然使用了稀疏卷积，但 FPN 的上采样过程会增加活跃位置的数量，可能在一定程度上削弱稀疏带来的计算优势。
*   **类别局限**：目前仅在单类（无人机）检测上验证，尚未在更复杂的多类别（如自动驾驶）场景下测试其类别区分能力。
