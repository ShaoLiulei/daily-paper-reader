## 摘要
上下文稀疏性是减少大语言模型（LLM）推理过程中计算复杂度的方法之一。现有的基于上下文稀疏性且精度损失极小的 LLM 推理加速技术通常需要训练稀疏模式预测器。本文提出了一种用于加速 LLM 中基于 ReGLU 的前馈网络（FFN）推理的框架。该框架提供了一种快速、无需训练的方法，通过对门控投影矩阵进行截断感知的奇异值分解（SVD）来构建稀疏模式预测器，并配备了阈值校准算法以及支持在 CUDA 和 CANN 设备上进行条件计算的推理执行器。在三个 FFN 平均激活稀疏度为 90% 的稀疏 LLM 上进行的实验表明，端到端解码时间减少了高达 1.8 倍，同时在涉及复杂数学和代码生成的任务中，基准测试分数的下降保持在 1% 以内。这项工作推动了 LLM 在边缘设备上的部署。

## Abstract
Contextual sparsity is one of the approaches used to reduce computational complexity in the inference process of large language models (LLMs). Existing techniques for efficient LLM inference acceleration based on contextual sparsity with minimal accuracy degradation require training sparse pattern predictors. This paper presents a framework for accelerating inference of ReGLU-based feed-forward networks (FFNs) within LLMs. The proposed framework provides a fast, training-free method for building sparse pattern predictors using truncation-aware singular value decomposition (SVD) of the gate projection matrix, along with a threshold calibration algorithm, and inference executors supporting conditional computation on CUDA and CANN devices. Experiments on three sparse LLMs with an average activation sparsity level of 90% in the FFNs demonstrate up to a 1.8x reduction in end-to-end decoding time while maintaining less than 1% degradation in benchmark scores on tasks involving complex math and code generation. This work advances the deployment of LLMs on edge devices.

*   **研究动机**：大语言模型（LLM）在边缘设备部署面临巨大的计算和内存带宽挑战。现代 LLM（如基于 ReGLU 激活的模型）存在**上下文稀疏性**（Contextual Sparsity），即在推理过程中，FFN 层中只有极少数神经元被激活。
*   **核心问题**：现有的利用稀疏性加速推理的方法（如 Deja Vu）通常需要训练额外的轻量级预测器来识别激活模式，这增加了模型部署的复杂度和训练开销。
*   **整体含义**：本文提出了一种**无需训练（Training-free）**的框架，利用奇异值分解（SVD）构建稀疏预测器，旨在不损失精度的情况下显著提升 LLM 的解码速度。

### 2. 方法论：核心思想与关键技术
*   **核心思想**：利用门控投影矩阵 $W_{gate}$ 的低秩近似作为预测器。由于 ReGLU 结构中 $ReLU(W_{gate}x)$ 会将负值置零，预测器的任务是提前识别哪些神经元的点积为正。
*   **关键技术细节**：
    *   **截断感知 SVD 分解**：对 $W_{gate}$ 进行 SVD 分解并保留前 $r$ 个奇异值。为了减少误差，引入了**数据白化（Data Whitening）**技术，利用少量校准数据的协方差矩阵对权重进行变换。
    *   **贪心偏置校准算法**：SVD 截断会导致预测分布偏移。论文提出一种贪心算法，为每个神经元计算特定的偏置项（Threshold），在给定的目标稀疏度下，优先保留对模型输出贡献最大的神经元。
    *   **顺序执行流水线（Sequential Pipeline）**：在推理时，先计算 gate 投影，利用其实际结果进一步过滤 up 投影中被误判为激活的神经元（False Positives），从而实现比预测值更高的实际稀疏度。
    *   **硬件优化执行器**：开发了针对 NVIDIA CUDA 和华为昇腾 CANN 的自定义算子，支持条件计算以跳过未激活神经元的计算。

### 3. 实验设计
*   **实验模型**：选取了三个具有代表性的稀疏化 7B 模型：ProSparse-LLaMA2-7B、SparseQwen2-7B 和 TurboSparse-Mistral-Instruct。
*   **数据集/Benchmark**：涵盖数学推理（GSM8K）、代码生成（HumanEval, MBPP）、科学常识（ARC-E/C）、通用问答（TriviaQA）、复杂推理（BBH）和中文多任务理解（CMMLU）。

### 5. 实验数量与充分性
*   **实验规模**：
    *   在 3 个不同架构的模型上进行了跨 8 个主流 Benchmark 的全面测试。
    *   进行了**消融实验**，验证了数据白化、偏置校准以及顺序执行流水线对精度的贡献。
    *   进行了 **ROC-AUC 分析**，对比了 SVD 预测器与学习型预测器在神经元分类上的准确性。
*   **充分性评价**：实验设计较为充分且客观。通过对比不同稀疏比例（s=0.4 到 0.7）下的表现，展示了速度与精度的权衡曲线。同时，在两种不同硬件平台（CUDA 和 CANN）上验证了加速效果，增强了结论的说服力。

### 6. 主要结论与发现
*   **加速效果显著**：在 FFN 激活稀疏度达到 90% 的情况下，端到端（E2E）解码速度提升高达 **1.8 倍**。
*   **精度保持良好**：在大幅加速的同时，数学和代码等复杂任务的精度下降控制在 **1% 以内**。
*   **预测能力优越**：SVD 预测器的 ROC-AUC 分数优于部分需要训练的预测器（如 PowerInfer），说明直接利用权重结构的 SVD 近似能更好地捕捉神经元激活特征。
*   **硬件友好**：在昇腾设备上，仅通过高层 PyTorch API 即可获得显著加速，无需底层指令优化。

### 7. 优点
*   **部署便捷**：无需复杂的反向传播训练过程，仅需少量数据做 SVD 分解和贪心校准，适合快速适配新模型。
*   **理论支撑**：论文为 SVD 预测器的误差界限提供了确定性的理论分析（见附录）。
*   **灵活性高**：通过调整偏置校准中的目标稀疏度参数，可以轻松实现不同场景下的速度-精度平衡。

### 8. 不足与局限
*   **激活函数限制**：该方法目前主要针对 **ReLU 或 ReGLU** 等具有硬零特性的激活函数。对于 SiLU（Swish）等平滑激活函数，直接应用会导致明显的精度下降（如文中对 Qwen2-Instruct 的测试所示）。
*   **Batch Size 限制**：实验主要针对 **Batch Size = 1** 的解码场景。在批处理推理中，由于不同序列的稀疏模式不重合，稀疏带来的加速增益会显著降低。
*   **Prefill 阶段无效**：由于 Prefill 阶段通常是计算密集型且具有高度并行性，该稀疏预测方法目前仅应用于 Decoding（解码）阶段。
