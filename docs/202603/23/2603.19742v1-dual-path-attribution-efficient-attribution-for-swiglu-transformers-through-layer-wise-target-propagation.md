## 摘要
理解基于 Transformer 的大语言模型（LLM）的内部机制对于其可靠部署和有效运行至关重要。尽管最近的研究产生了大量试图平衡忠实度（faithfulness）和计算效率的归因方法，但密集组件归因（dense component attribution）的成本仍然高得令人望而却步。在这项工作中，我们引入了双路径归因（DPA），这是一个新颖的框架，它通过一次前向和一次后向传递，在冻结的 Transformer 上忠实地追踪信息流，且无需反事实样本。DPA 通过解析地分解并将 SwiGLU Transformer 的计算结构线性化为不同的路径，并沿着这些路径传播目标解嵌入向量（unembedding vector），从而在每个残差位置获取有效表示。这种以目标为中心的传播在模型组件数量方面实现了 O(1) 的时间复杂度，可扩展到长输入序列和密集组件归因。在标准可解释性基准测试上的广泛实验表明，与现有基准相比，DPA 实现了最先进的忠实度和前所未有的效率。

## Abstract
Understanding the internal mechanisms of transformer-based large language models (LLMs) is crucial for their reliable deployment and effective operation. While recent efforts have yielded a plethora of attribution methods attempting to balance faithfulness and computational efficiency, dense component attribution remains prohibitively expensive. In this work, we introduce Dual Path Attribution (DPA), a novel framework that faithfully traces information flow on the frozen transformer in one forward and one backward pass without requiring counterfactual examples. DPA analytically decomposes and linearizes the computational structure of the SwiGLU Transformers into distinct pathways along which it propagates a targeted unembedding vector to receive the effective representation at each residual position. This target-centric propagation achieves O(1) time complexity with respect to the number of model components, scaling to long input sequences and dense component attribution. Extensive experiments on standard interpretability benchmarks demonstrate that DPA achieves state-of-the-art faithfulness and unprecedented efficiency compared to existing baselines.

### 2. 方法论
*   **核心思想**：**目标中心传播（Target-Centric Propagation）**。不同于传统方法将组件影响“向前”传递，DPA 将目标 Token 的解嵌入向量（Unembedding Vector）“向后”递归传播，通过一次前向（缓存激活）和一次后向（传播目标）即可计算所有组件的归因。
*   **关键技术细节**：
    *   **双路径分解**：利用 SwiGLU 的双线性结构，将计算图分解为**内容路径（Content Pathway）**（负责传递表示，如 Value 和 Up 投影）和**控制路径（Control Pathway）**（负责路由和转换，如 Attention 评分和 Gate 门控）。
    *   **线性化反向传播**：
        *   **GLU 神经元**：将神经元贡献分解为 Up 路径和 Gate 路径，通过局部梯度比率近似非线性激活（SiLU）。
        *   **注意力头**：将 MHSA 分解为 Query、Key 和 Value 路径。对于 Softmax 的非线性，采用基于泰勒展开的分解来保持稳定性。
    *   **加权聚合**：引入超参数 $\mu$ 来平衡不同路径的贡献，确保目标向量在回传过程中不发生范数爆炸并维持完整性。
*   **算法流程**：
    1.  **前向执行**：运行模型并缓存所有必要的中间激活值。
    2.  **自顶向下传播**：从输出层开始，将目标向量递归地通过线性化的逆变换传回每一层，计算每个残差位置的“有效目标”。
    3.  **得分计算**：通过有效目标与组件贡献的内积，直接得到归因分数。

### 6. 主要结论与发现
*   **性能领先**：DPA 在所有测试的数据集和模型上，其归因忠实度（Total AUC）均达到或超过了最先进的基准方法。
*   **效率突破**：成功解决了密集组件归因的计算瓶颈，使得在长序列和大规模模型上进行全量组件分析成为可能。
*   **路径特性**：实验发现，宏观的 Token 重要性更依赖于“内容路径”，而细粒度的组件功能定位则高度依赖于“控制路径”（如 Gate 和 Query/Key）。

### 7. 优点
*   **极高效率**：单次后向传播即可完成归因，彻底摆脱了对多次前向推理的依赖。
*   **高忠实度**：通过对 SwiGLU 结构的精确解析分解，比传统的梯度法更贴合模型的实际物理机制。
*   **架构通用性**：虽然针对 SwiGLU 优化，但其“自顶向下目标传播”的逻辑可推广至其他 Transformer 变体。

### 8. 不足与局限
*   **架构依赖性**：对于非 SwiGLU 架构（如 MoE 或 Mamba），需要手动推导新的数学逆变换公式，无法直接开箱即用。
*   **线性化误差**：在模型表现出高度非线性或强耦合交互的区域，一阶泰勒展开的近似可能会失效。
*   **Logit 局限**：DPA 追踪的是 Logit 分数而非最终概率，无法捕捉通过抑制竞争 Token 来提升目标概率的间接机制。
*   **内存开销**：虽然计算快，但缓存所有中间层激活值对显存有较高要求。
