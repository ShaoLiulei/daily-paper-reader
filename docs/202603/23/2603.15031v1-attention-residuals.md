## 摘要
采用 PreNorm 的残差连接是现代大语言模型（LLM）的标准配置，但它们以固定的单位权重累加所有层的输出。这种均匀聚合导致隐藏状态随深度增加而出现不受控的增长，从而逐渐稀释了每一层的贡献。我们提出了注意力残差（Attention Residuals，简称 AttnRes），它将这种固定累加替换为对前序层输出的 softmax 注意力机制，使每一层能够利用学习到的、依赖于输入的权重，选择性地聚合早期的表示。为了解决在大规模模型训练中对所有前序层输出进行注意力计算所带来的内存和通信开销，我们引入了分块注意力残差（Block AttnRes），它将层划分为块，并对块级表示进行注意力计算，在保留完整 AttnRes 大部分收益的同时减少了内存占用。结合基于缓存的流水线通信和两阶段计算策略，Block AttnRes 成为标准残差连接的实用即插即用替代方案，且开销极小。缩放法则（Scaling law）实验证实，这种改进在不同模型规模下是一致的，消融实验验证了依赖内容的深度选择所带来的益处。我们进一步将 AttnRes 集成到 Kimi Linear 架构中（总参数 48B / 激活参数 3B），并在 1.4T token 上进行预训练。实验表明，AttnRes 缓解了 PreNorm 稀释问题，使不同深度的输出幅度和梯度分布更加均匀，并提升了所有评估任务的下游性能。

## Abstract
Residual connections with PreNorm are standard in modern LLMs, yet they accumulate all layer outputs with fixed unit weights. This uniform aggregation causes uncontrolled hidden-state growth with depth, progressively diluting each layer's contribution. We propose Attention Residuals (AttnRes), which replaces this fixed accumulation with softmax attention over preceding layer outputs, allowing each layer to selectively aggregate earlier representations with learned, input-dependent weights. To address the memory and communication overhead of attending over all preceding layer outputs for large-scale model training, we introduce Block AttnRes, which partitions layers into blocks and attends over block-level representations, reducing the memory footprint while preserving most of the gains of full AttnRes. Combined with cache-based pipeline communication and a two-phase computation strategy, Block AttnRes becomes a practical drop-in replacement for standard residual connections with minimal overhead.   Scaling law experiments confirm that the improvement is consistent across model sizes, and ablations validate the benefit of content-dependent depth-wise selection. We further integrate AttnRes into the Kimi Linear architecture (48B total / 3B activated parameters) and pre-train on 1.4T tokens, where AttnRes mitigates PreNorm dilution, yielding more uniform output magnitudes and gradient distribution across depth, and improves downstream performance across all evaluated tasks.

以下是对该论文的结构化总结：

### 1. 核心问题与研究动机
*   **核心问题**：现代 LLM 普遍采用 PreNorm 残差连接（$h_l = h_{l-1} + f(h_{l-1})$），这种机制以固定的单位权重（1.0）累加所有层的输出。
*   **研究动机**：
    *   **隐藏状态增长失控**：随着模型深度增加，隐藏状态的幅度呈 $O(L)$ 线性增长，导致每一层对最终表示的相对贡献被稀释（PreNorm Dilution）。
    *   **缺乏选择性**：所有层都接收相同的均匀聚合状态，无法根据输入内容选择性地提取或抑制特定层的信息。
    *   **深度-时间对偶性**：残差连接在深度维度上类似于 RNN 的循环。正如 Transformer 用注意力机制取代了序列上的循环，作者认为也应该用注意力机制取代深度上的循环累加。

### 2. 方法论
*   **核心思想**：将固定的残差累加替换为对所有前序层输出的 **Softmax 注意力聚合**。
*   **Full AttnRes（完整版）**：
    *   每一层 $l$ 拥有一个可学习的伪查询向量（Pseudo-query）$w_l$。
    *   它对嵌入层和之前所有层的输出进行加权聚合：$h_l = \sum \alpha_{i \to l} \cdot v_i$。
    *   使用 RMSNorm 处理 Key 以防止幅度差异主导权重。
*   **Block AttnRes（分块版）**：
    *   为了解决大规模训练中 $O(L^2)$ 的内存和通信开销，将层划分为 $N$ 个块（通常 $N \approx 8$）。
    *   块内使用标准残差，块间使用 AttnRes。这使通信开销从 $O(Ld)$ 降至 $O(Nd)$。
*   **关键技术优化**：
    *   **跨阶段缓存（Cross-stage Caching）**：在流水线并行训练中，通过缓存减少冗余的块传输。
    *   **两阶段计算策略**：在推理时，将跨块注意力（并行）与块内残差（串行）结合，利用 Online Softmax 融合，将推理延迟开销降至 2% 以下。

### 6. 主要结论与发现
*   **性能提升**：AttnRes 在相同算力下显著优于 Baseline，Block AttnRes 达到了 Baseline 1.25 倍算力的性能水平。
*   **任务表现**：在推理密集型任务（GPQA +7.5，Math +3.6）和代码任务（HumanEval +3.1）上提升尤为显著。
*   **训练稳定性**：AttnRes 有效抑制了隐藏状态幅度的无序增长，使梯度在不同深度间的分布更加均匀，缓解了深层稀释问题。
*   **架构偏好**：AttnRes 使得模型更倾向于“深而窄”的架构，能够比标准 Transformer 更有效地利用深度。

### 7. 优点与亮点
*   **理论完备性**：通过“深度-时间对偶性”为残差连接提供了全新的视角，将残差演进路径统一在结构化矩阵框架下。
*   **工程落地性强**：提出的 Block AttnRes 和两阶段推理策略极大地降低了实际部署的门槛，证明了该方法不仅理论优美，而且在大规模生产环境中可行。
*   **即插即用**：作为残差连接的替代方案，它几乎不改变原有的算子结构，易于集成到现有框架。

### 8. 不足与局限
*   **内存/通信开销**：尽管 Block AttnRes 降低了开销，但相比标准残差，它仍需额外的显存来存储块表示，且在流水线并行下增加了通信复杂性。
*   **推理延迟**：虽然开销控制在 2% 以内，但在极端低延迟要求的场景下，额外的注意力计算仍是一个考虑因素。
*   **超参数敏感性**：虽然论文给出了 $N=8$ 的建议，但在不同深度或不同任务的模型中，最优的块大小和初始化策略可能仍需微调。
