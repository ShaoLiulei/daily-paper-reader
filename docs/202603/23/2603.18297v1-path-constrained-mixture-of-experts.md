## 摘要
稀疏混合专家（MoE）架构通过为每个输入仅激活一部分参数，实现了高效的规模扩展。然而，传统的 MoE 路由独立地选择每一层的专家，从而在 L 层、每层 N 个专家的情况下产生了 N^L 条可能的专家路径。这远远超过了典型的训练集规模，导致统计效率低下，因为模型可能无法在如此巨大的路径空间中学习到有意义的结构。为了约束这一空间，我们提出了 Path-MoE，它在连续层之间共享路由参数。在 0.9B 和 16B 参数模型上的实验表明，与独立路由相比，该方法在困惑度（perplexity）和下游任务上均有一致的提升，同时消除了对辅助负载均衡损失的需求。分析表明，遵循相同路径的 token 会根据语言功能自然聚类，而 Path-MoE 产生了更集中的聚类、更好的跨层一致性以及对路由扰动更强的鲁棒性。这些结果为从专家路径的角度理解 MoE 架构提供了一个新的视角。

## Abstract
Sparse Mixture-of-Experts (MoE) architectures enable efficient scaling by activating only a subset of parameters for each input. However, conventional MoE routing selects each layer's experts independently, creating N^L possible expert paths -- for N experts across L layers. This far exceeds typical training set sizes, leading to statistical inefficiency as the model may not learn meaningful structure over such a vast path space. To constrain it, we propose \pathmoe, which shares router parameters across consecutive layers. Experiments on 0.9B and 16B parameter models demonstrate consistent improvements on perplexity and downstream tasks over independent routing, while eliminating the need for auxiliary load balancing losses. Analysis reveals that tokens following the same path naturally cluster by linguistic function, with \pathmoe{} producing more concentrated groups, better cross-layer consistency, and greater robustness to routing perturbations. These results offer a new perspective for understanding MoE architectures through the lens of expert paths.

*   **核心问题**：传统的稀疏混合专家（MoE）架构在每一层都独立进行路由决策。对于拥有 $L$ 层、每层 $N$ 个专家的模型，理论上存在 $N^L$ 条可能的专家路径。
*   **研究动机**：
    *   **统计效率低下**：路径空间（如 $10^{29}$）远超实际训练数据量（如 $10^{11}$ tokens），导致绝大多数路径在训练期间从未被激活，模型难以学习到有效的路径结构。
    *   **缺乏跨层协调**：独立路由忽略了 token 在网络深处处理的连续性。
*   **整体含义**：本文旨在通过架构设计约束专家路径空间，提高 MoE 模型的样本效率和性能。

### 2. 论文提出的方法论：PathMoE
*   **核心思想**：引入**块级参数共享路由（Block-wise Parameter Shared Routing）**。将网络划分为多个连续层的“块”（Block），同一个块内的所有 MoE 层共享同一个路由器的权重参数。
*   **关键技术细节**：
    *   **路由机制**：给定输入 $x$，路由概率 $p = \text{softmax}(Wx)$。在 PathMoE 中，若块大小为 $B$，则对于层 $l$，其路由器参数 $W_l = W_{\text{shared}}^{\lceil l/B \rceil}$。
    *   **路径约束逻辑**：由于残差连接的存在，相邻层的表示 $x$ 变化缓慢。共享 $W$ 会诱导相邻层做出相似（但不完全相同）的路由决策，从而在不强制锁定决策的情况下，自然地形成连贯的专家路径。
    *   **无需辅助损失**：PathMoE 在不使用传统负载均衡损失（Auxiliary Load Balancing Loss）的情况下，依然能保持专家利用率的平衡，简化了超参数调优。

### 6. 主要结论与发现

*   **路径集中化**：PathMoE 将 token 集中到更少、更有效的路径中，有效路径空间减少了约一半（熵降低 1 bit）。
*   **语言学特化**：发现专家路径会自发地根据语言功能（如标点、人名、动词、时间词）进行聚类，PathMoE 的聚类比独立路由更紧密。
*   **鲁棒性极强**：在对路由进行随机扰动时，PathMoE 的性能下降远小于独立路由（鲁棒性高出 22.5 倍），表明其学习到了更稳健的特征处理路径。

### 7. 优点
*   **简单且优雅**：仅通过参数共享就解决了复杂的路径爆炸问题，没有引入复杂的循环结构或额外的计算开销。
*   **稳定性**：消除了对辅助负载均衡损失的依赖，降低了训练不稳定的风险。
*   **可解释性**：通过“专家路径”视角，揭示了 MoE 模型内部如何按语言学逻辑分工。

### 8. 不足与局限
*   **超参数敏感性**：块大小 $B$ 需要根据模型深度和任务类型进行调整（实验显示 $B=4$ 通常较好，但并非绝对）。
*   **适用范围限制**：初步实验显示该方法对“专家选择 token”（Expert-choice）路由无效，主要适用于“token 选择专家”（Token-choice）路由。
*   **路径预测器缺失**：目前仍依赖于逐层（或逐块）路由，未来若能直接预测完整路径，可能会进一步提升推理效率。
