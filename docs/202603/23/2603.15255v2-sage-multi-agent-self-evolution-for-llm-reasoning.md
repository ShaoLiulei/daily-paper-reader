## 摘要
具有可验证奖励的强化学习提升了大语言模型（LLMs）的推理能力，但许多方法仍依赖于大规模的人工标注数据集。虽然自我博弈（self-play）减少了这种依赖，但它往往缺乏显式的规划和强大的质量控制，限制了在长程多步推理中的稳定性。我们提出了 SAGE（Self-evolving Agents for Generalized reasoning Evolution），这是一个闭环框架，其中四个智能体：挑战者（Challenger）、规划者（Planner）、求解者（Solver）和评论者（Critic），仅使用少量的种子集，从共享的 LLM 主干网络中共同演化。挑战者不断生成难度递增的任务；规划者将每个任务转换为结构化的多步计划；求解者遵循该计划生成答案，其正确性由外部验证器确定。评论者对生成的题目和计划进行评分和过滤，以防止课程漂移（curriculum drift）并保持训练信号的质量，从而实现稳定的自我训练。在数学和代码生成基准测试中，SAGE 在不同模型规模上均实现了持续的提升，使 Qwen-2.5-7B 模型在 LiveCodeBench 上提升了 8.9%，在 OlympiadBench 上提升了 10.7%。

## Abstract
Reinforcement learning with verifiable rewards improves reasoning in large language models (LLMs), but many methods still rely on large human-labeled datasets. While self-play reduces this dependency, it often lacks explicit planning and strong quality control, limiting stability in long-horizon multi-step reasoning. We present SAGE (Self-evolving Agents for Generalized reasoning Evolution), a closed-loop framework where four agents: Challenger, Planner, Solver, and Critic, co-evolve from a shared LLM backbone using only a small seed set. The Challenger continuously generates increasingly difficult tasks; the Planner converts each task into a structured multi-step plan; and the Solver follows the plan to produce an answer, whose correctness is determined by external verifiers. The Critic scores and filters both generated questions and plans to prevent curriculum drift and maintain training signal quality, enabling stable self-training. Across mathematics and code-generation benchmarks, SAGE delivers consistent gains across model scales, improving the Qwen-2.5-7B model by 8.9% on LiveCodeBench and 10.7% on OlympiadBench.

#### 1. 核心问题与整体含义（研究动机和背景）
当前大语言模型（LLM）在数学和代码等推理任务中，主要依赖具有可验证奖励的强化学习（RLVR）。然而，这类方法通常面临两个瓶颈：
*   **数据依赖性**：高度依赖大规模人工标注的高质量数据集，难以实现自主进化。
*   **系统不稳定性**：现有的自我博弈（Self-play）方法往往缺乏显式的规划（Planning）和严格的质量控制，导致在处理长程、多步推理任务时容易出现“课程漂移”（Curriculum Drift），即生成的任务质量下降或模型陷入无效的训练循环。

**SAGE** 旨在通过一个闭环的多智能体协同进化框架，仅利用极少量的种子数据（Seed Set），实现模型在可验证领域（数学、编程）的自主能力提升。

#### 2. 方法论：核心思想与关键技术
SAGE 在一个共享的 LLM 骨干网络上实例化了四个专门的智能体，形成“挑战-规划-求解-评价”的闭环：
*   **挑战者 (Challenger)**：基于种子示例生成更具挑战性的新任务及其验证器。其奖励由任务质量（评论者评分）和难度（求解者的失败率）共同决定，形成对抗性进化。
*   **规划者 (Planner)**：将任务分解为结构化的多步执行计划。
*   **求解者 (Solver)**：遵循规划者的计划生成最终答案。其正确性由外部环境（如编译器、数学公式检查器）进行客观验证。
*   **评论者 (Critic)**：双重职责。一是提供格式奖励以稳定训练；二是对生成的题目和计划进行质量评分和过滤，防止低质量数据污染训练集。
